# 策略设计与迭代规程

## 一、必须能回答的六问（答不上就是策略有洞）

1. 为什么选这只（触发因子 + 数据日期）
2. 为什么现在买（入场区间的依据）
3. 为什么买了却亏（失效条件是否被触发，还是规则本身错）
4. 为什么它能涨（哪条因子/资金在起作用）
5. 为什么没发现它在**套人**（出货特征：放量滞涨、上影密集、资金流与价格背离、板块内相对强度衰减）
6. 为什么没发现它在**吸筹**（缩量横盘、尾盘拉升、大单净流入价格不涨、筹码集中度上升）

## 二、传导关系（三层，逐层给证据）

- **大盘 ↔ 个股**：指数相位（orchestrator 相位加权）决定仓位上限，个股强度决定是否超配。
- **板块 ↔ 个股**：板块资金流为个股前提；板块走弱时个股信号降权，不许逆板块加仓。
- **外围 ↔ 大盘**：外围只影响开盘与风险偏好，不直接改个股规则；外围冲击时先降杠杆再看信号。

## 三、策略写法（可判定才叫策略）

每条策略必须包含：
- 触发条件（可计算的表达式，含阈值与窗口）
- 失效条件（什么情况下立即离场）
- 仓位规则（与大盘相位绑定）
- 例外处理（涨停/跌停/停牌/除权/流动性枯竭/一字板）
- 回测口径（样本区间、轮次、win / beat / net 三指标）

反例（不许写）："行情转暖时择机介入"——不可判定，等于没写。

## 四、自我迭代机制

1. 推票留痕：日期、票、置信度、入场区、结果。
2. 定期复盘：算真实 win/beat，和回测基线比。
3. 偏差归因：规则错 / 数据错 / 执行错，三者分开记。
4. 修订登记：改了什么规则、为什么改、改前改后指标。
5. **撤销机制**：发现回测虚高（如单一行情 artifact）必须撤销注册并记录污染原因，不许保留"好看的历史数字"。

## 六、突发情况应对（预案，不是事后解释）

| 情况 | 处置 |
|---|---|
| 大盘单日大幅下挫 | 触发相位降档，暂停新开仓，已有仓位按失效条件处理 |
| 板块集体涨停 | 不追高，等次日分化，只做仍在资金流前列的 |
| 个股一字板/停牌 | 剔除出候选池，不占用置信度名额 |
| 数据源断供 | 标注"数据不足"，停止出票，不许用旧值外推 |
| 置信度与实际连续背离 | 上报复核，冻结该策略出票权 |
