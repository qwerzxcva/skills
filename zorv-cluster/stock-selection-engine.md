# 选股引擎规程

## 零、交易范围（硬边界）

- **只做股票 + ETF**。可转债、期权、期货、融资融券不作为交易对象；可转债数据仅作市场情绪/溢价率辅助指标。
- 港股/美股数据可用于参考，但输出主体是 A 股个股与 ETF。
- 不推荐、不实现转债与期权类功能，避免范围蔓延。

## 一、三池框架（必须齐，不许只有热点池）

用户明确指出过的问题：**只有"热点池"和"AI 推荐"、且 AI 推荐全是涨停股，等于追高。** 必须三池并行：

1. **周期池**：数据库 + 实时热点 + 周期算法 + 每日复盘。回答"当前处在什么周期阶段、什么风格占优"。
2. **板块池**：数据库 + 实时热点 + 板块轮动 + 每日复盘。回答"资金在哪些板块轮动、板块相对强度排序"。
3. **低位股票池**（重点、最缺）：**尚未涨停的低位票**、**今天买入明天能涨的低位票**。这是与热点池互补的入口，不许用涨停股充数。

每池独立产出候选，再进入共识环节。算法规模目标 ≥1GB（用户明确要求），不许只做轻量筛选。

## 二、四引擎共识（缺引擎就标"降级"）

1. **orchestrator**：相位加权总控
2. **117 因子截面融合**
3. **v7 回本校验**
4. **mf_factors 资金流**（约 435 票覆盖）

四引擎同向 → 高置信；三对一 → 中置信并说明分歧；二对二 → 不出票。

## 三、输出格式（每只票必须齐）

- 代码 + 名称 + 板块 + 所属池（周期/板块/低位）
- **连续置信度**（0~1，非二值）
- 触发因子（因子名 + 当前值/分位）
- **入场价格区域**（区间，不是"现在买"）
- **失效条件**（跌破某价、因子反转、板块走弱）
- 持有周期（按 22 日截面口径）

## 四、用户偏好（硬约束）

- **只要事实变化，不要宏观分析与涨跌预测**。
- 自选股固定关注：贵州茅台、宁德时代、比亚迪、腾讯控股、中国移动；每只给一个具体价格区域。
- 无票时直接说"今日无票"，不凑数。

## 五、盈利验证闭环（核心指标）

- 算法第一目标是**可验证的赚钱效果**，不是指标好看。
- 推股必须留痕：日期、票、池、置信度、入场区。
- 验证口径：**早盘/午盘推股 → 收盘与次日开盘验证盈利**，逐期统计 win / beat / net。
- 收益主张必须附样本区间与轮次；禁引无口径数字。
- 必引基线：v7 300 轮 recoup22 88.8% / recoup60 93.1% / beat 66%；v4 5 年 win 47.4% / beat 62% / net +0.05%/22日（旧 55.6% 含水分已作废）。

## 六、纪律

- 每个入选必须有可回溯依据：因子名 + 数值 + 数据日期。
- 数据缺失时标"数据不足，不出票"，不许用估算值冒充实测。
- 连续 N 期置信度与实际收益背离 → 上报策略专家复核，不许自行放宽阈值。
