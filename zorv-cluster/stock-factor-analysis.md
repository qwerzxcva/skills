# 因子分析检验规程

## 一、因子矩阵事实基线

- `factor_matrix.duckdb`：约 695 万行 × 3317 票 × 117 列，含标签 `fwd_ret_1d`；重建后 7.5GB。增量模式可断点续算。
- 因子族：动量、反转、波动率结构、资金流（mf_factors 5 因子）、情绪筹码（涨停池可造）、PIT 基本面（db-fin-0 待对齐）。
- 写入必须逐批 INSERT + CHECKPOINT（一次性 concat 会被 OOM killer 杀）。

## 二、三条铁律（都是真实踩过的坑）

1. **标签必须用 `lead()` 不能用 `lag()`**。用 lag = 把当日收益当未来收益，前视泄漏，AUC 会虚高到 1.0。
2. **因子必须分年检验**。反例：`rev_pick` 在 2024–26 显示 +15%，实为 2025 行情 artifact；全期 −13.5%，等于接飞刀，已撤销注册。
3. **A 股月频呈反转结构**：高 IC 动量因子多空（LS）常为负，不许因为"动量 IC 高"就上线。

## 三、检验流程（新因子必经）

1. 截面标准化（去极值 → 中性化按需 → z-score），避免量纲影响。
2. IC / IR：逐期截面秩相关，看**时序稳定性**而非单一均值。
3. 分层回测：按因子分位分组，看单调性与多空（LS）方向。
4. **LS 检验（22 日截面）必须先跑**，未跑不许登记。
5. 相关性去冗余：与存量因子相关性过高（>0.7）则合并或替换，不叠加。
6. 分年 + 分板块稳健性：任一子样本反向要说明原因。

## 四、输出：因子体检报告（固定结构）

```
因子名 / 定义 / 计算口径（含数据源与窗口）
覆盖：票数 × 期数 ｜ 缺失率
IC 时序：均值 / 标准差 / IR / 胜率
分年 IC：2020…2026 逐年值
分层回测：各组年化、单调性
LS 方向与强度（22日）
与存量因子最大相关性
结论：登记 / 观察 / 否决（附理由）
```

## 五、禁止事项

- 未跑 LS 检验就登记因子。
- 用全期均值掩盖子样本反向。
- 把 artifact 当 alpha（必须回看分年）。
- 发现污染不上报、悄悄改阈值。

## 六、协同升级方向（已有规划，不许另起炉灶）

- 连续置信度替代二值信号；引擎协同用 Wolpert stacking。
- 57 引擎合并路线：57 → 44 → 11 功能组。
- 优化缺口：情绪筹码（涨停池）、波动率结构（零成本）、PIT 基本面（待 db-fin-0 对齐）。
