## ⚡ 核心规则（必读）

### 时间约束
- **总响应时间 ≤ 5分钟**（含脚本执行+分析生成）
- 脚本超时设为 8~15 秒，超时直接降级处理
- 非交易时段：跳过实时API，直接用最近交易日缓存数据
- K线数据只取最近 60 根（日K），减少计算量

### 执行策略
- **优先并行**：行情+K线+周K+舆情+板块 多个请求同时发出
- **只取必要数据**：默认返回 TOP10 排行而非 TOP20
- **一次对话只做一件事**：不要在一次回复里既分析个股又扫全市场

### ❌ 不要做的事
- 不要在非交易时段反复重试API（直接提示「非交易时段，显示昨日收盘数据」）
- 不要给出「一定涨」「包赚」等绝对化承诺
- 不要对同一只股票在单次对话中重复请求超过 2 次
- 不要忽略脚本报错，必须翻译成中文友好提示

| K线数据为空 | 「该股票K线数据不足（可能是新股或长期停牌），暂时无法进行技术分析。」 |
| ImportError: requests | 「缺少必要的网络库，正在自动安装中...」（然后执行 pip install requests） |
| 股票代码不存在 | 「未找到代码「XXX」，请尝试用股票名称搜索，如「搜索茅台」。」 |
| 非交易时段 | 「当前非交易时段，以下为最近交易日（X月X日）收盘数据。」 |
| DuckDuckGo限流 | 「搜索请求较频繁，请稍后再试。」 |
| ImportError: thsdk | 「缺少同花顺数据包，正在自动安装中...」（然后执行 pip install thsdk） |
| THS「未登录」 | 「THS游客模式连接失败，请检查网络或稍后重试。」 |
| 竞价异动数据为空 | 「竞价异动数据需在9:15~9:25时段查询，当前非竞价时段。」 |
| 问财查询无结果 | 「问财未找到符合条件的结果，请尝试放宽条件。」 |

**兜底原则**：任何未预料的错误，统一回复：
> 「抱歉，出了点小问题（错误类型：XXX）。请尝试：①检查股票代码 ②稍后重试 ③换一只股票试试。」

## 🚫 常见反例（不要这样做）

| ❌ 错误做法 | ✅ 正确做法 |
|-----------|-----------|
| 输出英文报错 `ConnectionError:...` | 翻译成「网络不太稳定，请稍后重试」 |
| 一次回复同时分析5只股票 | 一次只分析1只，让用户逐一询问 |
| 分析结果超过500字 | 精简到300字以内，关键信息优先 |
| 给出「一定会涨」的判断 | 只给评分和概率性建议 |
| 非交易时段反复重试API | 直接提示非交易时段，显示昨日数据 |
| 用户说「茅台」直接当代码查 | 先搜索确认代码，再查询行情 |
| 忽略用户说的市场（港股/美股） | 根据上下文判断市场，美股用字母代码 |
| 热门扫描只搜一个源 | 多源聚合（东方财富+Google News+DuckDuckGo） |
| 用户要看图只给文字 | 调用 chart_renderer.py 生成PNG并返回路径 |
