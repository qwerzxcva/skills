## 📌 这是什么？

一个**AI股票监测助手**，可以帮你：
- 📡 **实时盯盘** — 股价异动自动提醒
- 💰 **持仓管理** — 记录成本价，自动算盈亏，**给操作建议**
- 📊 **深度分析** — 技术面+资金面+基本面，8大模块专业分析
- 🔔 **企微推送** — 异动消息直接推到手机（企业微信群）
- 🛡️ **进程守护** — 挂了自动重启，不用天天管

## ⚡ 快速上手（3步）

### 第1步：安装依赖

打开命令行（CMD或PowerShell），执行：

```
pip install requests
```

> 可选：`pip install win10toast`（Windows桌面弹窗提醒）

### 第2步：添加你的持仓

```
python position_manager.py add sh600519 --name 贵州茅台 --cost 1700 --shares 100 --date 2026-02-13
```

参数说明：
- `sh600023` = 股票代码（上海用sh，深圳用sz）
- `--cost 1700` = 你的买入成本价
- `--shares 100` = 持有股数
- `--date 2026-02-13` = 买入日期

### 第3步：开始监测

```
python monitor.py "sh600519:贵州茅台:2.0" --interval 30 --duration 120
```

意思是：**每30秒检查一次茅台，涨跌超2%就提醒，持续监测120分钟**

## 🔔 配置推送通知（可选）

### 企业微信群机器人

1. 在企业微信群里创建群机器人（群设置 → 群机器人 → 添加）
2. 复制 Webhook 地址
3. 编辑 `notifier_config.json`：

```json
{
  "wechat": {
    "enabled": true,
    "webhook_url": "你的webhook地址",
    "mention_mobiles": []
  }
}
```

4. 测试推送：
```
python notifier.py test
```

### 推送内容长什么样？

v5.0的推送格式是**结论前置**，不像其他工具丢一堆数据：

```
📊 【茅台操作建议】继续持有 ✅
浮盈 +3.2%，目标价位 1850 元，止损位 1680 元

📋 持仓情况：100股 × 1700元 → 当前1754元
💰 总盈亏：+5,400元（+3.2%）
📈 今日行情：1754元 +1.05%

⚠️ 注意事项：MA20支撑有效，量能温和放大
🔥 推荐：宁德时代（仅供参考）
━━━━━━━━━━━━━━━
⚠️ 以上为AI辅助建议，不构成投资建议
```

## ❓ 常见问题

**Q: 需要注册账号吗？**
A: 不需要。数据源是公开接口，直接能用。

**Q: 支持哪些股票？**
A: A股全市场——沪深主板、创业板、科创板都支持。

**Q: 数据准吗？**
A: 三数据源交叉验证（腾讯财经+东方财富+新浪），价格差异超0.5%会警告。

**Q: 监测会一直跑吗？**
A: 默认按你设定的时间跑。可以用guardian.py在交易时间自动守护。

**Q: 能推送到手机吗？**
A: 可以！目前支持企业微信、钉钉、Bark(iOS)、Server酱。

**Q: 分析结果靠谱吗？**
A: 基于技术指标和量化模型的AI辅助参考，**不构成投资建议**。买卖决策还需结合自身判断。
