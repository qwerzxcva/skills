## 📊 功能详解

### 1️⃣ 智能分析专家 ⭐⭐⭐⭐⭐

**最推荐的功能！** 输入股票代码，秒出专业分析报告。

```bash
python analyzer.py 600105 --name 永鼎股份
```

| 📈 行情数据 | 价格、涨跌幅、成交量、成交额 |

| 💰 财务指标 | PE市盈率、PB市净率、估值评价 |
| 📊 大盘对比 | 相对上证指数强弱 |
| ⭐ 综合评分 | 五星评级系统 |
| 💡 操作建议 | 买入/持有/观望/减仓 + 理由 |
| 🎯 目标/止损 | 目标价、止损价 |

### 2️⃣ 实时监测盯盘 ⭐⭐⭐⭐⭐

**不用一直看盘，有异动自动提醒！**

```bash
python monitor.py "sh600519:茅台:2.0" --interval 30 --duration 240
```

**参数说明：**

| 参数 | 说明 | 示例 |
|------|------|------|
| `sh600519:茅台:2.0` | 股票代码:名称:涨跌幅阈值 | 涨超2%提醒 |
| `--interval 30` | 刷新间隔（秒） | 30秒刷一次 |
| `--duration 240` | 运行时长（分钟） | 跑4小时 |

**提醒类型：**
- 🔔 大涨提醒：涨幅超过设定阈值
- 🔔 大跌提醒：跌幅超过设定阈值
- 🔔 价格突破：创新高/新低

## 🎓 股票代码格式

| 市场 | 代码格式 | 示例 |
|------|----------|------|
| 沪市主板 | sh6xxxxxx | sh600519（茅台） |
| 深市主板 | sz0xxxxxx | sz000001（平安银行） |
| 创业板 | sz3xxxxxx | sz300061（旗天科技） |
| 科创板 | sh688xxx | sh688981（中芯国际） |

**小技巧：**
- 查询时可以只输数字，如 `600519`
- 分析时建议带上名称，如 `--name 贵州茅台`
