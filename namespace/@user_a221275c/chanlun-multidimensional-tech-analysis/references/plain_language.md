# 通俗化术语对照表（结论版专用）

> 供「结论速览」卡与双行人话注解引用。目标用户：股票知识有限的读者。
> 每条 = 术语（报告里出现的词）→ 人话（一眼能懂的解释）。

## 一、缠论结构（中枢 / 笔 / 线段 / 背驰 / 买卖点）

- **背驰 / 背离**：价格还在往一个方向走，但指标（如 MACD）的动能跟不上了。像「车还在往前冲，油门已经松了」——提示这段趋势可能到头、要反转。
- **中枢**：一段时间内价格上不去也下不来、来回晃荡的区间。相当于「多空拉锯区」。
- **笔**：缠论把涨跌归纳成一段段的「笔」——一笔 = 一波上涨或一波下跌。
- **线段**：若干笔连成的更大一段趋势（几波涨/几波跌拼起来）。
- **分型**：K 线凑出的一个小顶或小底，是「笔」起步的信号。
- **一类 / 二类 / 三类买卖点**：缠论定义的几种上车位置。一类=趋势刚转势的回调低点；二类=确认后的回踩点；三类=突破后的回踩确认点。人话：趋势不同阶段的「买点」。
- **中枢上移 / 下移**：上涨时每个震荡区都比前一个高=趋势强；反之=趋势弱。

## 二、K线形态

- **看涨吞没 / 看跌吞没**：一根大阳线把前一根阴线「包住」= 多头发力；反之=空头发力。
- **早晨之星 / 黄昏之星**：底部三根 K 线组合暗示跌转涨 / 涨转跌。
- **三只乌鸦 / 三白兵**：连续三根阴线（看空）/ 三根阳线（看多）。
- **锤子线 / 上吊线**：带长下影的小 K 线，暗示下方有支撑 / 上方有压力。

## 三、量价关系

- **量价齐升**：价格上涨同时成交量放大，说明上涨有「真金白银」支撑，较健康。
- **量价背离**：价格涨但成交量萎缩，上涨「底气不足」，容易回落。
- **天量 / 地量**：异常放大的成交量 / 异常萎缩的成交量，往往是阶段拐点信号。
- **量比**：当前成交量相对近期平均的倍数。>1.5 偏活跃，<0.6 偏清淡。

## 四、资金流向

- **资金流入 / 流出**：大单资金当日净买入为正 / 负。人话：大资金在进 / 在出。
- **主力净流入**：机构等大资金当日净买入金额。正=大资金买入多于卖出。
- **资金强度**：大资金态度的强弱刻度（-1~+1）。
- **价格-资金背离**：价格涨但资金在流出，或价格跌但资金在流入——信号打架，需警惕。

## 五、技术指标（MACD / KDJ / RSI / OBV）

- **MACD 金叉 / 死叉**：快慢线交叉。金叉=短线转强；死叉=短线转弱。
- **KDJ 超买 / 超卖**：指标到高位（>80）提示短期过热、可能回调；低位（<20）提示可能反弹。
- **RSI 超买 / 超卖**：类似 KDJ，>70 过热、<30 过冷。
- **OBV**：把成交量按涨跌累加的曲线。持续上行=资金在悄悄流入。
- **共振**：多个指标同时指向同一方向，信号更可信。
- **信心打分（0–10）**：综合多个指标一致性的可靠度评分。越高=信号越可信。

## 六、verdict（结论速览五档）映射规则

基于引擎 `fused_signal`（综合信号，范围约 -1~+1，缠论为锚、指标为辅）：

| fused_signal | verdict | 颜色（A股涨红跌绿） | 含义 |
|------|---------|------|------|
| > +0.5 | 强烈看多 | 深红 #c0392b | 多维强共振偏多，趋势明确，逢低积极关注但不追涨 |
| +0.2 ~ +0.5 | 看多 | 红 #e74c3c | 多维度一致偏多，可逢低关注 |
| -0.2 ~ +0.2 | 中性观望 | 灰 #888 | 信号互相抵消或偏温和，方向不明，先观察等清晰 |
| -0.5 ~ -0.2 | 看空 | 绿 #27ae60 | 多维度一致偏空，控仓谨慎 |
| < -0.5 | 强烈看空 | 深绿 #1e8449 | 多维强共振偏空，下行风险大，规避为主 |
