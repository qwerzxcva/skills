## 0. 总纲：走势必完美（L17 / L102）

- **原理一**：任何级别的任何走势类型终要完成。
- **原理二**：任何级别任何完成的走势类型，必然包含一个以上的缠中说禅走势中枢。
- 走势是"不患"的（有客观规律），根源在于人"贪嗔痴疑慢"的不患。理论不预测，只"看和干"——跟着市场合力、当下走势而行（L15）。
- 级别是关键：走势可唯一分解为 `a1A1 + a5A5 + a30A30`（1 分钟、5 分钟、30 分钟级别的递归）。一般操作 1/5/30 三级别足够，大资金加日线（L102）。
- **区间套**：因走势必完美，买卖点可被精确"区间套"定位——从大级别往小级别逐层缩小，直到最低级别确认（L61 / L104）。

## 1. 分型、笔、线段（L62 / L65 / L67）

### 1.1 K 线包含关系处理（L65）
- 用 `[di, gi]` 标记第 i 根 K 线的最低/最高区间。
- **向上**时，顺次 n 根包含关系的 K 线等价于 `[max di, max gi]` 这一根；**向下**时等价于 `[min di, min gi]`。
- **结合律 + 顺序原则**：包含关系不满足传递律。必须先用第 1、2 根确认新 K 线，再用新 K 线与第 3 根比，依次处理（不得跳步）。
- 定义（L65）：第 n 根与 n+1 根包含、与 n-1 根不包容 → 若 `gn ≥ g(n-1)` 称向上，若 `dn ≤ d(n-1)` 称向下。
- 分型识别是**唯一、客观、可当下确认**的（L67）：K 线走出来后，按定义可当下唯一找出，与时间、与人无关。

### 1.2 分型（顶分 / 底分）
- 顶分型：三根经包含处理后，中间 K 线高点最高、低点也最高。
- 底分型：中间 K 线低点最低、高点也最低。
- 中继分型与转折分型靠**是否延伸出笔**来区分（L82 心理因素）。

### 1.3 笔
- 两个相邻的顶/底分型之间，且顶底之间有至少一根独立 K 线，构成一笔。
- 笔是线段的构件；笔的端点即高低点。

### 1.4 线段（L67 / L79）
- 线段至少呈现 上—下—上 或 下—上—下，故不存在直线走平。
- **前后两线段不可能同向**（两个向上线段不能相邻）。
- 线段结束的确认：趋势中用**背驰**确认；其他情况用**盘整背驰**确认；突发用**二类买卖点**确认（L61）。
- 一字涨停无论延伸多久都低于线段级别（最小级别）（L61）。

## 2. 缠中说禅走势中枢（L18 / L20）

### 2.1 定义
> 某级别走势类型中，被**至少三个连续次级别走势类型**所重叠的部分。

- 区间公式（回升/回调形成均适用，可简化）：
  `[ZG, ZD] = [max(a2, c2), min(a1, c1)]`
  其中 A、B、C 为前三段次级别走势，高点 a1/a2/c1/c2、低点 b1/b2（与中枢同向的段方向一致）。
- **注意**：次级别前三段必须都是"完成"的走势类型，才构成该级别中枢。完成的走势类型在次级别图上很明显（L18）。

### 2.2 中枢的记号（L20）
- 与中枢方向一致的次级别走势段记为 Zn（按时间顺序），其高/低点为 gn / dn。
- `GG = max(gn)`，`G = min(gn)`，`D = max(dn)`，`DD = min(dn)`。
- `[ZD, ZG] = [max(d1,d2), min(g1,g2)]` 即中枢区间。

### 2.3 走势类型
- **盘整**：只包含一个走势中枢的完成走势类型。
- **趋势**：至少包含两个**依次同向且不重叠**中枢的完成走势类型。向上=上涨，向下=下跌。
- 趋势中相邻中枢之间必须**绝对无重叠**（L18）。

### 2.4 中枢的三种演变（L18 / L20）
| 演变 | 含义 | 对操作的意义 |
|------|------|------|
| **延伸** | 围绕中枢的波动都至少触及中枢区间，中枢可无限延续 | 中枢上只可能有卖点，不可能有买点 |
| **新生** | 产生新的同级别中枢，且与原中枢无重叠 | 趋势延续（上涨/下跌继续） |
| **扩张** | 新中枢波动触及前一中枢某瞬间区间 → 更大级别中枢 | 级别升级，原趋势级别结束 |

- **级别延续定理一**：更大级别中枢产生前，该级别走势类型延续（只能是盘整或趋势的延续）（L20）。
- **级别延续定理二**：更大级别中枢产生 ⇔ 连续两个同级别中枢的波动区间产生重叠（L20）。
- 趋势力度：相连走势类型级别越低（如跳空缺口），力度越大（L18 定理一推论）。

## 3. 背驰（L15 / L24 / L37 / L43 / L44）

### 3.1 基础
- **没有趋势，没有背驰**：盘整中无所谓背驰（L15）。背驰只发生在趋势（同向且中枢依次上/下移）中。
- **趋势力度**：前一吻结束与后一吻开始，由短期均线与长期均线相交所形成的面积。前后同向趋势中，力度比上次弱 → 背驰（L15）。
- **趋势平均力度**（即时判断）：当下与前一吻结束时，短长均线面积 ÷ 时间。一旦比上次弱即预判背驰将至（L15）。

### 3.2 MACD 辅助判断（L24 / L25）
- 背驰标准用法：黄白线（DIF/DEA）**回拉 0 轴**后，价格创新高/新低，但 MACD **红/绿柱面积**与黄白线高度**不如前一段** → 背驰（L25 示 60 后必调）。
- 区间套：大级别背驰段 → 切小级别找精确卖/买点（L24 / L61）。

### 3.3 盘整背驰（L27）
- 盘整中也可出现"盘整背驰"，常对应历史性底部/短线高低点，但**不等于趋势背驰**，安全边际不同（L27）。

### 3.4 背驰的再分辨（L37 / L43）
- 背驰分**趋势背驰**（最标准，对应趋势最后中枢）与**盘整背驰**（中枢震荡内）。
- 背驰后**不必然反转成大级别转折**：可能只是同级别中枢延伸，或更大级别盘整（L43 补习课）。

### 3.5 小级别背驰引发大级别转折（L44）
- 小级别（如 1 分钟）背驰可引发大级别（如 5 分钟/日线）转折——关键是看**小级别背驰后是否破坏大级别结构**（如出现大级别三类买卖点）。
- 实战中：小级别背驰先按小级别操作，再用大级别结构确认。

## 4. 三类买卖点（L20 / L21 / L53）

> 三类买卖点是理论**保证 100% 安全**的买卖点：点之后市场必然转折，无模糊选择（L21）。

### 4.1 第一类买卖点（趋势背驰点）
- **下跌**确立后，最后一个中枢下方出现的**趋势背驰**点 = 一类买点（L21）。
- 只在下跌走势类型中可能出现；上涨趋势确定后不再有一/二类买点，只可能有三类买点（L21）。

### 4.2 第二类买卖点
- 一类买点后，必然只出现盘整与上涨；一类后的**第二段次级别走势低点** = 二类买点（L21）。
- 二类买点不必然在中枢上或下：中枢下出现 → 力度可疑，扩张性中枢可能大；中枢上出现 → 中枢新生机会大（L21）。
- 二类与一类**不可能重合**；二类与三类**可能重合**。

### 4.3 第三类买卖点（L20 / L21）
- 一个次级别走势**突破中枢**后，其**回抽不跌回（不升回）该中枢**的区间 = 三类买卖点。
- 三类买点 = 中枢**扩张或新生**产生 → 其后必盈利（L21）。
  - 扩张 → 更大级别中枢（不诱人）
  - 新生 → 上涨趋势（诱人）
- **二三类重合**：一类后次级别凌厉上破前一下跌最后中枢，其上回抽不触及该中枢 → 二类三类重合，常预示大级别上涨（L21，1994 年 325 点案例）。

### 4.4 完备性（L21）
- 除了这三类，不存在其他被理论保证的买卖点。所有买卖点都对应"与该级别最靠近的一个中枢的关系"（L21）。
- 中枢下买点 → 转折；中枢上买点 → 延续（仅三类买点可在中枢上）。

## 5. 级别与递归（L61 / L102 / L104）

- 从 1 分钟到年线，对应 8 个级别（名称可随意取）。任何走势都可在这些级别的唯一分解中表达（L102）。
- **高级别改变必先起于低级别**：不可能 5 分钟已转折为上涨而 1 分钟还在下跌段（L102）。
- 线段与笔是更精细的分解，一般没必要；一般操作 1/5/30 三级别足够（L102）。
- 完全分类：走势必完美 → 走势可完全分类，分类有明确点位界限（数量化、精确化），当下直接显现，可控（L102 / L104）。

## 6. 均线系统的缠论解读（书2）

- 均线只是**滤除日常波动、显示大趋势**的工具；滞后性是稳定型的另一面（书2）。
- **均线流（MA flow）**：把多参数均线聚成"海浪"，站在密集均线流之上=轻松，被压在浪底=痛苦。K 线如船，均线流如海，船在水下=出事（书2）。
- **中枢 > 吻**：均线之吻（飞吻/唇吻/湿吻）是不精确的小学课程；有了中枢就不必看吻。湿吻后转折，不如直接用中枢判定（书2 / L15）。
- **背驰定真假突破**：均线粘合时所谓"支撑/压力"是否成立，唯一解在缠论——带上背驰/分型就是压力，反之是支撑（书2）。乘离率超买是否回抽，也看背驰（书2）。
- **猎杀**：利用均线缠绕粘合玩真假突破、用乘离率诱杀多头——皆是利用人性"贪嗔痴疑慢"（书2）。

## 7. 仓位与利润率最大化（L31 / L49）

- **资金管理最稳固基础**（L31）：仓位管理优先于选股；任何操作必先有资金安排。
- **利润率最大的操作模式**（L49）：大级别上涨中，成本为 0 前不断降成本，成本为 0 后不断挣筹码；震荡即降成本、增筹码的机会。最终追求"大牛市结束时持股最多且成本为 0"（L49）。
- **防狼术**（L103）：学屠龙术前先学好防狼术——在不该出手时管住手，比精准出手更重要。
