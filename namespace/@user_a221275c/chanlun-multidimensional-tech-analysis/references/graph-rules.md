## 1. 标准趋势模型：a + A + b + B + c（书1）

这是缠论最标准的**上涨趋势**形态，也是三类买卖点与背驰段比较的基准图。

```
         ┌── A ──┐        ┌── B ──┐
    a    │       │   b    │       │   c →(背驰段)
  ╱╲    │       │  ╱╲    │       │  ╱╲___
 ╱  ╲___╱       ╲╱  ╲___╱       ╲╱
```

### 元素含义与标注规范（书1 原设）
| 元素 | 书中画法 | 标准标注（本 SKILL 采用） |
|------|----------|---------------------------|
| a / b / c | 黑色线段 | 黑色实线 = 次级别（如 5 分钟）走势段 |
| A / B | 绿/红椭圆包围 | 绿色/红色椭圆 = 同级别（如 30 分钟）中枢；中枢区间 [ZD, ZG] |
| c 内部 | 紫色线段 | 紫色实线 = 更低级别（如 1 分钟）走势段，用于背驰段内部分解 |

### 三类买卖点位置（书1 / L20 / L21）
1. **一类买点**：下跌趋势最后一个中枢 **B 的下方**，c 对 b 趋势背驰处。
2. **二类买点**：一类之后，次级别回抽的**低点**（不破一类低点，或中枢下/中/上皆可）。
3. **三类买点**：b 突破中枢 B 后，**回抽不回 B 区间**（ZG~ZD）处。
   - 卖点完全对称（顶部 a+A+b+B+c 的反向结构）。

### 背驰段 c 的内部分解（书1 图2）
- c 本身可再分解为若干 1 分钟线段（紫色），整体构成一个"含 2 个 5 分钟中枢的 5 分钟顶背离段"。
- **识别要点**：c 段内部 MACD 红柱面积 / 黄白线高度 < b 段 → c 为背驰段；c 内部最后一个 5 分钟中枢的三类卖点 = 精确逃顶点。

## 2. 下跌走势类型的完全分类（书1：9 图）

书1 给出"股价从高处往下跌"的**完全分类**（9 型图示）。完全分类的思维来自 L17/L18：任何下跌都可归为以下结构之一，分类有明确界限、当下可判定。

| 类型 | 结构特征 | 操作含义 |
|------|----------|----------|
| ① 趋势下跌背驰 | ≥2 个不重叠下跌中枢，最后背驰 | 一类买点出现，趋势终完美 |
| ② 盘整下跌背驰 | 1 个下跌中枢后直接背驰反转 | 盘整背驰买点，力度弱于一买 |
| ③ 中枢延伸下跌 | 1 个中枢不断延伸，迟迟不结束 | 等待延伸结束（产生新中枢或背驰） |
| ④ 下跌+盘整+上涨 | 下跌结束后进入盘整再转涨 | 盘整下沿二买，上破三买 |
| ⑤ 下跌+盘整+下跌 | 两个中枢、未背驰 | 中继，继续下看，不抄底 |
| ⑥ 小转大 | 无标准背驰，因突发直接反转 | 用二类买卖点确认（L61） |
| ⑦ 中枢扩张下跌 | 下跌中枢扩张成更大级别 | 级别升级，原小级别下跌延续 |
| ⑧ 盘整背驰假破 | 诱空破位后拉回中枢 | 假破位=三类买点，勿杀跌 |
| ⑨ 直线跳水 | 缺口/一字快速下跌，无中枢 | 等待第一个中枢形成再研判 |

> **使用方法**：拿到一只下跌中的标的，先判它属于哪一型，再决定"等背驰 / 等三买 / 继续观望"。切忌在 ⑤⑦⑨ 型中盲目抄底。

## 3. 均线流与完全分类图读法（书2）

- **均线流（MA flow）**：多参数均线聚成"海浪"。图读法：
  - 股价站在密集均线流**之上**且均线多头排列 → 轻松区，顺势持有。
  - 股价被压在均线流**之下** → 痛苦区，等待均线流走平/粘合。
  - 均线流**粘合** = 某级别中枢构造完成或接近完成（中阴阶段，方向未定）（书2）。
- **完全分类（大盘/个股）**：用均线流的支撑/压力 + 背驰，对走势做多空完全分类，类似支撑压力但带上缠论视角（书2 / L106）。
- **真假突破判定**：均线粘合处放量突破又缩量回跌 = 真突破前洗盘；无量假突破 = 诱多（书2）。

## 4. 统一标注规范（本 SKILL 强制）

在 K 线图 / 引擎输出 / 报告中，一律按以下规范标注，确保跨标的、跨级别一致可读：

| 对象 | 颜色 / 符号 | 说明 |
|------|-------------|------|
| 次级别走势段（笔/线段） | 黑色 / 橙色细实线 | 构成 a/b/c 等 |
| 上涨中枢 | 红色椭圆（半透明） | 区间 [ZD, ZG] 标注 ZD~ZG |
| 下跌中枢 | 绿色椭圆（半透明） | 同上 |
| 背驰段 | 高亮描边（紫色） | c 段 / 顶部背离段 |
| 一类买卖点 | ★ 红（买）/ ▲ 绿（卖） | 中枢下/趋势背驰 |
| 二类买卖点 | ★ 橙（买）/ ▲ 蓝（卖） | 回抽低点/高点 |
| 三类买卖点 | ★ 金（买）/ ▲ 紫（卖） | 突破后回抽不回中枢 |
| 级别后缀 | 文本标注 | 如 "30F 三买"、"5F 背驰" |
| MACD 背离 | 图表 pin 标注 | 顶背离红 pin / 底背离绿 pin |

**规则**：
1. 中枢必标 [ZD, ZG] 数值区间；买卖点必带级别后缀。
2. 同一图只画**一个操作级别**的笔/线段；更低级别只在"背驰段"局部展开（如 c 段内紫色）。
3. 标注语言只用客观结构词（中枢/笔/线段/背驰/买卖点），不写预测性结论。

## 5. 背驰确认图读法（L15 / L24 / L25）

标准背驰确认四步（结合 MACD）：
1. **定趋势**：确认是同向、中枢依次上/下移的**趋势**（非盘整）。
2. **看回拉**：MACD 黄白线（DIF/DEA）**回拉 0 轴**。
3. **比面积**：价格创新高/低，但 MACD **红/绿柱面积**与黄白线高度**不如前一段**。
4. **区间套**：大级别背驰段 → 切小一级找精确买卖点（L61）。

> 盘整中只会有**盘整背驰**，安全边际低于趋势背驰，不可同等对待（L27）。

---

## 6. 线段结束的图读确认（L61 / L67）

- 线段结束：趋势中用**背驰**确认；其他情况用**盘整背驰**；突发用**二类买卖点**（L61）。
- 精度一致性：K 线包含处理、笔线段划分的精度（如小数点位数）必须**全程统一**，否则相邻线段划分会漂移（L61）。
- 显微镜比喻：30 分钟图找不到分型很正常，换 1 分钟图即可；看什么图与操作级别无必然关系（L67）。
