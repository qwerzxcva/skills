# 风控模块（风险边界制度化）

> 本文件是「缠论投研分析 SKILL」的**风控模块**。缠论买卖点虽"100% 安全"，但安全指的是"点之后必然转折"这一结构属性；
> 实战风险来自**级别错配、背驰失效、中阴、政策、仓位**。本模块把这些边界条件制度化。

---

## 1. 级别风控（L102 / L104）
- 风险控制在**操作级别内**绝对执行：高级别改变必先起于低级别（L102）。
- 禁止用大级别背驰结论直接做小级别重仓；必须**区间套**到操作级别确认。
- 跨级别信号矛盾时，**以小级别结构破坏**为最终止损依据。

## 2. 背驰失效 / 小转大（L43 / L44）
- 背驰后**不必然**大级别反转：可能只是同级别中枢延伸，或更大级别盘整（L43）。
- 小级别背驰引发大级别转折的关键：小级别背驰后是否破坏大级别结构（出现大级别三类买卖点）（L44）。
- **应对**：背驰先按小级别操作，用大级别结构确认再加仓；不背驰直接反转（小转大）时，用二类买卖点兜底（L61）。

## 3. 中阴阶段（L89 / L90）
- 中枢完成后的"中阴身"方向未定：可成鬼（下）也可成仙（上）（书2 / L89）。
- 中阴阶段**最难操作**：用中枢震荡手法，或以三类买卖点判真突破/假突破（书2）。
- **应对**：中阴阶段轻仓或观望，等三类买卖点明朗再动。

## 4. 政策性风险 / 防狼术（L74 / L103）
- 政策性风险无法用技术完全规避（如突发印花税、监管）（L74）。
- **防狼术**（L103）：学屠龙术前先学好防狼术——不该出手时管住手，比精准出手更重要。
- **应对**：重大事件窗口降低仓位；出现政策性利空先减仓，不赌反转。

## 5. 三类买卖点的安全边界（L21）
- 一类买点：仅下跌走势类型中出现；上涨趋势确定后不再有（只会有三类）。
- 二类买点：中枢下出现力度可疑（扩张性中枢可能大）；中枢上出现新生机会大。
- 三类买点：条件符合则**必盈利**，但扩张（更大级别中枢）不如新生（趋势）诱人（L21）。
- 二三类重合：常预示大级别上涨，但理论上不保证不扩张（L21）。

## 6. 仓位与止损纪律（L31 / L49）
- 任何操作前先有资金安排（L31）。
- 止损设于**最近支撑下方 3%**；买点失效条件 = 有效跌破最近中枢 ZD / 支撑位（现有引擎逻辑）。
- 牛市大级别上涨中：成本归 0 前降成本、归 0 后挣筹码，不为短线波动交出筹码（L49）。
- 单标的仓位上限按信号强度 + 置信度分级（现有引擎：强买 60–80%，偏买 40–60%，观望 30–50%，偏卖 20–40%，强卖 0–20%）。

## 7. 风控检查清单（每笔交易必过）
- [ ] 操作级别是否已用区间套确认到精确点？
- [ ] 背驰是否发生在**趋势**中（非盘整背驰）？
- [ ] 是否处于中阴阶段 / 政策性高风险窗口？
- [ ] 止损位与买点失效条件是否明确写出？
- [ ] 仓位是否匹配信号强度 + 置信度 + 自身资金规模？
- [ ] ETF 是否额外核对跟踪误差 / 流动性 / 折溢价（见 etf-adaptation.md）？

> 铁律：理论保证的是"结构必然转折"，不保证"你能在正确级别、正确仓位上吃到这段"。风控守的是后者。
