# 投研分析 SOP（决策模块）

> 本文件是「缠论投研分析 SKILL」的**决策模块**。把理论 + 识别转化为一套**可执行、可复用**的投研分析流程。
> 适用于个股与 ETF（ETF 差异见 etf-adaptation.md）。每一步都对应理论模块的判定规则。

---

## 总原则：完全分类思维（L17 / L102）

走势必完美 → 任一点只有两种可能：**延续** 或 **转折**。分析从一开始就要对"当下点是延续还是转折"做完全分类，不预测、只分类、跟合力。

---

## 7 步分析 SOP

### 步骤 1 ｜ 确定操作级别（L102 / L104）
- 依据**资金规模 + 性格 + 操作风格**选定操作级别（一般 1/5/30 分钟三级别；大资金加日线）。
- 明确"显微镜倍数"：用什么周期图**不决定**操作级别，但决定精度（L67）。
- ETF 偏向日/周线趋势（见 etf-adaptation.md）。
- **产出**：操作级别 L（如 30F）、观察级别（L 上下各一级）。

### 步骤 2 ｜ 获取与预处理数据
- 个股：`tdx_lookup_stock` 查名 → `pytdx`/`tdx` 拉 L 级别 K 线（≥ 当年 1.5 年约 380 根日线，或对应级别足量）。
- ETF：同上，但更关注**日/周线**（噪音小）。
- **预处理**：确认 K 线包含关系处理精度（全文统一）。

### 步骤 3 ｜ 包含处理 → 分型 → 笔 → 线段（L62 / L65 / L67）
- 严格按**顺序原则**处理 K 线包含（L65）。
- 找顶/底分型 → 连笔 → 连线段。
- **校验**：前后线段不同向；线段结束用背驰/盘整背驰/二类买卖点确认（L61）。
- **产出**：线段序列、笔序列。

### 步骤 4 ｜ 定中枢（L18 / L20）
- 用前三段次级别重叠定中枢区间 `[ZD, ZG] = [max(d1,d2), min(g1,g2)]`。
- 记录：中枢方向、ZG/ZD、GG/G/DD/D、是否完成。
- **产出**：中枢列表（含级别、区间、状态：延伸/新生/扩张）。

### 步骤 5 ｜ 判走势类型（L17 / L18 / L20）
完全分类当下走势：
- **趋势**（≥2 个同向不重叠中枢）→ 上涨 / 下跌。
- **盘整**（仅 1 个中枢）。
- 中枢**延伸 / 新生 / 扩张** 三态判定（L20 定理）。
- **当下点属性**：中枢上（延续多）/ 中枢下（转折买）/ 中枢内（震荡）。
- **产出**：当前走势类型 + 最近中枢 + 当下点相对位置。

### 步骤 6 ｜ 定位三类买卖点（L20 / L21 / L53）
- 中枢**下 + 趋势背驰** → 一类买点。
- 一类后次级别回抽低点 → 二类买点。
- 突破中枢后回抽**不回中枢区间** → 三类买点（扩张/新生）。
- 检查二三类是否**重合**（大级别上涨前兆，L21）。
- 卖点对称。
- **产出**：买卖点列表（类型 + 级别 + 价格 + 安全边际）。

### 步骤 7 ｜ 背驰确认 + 区间套精确定位（L15 / L24 / L61）
- 趋势中才谈背驰（L15）；MACD 黄白线回拉 0 轴 + 红绿柱面积比较（L24/L25）。
- 大级别背驰段 → 切小一级**区间套**到精确买卖点（L61）。
- 小级别背驰引发大级别转折：先看小级别，再用大级别结构确认（L44）。
- **产出**：背驰结论（是/否 + 级别 + 区间套精确点）。

## 决策输出模板（每标的必出）

```
【级别】操作级别 L = ___，观察级别 ___ / ___
【结构】走势类型 = 趋势(上涨/下跌) | 盘整；中枢数 = _；最近中枢 [ZD, ZG] = ___
【当下】价格位于中枢 ___（上/下/内）
【买卖点】一类@___ 二类@___ 三类@___（标注级别与安全边际）
【背驰】趋势背驰 = 是/否；MACD 红/绿柱面积比较；区间套精确点 = ___
【仓位】建议仓位 ___%（依据利润率最大模式 L49 + 级别风控）
【风控】失效条件 = ___（跌破/突破 ___ 则判断失效）
```

## 仓位管理（L31 / L49）

- **资金优先**：任何操作前先有资金安排（L31）。
- **利润率最大**：大级别上涨中，成本归 0 前降成本，归 0 后挣筹码；震荡即降成本增筹码的机会（L49）。
- **分级建仓**：买点确认后分批，止损设于最近支撑下方 3%；卖点对称（源自现有引擎策略逻辑）。
- **防狼术**：不该出手时管住手（L103）。

## 个股 vs ETF 决策差异（详 see etf-adaptation.md）
- ETF 分析"指数合力 + 成分结构"，非个股庄家博弈。
- ETF 背驰看成分股整体合力；关注跟踪误差 / 流动性 / 折溢价。
- ETF 更适日/周线，避免 min 级噪音。
