# 三层传导框架（Three-Layer Transmission）

模式 B 的核心推理方法。任何事件默认至少推 2–3 层，不只在「事件→板块→龙头」第一层停留。

## 一、三层结构

- **第一层（直接冲击）**：事件直接影响什么商品、行业、区域、公司或资产。
- **第二层（二阶传导）**：这个影响会不会传导到价格、成本、供需、利润、订单、替代、政策预期。
- **第三层（A 股优先交易段）**：这些传导里，A 股更可能先交易哪一段——硬逻辑、历史映射、还是短线情绪。

## 二、第一性原理追问（每条事件都过一遍）

- 这个事件改变了什么约束条件？是供给、需求、成本、运输、政策、技术、情绪，还是风险偏好？
- 谁先受直接影响，谁后受间接影响？
- 哪个变量最关键？价格、利润、订单、替代、库存、运费、政策预期，还是市场情绪？
- 变化沿产业链、政策链、区域链还是情绪链继续传导？
- A 股会优先交易最硬的一段，还是先交易最容易形成题材共识的一段？

## 三、按事件类型的追问侧重

### 供给扰动类（停产/断供/天气/矿难）
- 停的到底是什么产品？不要把整条产业链混成一个方向。
- 影响会不会真的传到国内价格，还是只停留在新闻层面？
- 成本端会不会对冲利好（油价、运费、汇率、原料涨价）？
- 受益的是上游资源、国内替代、价差改善，还是纯题材联想？

### 地缘 / 制裁 / 限制出口类
- 约束的是哪一段？不是国家概念就一把抓。
- 是限制供给、限制技术、限制渠道，还是只影响情绪？
- 历史上 A 股先炒哪条线，这次会不会重复？
- 谁是真正受益，谁只是名字蹭热点？

### 政策 / 规划类
- 是顶层设计还是地方试点？有无时间表与资金？
- 受益链条：直接承接方 → 设备/材料 → 运营服务，分别落在哪类公司？
- 业绩兑现节奏：主题期 → 订单期 → 业绩期，市场当前交易哪一段？

### 业绩 / 涨价 / 订单类
- 是一次性还是趋势性？量价齐升还是单因子？
- 涨价能否传导到利润（看成本结构）？
- 同业谁弹性最大（产能、市占、库存）？

## 四、输出纪律

- 不把题材联想写成确定性基本面结论。
- 若事件有连续传导，至少点明第二/第三层逻辑，不写单层板块联想。
- 无法继续推深（证据断了）时，明确写出"传导到此为止，后续需看 X 验证"，不硬编。
