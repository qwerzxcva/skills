# 联网检测与降级策略（Web & Degradation）

题材/事件研究强依赖实时检索。本文件规定联网检测、多源交叉与遇阻降级的具体做法。

## 一、联网检测（每次任务启动必须执行）

1. 自动检查当前环境是否具备联网检索工具（WebSearch / 联网搜索 / Browse 等）。
2. **有联网工具** → 正常执行，用最新公开信息填充。
3. **无联网工具** → **立即终止**，输出「缺联网工具提示」（见 SKILL.md 通用铁律），不进离线模式、不基于旧知识出卡。

## 二、优先检索源（交叉验证）

按可信度与时效组合使用，至少跨 2 类源：
- 官方：交易所公告、公司公告、监管/发改委/部委通报。
- 快讯：财联社、金十数据。
- 门户/数据：东方财富、同花顺、主流财经媒体。
- 研报：券商研报（用于产业逻辑纵深，非买卖建议）。
- 社区：仅作情绪与热度参考，不单独采信。

**采信优先级**：官方公告 > 权威媒体/快讯 > 研报逻辑 > 社区热度。结果自相矛盾时优先官方与权威媒体，并注明分歧。

## 三、降级顺序（检索不顺时不中断）

1. **平台切换**：某平台受限/需登录/动态加载失败/结果少 → 切到另一平台，或从站内搜切到公开网页搜、从新闻切到公告/快讯/专题/个股资讯页。
2. **查询改写**：原句过长或口语化 → 改搜核心主体 → 「主体+动作」→「主体+行业/商品」→「事件+A股/概念/个股/受益」。
3. **事件转方向**：直接搜不到个股 → 先搜事件影响什么行业/商品/航线/区域/政策，再搜这些方向在 A 股通常映射到哪些概念与公司。
4. **方向转个股**：方向已找到但个股不清 → 搜「方向+东方财富」「方向+同花顺」「方向+财联社」「历史类似事件+A股」。
5. **降低结论强度**：仍证据不足 → 可以分析方向不强推具体个股；可列少量高确定性票不拼长名单；明确写"当前个股映射证据不足，先观察板块方向"。
6. **透明说明限制**：最后告诉用户——哪些平台搜到了、哪些没搜到/受限、结论主要基于哪些证据、哪些部分仍不确定。

## 四、自动重试与兜底

- 单次检索超时/报错/不完整 → **自动重试最多 2 次**，每次可换关键词或换平台。
- 重试仍失败 → 输出已确认部分，卡片/表格顶部标「⚠️ 在线模式 · 部分信息因网络波动未能完全核实」，空缺项标"暂无可靠信息"，不静默输出残缺结果。
