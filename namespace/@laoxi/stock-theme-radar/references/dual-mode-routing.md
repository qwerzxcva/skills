# 双模式路由细则（Dual-Mode Routing）

本文件说明主流程「双模式自动路由」的具体判定与边界澄清规则。

## 一、判定信号表

| 输入包含 | 路由 | 说明 |
|---|---|---|
| 题材名/概念词/板块名，无具体事件 | **模式 A：题材追踪** | 如「追踪 低空经济」「梳理 银发经济 概念股」 |
| 新闻/传闻/政策变化/地缘/业绩/涨价/断供/事故，或附图片 | **模式 B：事件映射** | 如「中东冲突利好哪些 A 股」「这张图影响哪些票」 |
| 题材名 + 事件同时出现 | **模式 B**（事件为主） | 用题材词做检索锚点，如「低空经济 刚出新规，利好哪些」 |
| 过宽词（AI/科技/新能源）或意图不清 | **先澄清** | 不强行出卡 |

## 二、过宽词澄清话术

当识别到过宽描述，用一次性反问收敛，给出 2–4 个常见细分方向供选：

- 输入「AI」→ 「你说的 AI 是指 AI 算力 / AI 应用 / AI 智能体 / AI  Agent 哪个方向？确认后立刻出卡。」
- 输入「科技」→ 「科技太宽，是指半导体 / 消费电子 / 通信 / 软件 哪个细分？」
- 输入「新能源」→ 「是指光伏 / 储能 / 新能源车 / 锂电 哪个方向？」

**原则**：澄清一次即可，用户补充分支后立刻执行，不反复追问。若用户坚持要"泛泛看看"，则按通用视角出卡，并在卡顶注明"题材范围较宽，结论偏方向性"。

## 三、模式切换的产出差异

- 模式 A 产出**追踪卡**（六段结构，侧重"这个题材是什么、谁在动"）。
- 模式 B 产出**映射表**（结论清单 + 个股概率表，侧重"这件事会牵动哪些票、逻辑多硬"）。

即使同一题材，两种入口的检索重点不同：
- 模式 A 检索重心：题材定义、政策/产业催化、代表标的、近期动态。
- 模式 B 检索重心：事件本身真实性、市场当前如何解读、被反复提及的个股、历史类似事件映射。

## 四、港股/美股题材处理

用户明确给出港股/美股标的或题材名时：
- 仍走同框架，但关联标的与来源以当前可检索公开信息为准。
- 在产出顶部注明市场（如「🇭🇰 港股题材」/「🇺🇸 美股题材」）。
- A 股映射逻辑中若涉及跨市场传导（如美股 AI 龙头带动 A 股映射），单独写一句传导关系，不混为一谈。
