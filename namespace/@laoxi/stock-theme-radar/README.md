# 股票题材早知道（Stock Theme Radar）

一个能**从题材摸底、也能从事件反推**的股票题材研究助手。给题材名出「追踪卡」，给新闻/事件/截图出「映射表」，两种入口自动识别，且全程标清"哪些是硬逻辑、哪些是情绪炒作"。

> ⚠️ 本 Skill 仅用于研究性梳理，**不构成投资建议**，不代言任何标的。需联网检索工具才能运行。

## 两种模式（自动路由）

| 你输入 | 它产出 |
|---|---|
| 一个题材名/概念/板块（如「追踪 低空经济」） | **追踪卡**：一句话定义 / 驱动因素 / 关联标的 / 关键来源 / 近期动态 / 追踪建议 |
| 一条新闻/传闻/政策/截图/事件（如「中东冲突利好哪些 A 股」） | **映射表**：事件结论 + 受益/风险方向 + 三层传导链 + 个股概率表（概率/时间维度/证据强度） |

## 核心能力

- **双模式自动路由**：识别输入类型，不需要记固定格式。
- **证据强度体系**：每只标的标 `硬逻辑 / 政策驱动 / 供需传导 / 历史映射 / 纯题材联想`，硬逻辑与情绪炒作一眼分开。
- **三层传导推理**：直接冲击 → 二阶传导 → A 股优先交易段，至少推 2–3 层。
- **图片识别**：发财经截图/快讯/聊天记录，先提取事件再分析。
- **联网铁律 + 降级**：启动检测联网工具；多源交叉；平台切换/查询改写/透明降级；无联网明确终止。

## 快速开始

1. 把整个 `stock-theme-radar/` 目录作为 Skill 安装到 CodeBuddy / WorkBuddy / SkillHub。
2. 确保运行环境已开启联网搜索。
3. 直接对话，例如：
   - 「帮我追踪 低空经济」
   - 「这条新闻利好哪些 A 股：中东冲突升级，油价拉升」
   - 「短线用，梳理 银发经济，近 7 天」
   - 「帮我看这张截图影响哪些票」（附图）
