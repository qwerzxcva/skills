# 股票价值投资分析助手

> **免责声明（使用前必读）**
> - 本 Skill 仅作为投资**思考框架**与**分析脚手架**，所有输出不构成任何证券、基金、投资或交易建议。任何买卖决策须由使用者独立作出，盈亏自负。
> - 方法论源自公开资料：邱国鹭《投资中最简单的事》、帕特·多尔西《股市真规则》(The Five Rules for Successful Stock Investing)、沃伦·巴菲特/查理·芒格/段永平的公开股东信、访谈与著作。本 Skill 未经任何机构或个人授权或背书，不代表其真实观点。
> - 量化模型对假设高度敏感，金融股/A股部分模型可能不适用（`applicable=false`），此时改用定性判断，不得机械否决。

## 一、它做什么 / 不做什么

**做的事**
- 从「行业、公司、价格」三个维度做**双层评估**（量化硬模型 + 定性框架），输出"能不能买、什么价位买、风险在哪"。
- 用**反向 DCF** 反解当前价格隐含的增速，判断市场"打的什么算盘"；用 EPV、情景加权给保守底线。
- 用 **F-Score / M-Score / Z-Score / 盈余质量** 给财务质量打分，识别造假与破产风险。
- 用**杜邦分解**区分"经营赚来的 ROE"还是"杠杆堆出来的 ROE"；看 5–10 年**时间序列趋势**而非单年快照。
- 识别护城河、定价权、估值陷阱，做逆向思维检查；最后**可选请三大师把脉**。

**不做的事**
- 不预测短期股价涨跌、不做技术面（K线/均线）分析。
- 不替代用户的独立判断；不依赖任何个人持仓/组合数据——本 Skill 是通用、可独立发布的分析框架。

## 二、方法论核心

```
投资价值 = 好行业 × 好公司 × 好价格
```

三个维度缺一不可。任一维度过低，整体结论就是"不适合投资"。

**双层判断架构（本 Skill 的灵魂）**

```
            ┌─────────────────────────────────────────────┐
            │  量化层（可复现硬模型，由脚本或手算提供）    │
            │  反向DCF / EPV / 情景 / 杜邦 / ROIC           │
            │  F-Score / M-Score / Z-Score / 盈余质量      │
            │  时间序列趋势 / CAGR / 周期归一化盈利        │
            └──────────────────┬──────────────────────────┘
                               │  提供客观证据与边界
                               ▼
            ┌─────────────────────────────────────────────┐
            │  定性层（人类判断：护城河/定价权/管理层/逆向）│
            │  行业格局 / 护城河来源 / 管理层资本配置       │
            │  波特五力 / 生命周期 / 产业链 / 逆向情绪     │
            └─────────────────────────────────────────────┘
```

- **量化层定边界**：给出客观区间（如反向 DCF 隐含增速 = 12%），回答"市场已经定价了什么"。
- **定性层定方向**：判断量化结果是否合理（如"12% 增速放在成熟期消费股上明显过度乐观"）。
- **两层冲突时**：以更保守的一方为准，并在报告中显式说明分歧来源。

## 三、🔴 前置环节：取数与校验（强制，不可跳过）

> 每一条铁律违反即视为校验未通过，报告不得发布。

### 前置 1：API 优先取数（铁律 + 自动算模型）

**铁律：能用 API 绝不用网页。** 双引擎（`yfinance` + `AkShare`）是第一信源，网页抓取仅作兜底。

```bash
# 脚本为可选加速器；缺失或失败时，LLM 应基于用户上传数据或联网搜索继续分析
python scripts/fetch_stock_data.py --symbol 0700.HK --market HK
python scripts/fetch_stock_data.py --symbol 600519 --market A
python scripts/fetch_stock_data.py --symbol AAPL  --market US
```

- 脚本输出标准 JSON，含 `time_series`（5–10 年序列）与 `models`（八个量化模型自动计算）。详见 `references/data-verification-protocol.md`。
- **跨市场标的（AH/ADR）必须分别独立调用，禁止汇率换算后混用。**
- 取数后必检查 `meta.engines_used` / `errors`；两引擎都失败时报告首页 ⚠️ 标注"数据降级"。

### 前置 2：多信源数据校验（铁律）

1. **价格类数据 ≥ 3 个独立权威源**交叉验证；每个价格必标 `[数据类型 / 取数时间戳 / 币种]`。
2. **数据类型混淆是头号红线**：严禁把研报目标价 / 52 周区间 / 分析师一致预期 / DCF 估值当作"现价"。
3. **跨市场标的分别独立取数**，AH 溢价方向须从原始价格重算。

### 前置 3：信源等级强制标注（铁律）

每个定量数据必须在行内/相邻列标注信源等级，且至少 1 个二级权威以上。

| 🟢🟢🟢🟢 T0 | 🟢🟢🟢 T1 | 🟢🟢 T2 | 🟢 T3 | 🟡 T4 | 🔴 T5 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| API 直取 | 一级官方(年报/交易所) | 二级权威(彭博/财新/券商深度) | 三级参考 | 单源/弱源 | 传闻 |

报告末尾 **K.4** 必须列出所有 🟡/🔴 弱信源。

### 前置 4：近 30 天重大事件扫描（铁律）

必扫 5 类（含竞争对手动作）：① 监管/政策 ② 管理层变动 ③ 重大战略 ④ 重大诉讼/安全 ⑤ 重大合作/并购/融资。🔴 级事件须在报告首页单列专栏并显式调分。

### 前置 5：强制提取时间序列（铁律）

禁止只用单年快照评估"好公司/好价格"。报告公司模块与估值模块必须引用至少 5 年序列趋势（ROE 一致性、毛利率走向、营收/FCF CAGR、股本变化）。

## 四、五大分析模块（双层评分）

> 模块得分 = 定性框架打分；量化层用于**校准、加减分、触发一票否决**。

### 模块一：行业分析（权重 30%）

**定性四维（各 0–25，满分 100）**：行业格局 / **定价权⭐** / 需求稳定性 / 进入壁垒。增强框架：波特五力、行业生命周期、产业链议价（"收税还是交税"）、TAM/SAM/SOM。评级 A/B/C/D = 80–100 / 60–79 / 40–59 / 0–39。详见 `references/industry-framework.md`、`references/three-good-principles.md`。

### 模块二：公司分析（权重 35%）

- **2.1 护城河（定性，0–40）**：五种护城河可叠加（品牌≤10 / 成本≤8 / 转换成本≤8 / 网络效应≤8 / 牌照专利≤6），评估在加深（+5）还是被侵蚀（−5~−15）。详见 `references/moat-analysis.md`。
- **2.2 财务质量量化评分卡（脚本算，0–30）**：杜邦分解 / ROIC vs WACC / F-Score / 盈余质量。详见 `references/financial-quality-models.md`。
- **2.3 管理层 + 资本配置（定性，0–20）**：诚信/能力/股东回报/战略聚焦，并入资本配置评分卡（再投资回报、并购理性、分红回购、留存收益转化、股本稀释）。
- **2.4 时间序列校准（必做）**：引用 `time_series`，趋势恶化即使单年靓丽也扣分（上限 ±10）。

### 模块三：价格/估值分析（权重 25%）

- **3.1 估值硬模型（量化）**：反向 DCF（反解隐含增速）、情景概率加权、EPV 保守底线、分行业估值路由（金融用 PB-ROE/DDM；周期用归一化盈利；成长用反向DCF/PEG/Rule of 40；稳定用 DCF）。详见 `references/valuation-models.md`。
- **3.2 PE 是结果不是原因（定性，0–25）**：先问"为啥这个 PE 低/高"——PE<10 基本面好可能错杀，基本面差则是估值陷阱。估值陷阱清单见 `references/valuation-models.md`。
- **3.3 辅助估值 + 历史分位 + 安全边际（各 0–25）**：PB/PS/PEG 按行业选用；历史分位 20% 以下=低估；安全边际 >40% 给满分。

### 模块四：逆向投资检查（权重 5%，有加减成）

市场情绪极度恐慌且三好 OK → 逆向加分 +10%；极度狂热即使三好不错也远离。逆向三重验证（行业还好吗/公司还好吗/价格够便宜吗）三个"是"才大胆买。详见 `references/contrarian-pricing-power.md`。

### 模块五：定价权专项（权重 5%，有重大加减分）

核心问题：能不能每年默默提价、客户还没脾气？强定价权 +10% / 中 +5% / 弱 0 / 无 −10%。来源：品牌忠诚 / 产品差异化 / 转换成本 / 供给受限 / 刚需。

> **可选：大师视角会诊**。在初稿完成后，若用户要求或标的适合，调用 `references/masters-perspectives.md` 以巴菲特/芒格/段永平单视角或三方会诊给出"把脉"段，不计入分数但单列呈现。

## 五、综合评分体系

```
综合得分 = 行业分×30% + 公司分×35% + 价格分×25% + 逆向调整 + 定价权调整
```
公司分内部：护城河 40 + 财务质量 30 + 管理层/资本配置 20，并由时间序列趋势做 ±校准（上限 ±10）。

| 综合得分 | 结论 | 建议 |
|---------|------|------|
| 80–100 | ⭐强烈推荐 | 三好齐备，可重仓 |
| 70–79 | 🟢推荐 | 标准仓位买入 |
| 60–69 | 🟡可关注 | 小仓位或等更好价格 |
| 50–59 | 🟠观望 | 短板明显，跟踪暂不建仓 |
| 40–49 | 🔴不推荐 | 问题较多 |
| <40 | ❌远离 | 不符合任何价值投资条件 |

### 一票否决项

以下任一触发，无论总分多高，结论直接降为"不推荐"：

- 🚫 行业评分 < 30（夕阳行业）
- 🚫 护城河评分 < 10（毫无竞争优势）
- 🚫 财务造假/重大违规历史；管理层诚信评分 = 0
- 🚫 连续 3 年经营现金流为负；有息负债率 > 80% 且无合理解释
- 🚫 **Beneish M-Score 触发盈余操纵警示**——**前提：`models.beneish_m.applicable == True`**
- 🚫 **Altman Z-Score 落入破产高危区**——**前提：`models.altman_z.applicable == True`**

> 量化否决护栏：M/Z-Score 仅在脚本明确返回 `applicable=True` 时方可作为否决依据。金融股、缺三大报表明细的 A 股标的一律 `applicable=False`，改用定性判断，不得机械否决。

## 六、🔴 交卷前自检（强制后置，不可跳过）

三关总闸，全过才能发布：

1. **关键数据复验**：对所有进入评分的关键数字（现价/市值/PE/净利/股息率/AH 溢价/建仓区间/否决原始数据）**换源重取一次**，信源不得与前置阶段完全重叠。
2. **核心结论反验证（反向 7 问）**：① 结论是否依赖单一数据（错 10% 会反转吗）② 评分与文字是否一致 ③ 一票否决项逐条真未触发 ④ 近 30 天事件真已纳入 ⑤ 跨市场逻辑自洽 ⑥ **算术回验**（所有 A+B=C / 百分比逐条二次独立计算）⑦ 信源等级回验（弱信源未进评分）。
3. **量化层一致性复核**：报告引用的反向 DCF 隐含增速、F/M/Z-Score、杜邦分解是否与脚本 `models` 输出一致？是否存在"脚本说 not applicable 却仍下了量化结论"的越界？
4. 报告末尾显式写："本报告已通过交卷前自检（数据复验 + 反向 7 问 + 量化层一致性），可以交付。"

未通过 → 报告首行标红"⚠️ 草稿未通过自检，不得作为决策依据"。

## 十、核心原则提醒

1. 三好缺一不可——好行业、好公司、好价格。
2. 定性看方向，定量定边界——两层都过才算数。
3. 便宜是硬道理，但便宜要用模型证明——反向 DCF / 情景 / EPV。
4. PE 是结果不是原因——先看基本面，再看 PE。
5. ROE 要看是经营赚来的还是杠杆堆的——杜邦分解。
6. 定价权是最关键指标——能不能默默提价。
7. 看 5 年趋势，不看 1 年快照——时间序列一致性。
8. 会赚钱更要会花钱——资本配置能力决定长期复利。
9. 认清能力圈，看不懂就别碰。
10. 知易行难——框架给你了，执行靠自己。
