# 时间序列分析（ROE 一致性 / CAGR / 周期归一化）

> 承接 SKILL.md 前置 5「强制提取时间序列」。禁止只用单年快照评估"好公司/好价格"。
> 数据来自 `scripts/fetch_stock_data.py` 输出的 `time_series`（index 0 = 最近期）。

---

## 1. ROE 一致性（好不好公司的试金石）

- 取 5–10 年 ROE 序列，算均值与波动（标准差/极差）。
- **真好公司**：均值 >15% 且波动小（护城河稳定）。
- **不稳定**：ROE 大起大落 → 周期性强或竞争优势不稳，扣分。
- 配合杜邦看 ROE 来源是否每年一致（经营 vs 杠杆）。

---

## 2. CAGR（复合增速）

```
CAGR = (期末值 / 期初值)^(1/年数) − 1
```
- 营收 CAGR、净利 CAGR、FCF CAGR 分别算。
- 关注**质量**：增长靠提价（好）还是靠堆销量/并购（弱）？见 `three-good-principles.md`。
- FCF CAGR 持续为正且接近净利 CAGR → 利润有现金支撑。

---

## 3. 毛利率 / 净利率趋势

- 上升或平稳 → 定价权/成本优势在。
- 持续下滑 → 竞争加剧或成本失控，估值陷阱预警（见 `valuation-models.md`）。

---

## 4. 股本趋势（稀释检查）

- 股本逐年扩张 → 股东被稀释，警惕"增长靠增发"。
- 回购缩减股本 + 业绩增 → 股东友好。

---

## 5. 周期股归一化盈利

- 周期股单年 EPS 在峰/谷都失真，须用**完整周期均值**（通常 5–10 年）。
- 归一化 EPS = 周期平均 EPS；用其 × 合理 PE 得周期中性估值。
- 买在周期低谷（PE 高但归一化盈利将反转）、卖在周期峰值（PE 低但将下行）。

---

## 6. 报告引用要求

模块二 2.4、模块三必须引用至少 5 年序列，给出：ROE 均值/波动、毛利率走向、营收/净利 CAGR、FCF 趋势、股本变化。趋势恶化即使单年靓丽也扣分（±10 校准）。
