# 估值模型（反向 DCF / EPV / 情景加权 / 分行业路由 / 估值陷阱）

> 供模块三「价格/估值分析（0–25 权重）」使用。量化模型字段来自 `scripts/value_models.py` 的 `models.*`；分行业路由指导"该用哪把尺子"。

---

## 1. 反向 DCF（反解市场隐含增速）

**思路**：给定当前市值与基准自由现金流，二分法反解"市场隐含的永续增速 g"，再判断该增速是否现实。

```
企业价值 = Σ FCF_t/(1+r)^t + 永续价值/(1+r)^n
永续价值 = FCF_n × (1+g) / (r − g)
```
固定 r（折现率）、n（预测期，通常 10 年）、前段增速，反解使 EV = 当前市值的 g。

- **隐含增速低（如 <5%）** → 市场定价保守，可能便宜。
- **隐含增速高（如 >12% 放在成熟期）** → 市场已透支未来，贵。
- `applicable`：A 股缺 FCF 明细、金融股常为 false，此时用 PE/分行业路由替代，禁止强行下结论。

> **铁律**：先看反解出的隐含增速，再用定性层判断"这个增速未来 10 年做得到吗"。两层冲突以保守为准。

## 2. EPV 盈利能力价值（不依赖增长假设的底线）

```
EPV = 调整后经营利润（永续水平） / 加权平均资本成本 WACC
```
- 假设零增长，只衡量"现有资产能赚多少"。是保守估值底线。
- 若 EPV > 当前市值 → 即使不增长也便宜（强信号）。
- 适合成熟、低增长公司；成长股 EPV 会显著低估。

---

## 3. 情景概率加权估值

| 情景 | 假设 | 内在价值 | 概率 | 加权 |
|---|---|---|:---:|---|
| 乐观 | 增速/利润率上行 | V_opt | p1 | V_opt×p1 |
| 中性 | 基准假设 | V_base | p2 | V_base×p2 |
| 悲观 | 增速/利润率下行 | V_pes | p3 | V_pes×p3 |

- 期望内在价值 = Σ 加权；概率须显式给出并合理（合计 100%）。
- 安全边际用**保守值**（情景加权或 EPV 的较低者）计算，避免乐观幻觉。

---

## 4. 分行业估值路由

| 行业类型 | 首选方法 | 备注 |
|---|---|---|
| 金融（银行/保险） | PB-ROE、股息折现 DDM | 不用 DCF（FCF 难定义）；M/Z-Score 不适用 |
| 周期股 | 归一化盈利（周期平均 EPS）× 合理 PE | 用景气的均值而非峰值/谷值 |
| 成长股 | 反向 DCF / PEG / Rule of 40 | Rule of 40：营收增速% + 利润率% ≥ 40 为健康 |
| 稳定消费/公用事业 | DCF / EPV | 现金流可预测，DCF 最适用 |
| 困境/反转 | 清算价值 / 重置成本 | 看"地板"而非"天花板" |

---

## 5. 安全边际

```
安全边际 = (内在价值 − 当前价格) / 内在价值 × 100%
```
- 强护城河 ≥20% / 一般 30–40% / 高风险 ≥60%。
- 历史估值分位（5 年 PE/PB）20% 以下辅助确认"低估"。

---

## 6. 估值陷阱清单（命中即扣分并触发 M-Score 复核）

| 检查项 | 含义 |
|---|---|
| 营收连续下滑 | 需求在萎缩 |
| 毛利率持续走低 | 竞争力/定价权在丧失 |
| 行业被颠覆 | 商业模式受威胁 |
| 靠非经常性损益撑利润 | 主业不挣钱 |
| 应收账款暴增（>营收增速） | 放宽信用"做"收入 |

任一命中 → 即便 PE 低也不是便宜，而是陷阱；须复核 Beneish M-Score。

## 7. 折现率参考（分风险）

| 公司类型 | 折现率 |
|---|---|
| 强护城河稳定公司 | 9% |
| 一般公司 | 10.5% |

调整因素：规模小 +1–2%、高杠杆 +1–2%、强周期 +1–2%、管理层信任低 +1%、弱竞争优势 +1–2%、业务复杂 +1%。
