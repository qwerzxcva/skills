# 行业分析框架（波特五力 / 生命周期 / 产业链 / TAM）

> 供模块一「行业分析（0–30 权重）」增强使用，与 `three-good-principles.md` 的四维评分互补。

---

## 1. 波特五力（逐力点评 + 找决定性力量）

| 力量 | 关注点 | 行业健康信号 |
|---|---|---|
| 现有竞争 | 集中度、价格战 | 寡头格局、不打价格战 |
| 潜在进入者 | 进入壁垒 | 牌照/规模/品牌挡住新玩家 |
| 替代品 | 被颠覆风险 | 无明显替代 |
| 供应商议价 | 上游挤压 | 供应商分散、公司可切换 |
| 买方议价 | 下游压价 | 客户分散、转换成本高 |

> 必答：**哪一力主导本行业？** 例如白酒=品牌壁垒+买方弱；代工=买方极强（大客户压价）。

---

## 2. 行业生命周期

| 阶段 | 特征 | 价值投资态度 |
|---|---|---|
| 导入期 | 高增长、格局未定 | 难下手，靠定性赌赢家 |
| 成长期 | 龙头跑出 | 重点研究护城河 |
| 成熟期 | 格局清晰、现金流好 | **主战场** |
| 衰退期 | 需求萎缩 | 回避，除非极低估+清算厚 |

判断依据：渗透率、增速、盈利状态、 capex 趋势。

---

## 3. 产业链议价地位（"收税还是交税"）

- **收税型**：公司对上下游都有议价权（如拥有牌照/品牌的平台），利润不会被挤压。
- **交税型**：被上下游两头夹（如代工厂、原料受大宗绑架），利润薄且波动。
- 一句话定性并给出证据（毛利率、应付账款/应收账款结构、预付款占比）。

---

## 4. TAM / SAM / SOM（成长股必做）

- **TAM** 总可寻址市场、**SAM** 可服务市场、**SOM** 可获取份额。
- 用反向 DCF 隐含份额**反向校验**：若隐含份额远超合理 SOM → 增速不现实 → 贵。
- 成熟期行业 TAM 接近存量，重点看份额与定价权而非渗透率。

---

## 5. 行业评分联动

模块一四维（格局/定价权/需求稳定/进入壁垒，各 0–25）= 行业分（0–100）。
- ≥80 A / 60–79 B / 40–59 C / 0–39 D。
- **行业分 < 30 触发一票否决**（夕阳行业）。
- 五力/生命周期/产业链/TAM 用于支撑四维打分，不单独计分但须在报告中呈现。
