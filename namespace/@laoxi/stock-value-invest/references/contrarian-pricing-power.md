# 逆向投资与定价权（模块四 / 模块五）

> 模块四 逆向投资（权重 5%，±10% 调整）；模块五 定价权（权重 5%，±10% 调整）。

---

## 一、逆向投资检查（模块四）

**核心**：别人贪婪时恐惧，别人恐惧时贪婪——但逆向不是无脑抄底，是"市场恐慌 + 三好仍成立"才出手。

**逆向三重验证**（三个"是"才大胆买）：
1. 行业还好吗？（基本面没坏）
2. 公司还好吗？（护城河/财务没恶化）
3. 价格够便宜吗？（安全边际达标）

| 市场情绪 | 三好状态 | 调整 |
|---|---|---|
| 极度恐慌 | 三好 OK | **+10%** |
| 中性 | 三好 OK | 0 |
| 极度狂热 | 即使三好不错 | **−10%**（远离） |

> 狂热期往往是"好公司卖天价"，价值投资应让利给别人。逆向是捡便宜，不是接飞刀。

---

## 二、定价权专项（模块五）

**核心问题**：能不能每年默默提价、客户还没脾气？

| 定价权等级 | 调整 |
|---|---|
| 强（品牌/牌照/网络，提价不丢量） | **+10%** |
| 中（有一定溢价能力） | **+5%** |
| 弱（随行就市） | 0 |
| 无（价格接受者） | **−10%** |

**来源判断**：
- 品牌忠诚（茅台）
- 产品差异化（独特功能）
- 转换成本（企业软件/银行）
- 供给受限（牌照/资源）
- 刚需（公用事业/医药）

**验证方法**：过去 3 年提价幅度 vs 销量变化。提价而销量稳/增 = 强定价权；一提价量就崩 = 无定价权。

> 定价权与波特五力的"买方议价"联动：买方越强，定价权越弱。定价权是最关键的质量指标——它决定了 ROE 能否长期维持。
