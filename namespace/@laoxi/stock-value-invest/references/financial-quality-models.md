# 财务质量量化模型（杜邦 / ROIC / F / M / Z / 盈余质量）

> 本手册供模块二 2.2「财务质量量化评分卡（0–30）」使用。所有指标由 `scripts/value_models.py` 计算，报告引用 `models.*` 字段，禁止手算估计。
> 金融股、缺三大报表明细的 A 股标的，部分模型返回 `applicable=false`，改用定性判断。

---

## 1. 杜邦分解（ROE = 净利率 × 总资产周转率 × 权益乘数）

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
     = (净利/营收) × (营收/总资产) × (总资产/净资产)
```

- **经营驱动 ROE**：高净利率 + 高周转 → 健康，加分。
- **杠杆驱动 ROE**：权益乘数很高才撑起 ROE → 警惕，结合负债率扣分。
- 报告须写出三项分解值，并判定"经营驱动 vs 杠杆驱动"。

---

## 2. ROIC vs WACC（是否真正创造价值）

```
ROIC = NOPAT / 投入资本
经济利润 = (ROIC − WACC) × 投入资本
```

- ROIC 长期 > WACC → 创造价值（+）；< WACC 仍扩张 → 毁灭价值（−）。
- WACC 估算：无风险利率 + β×股权风险溢价 + 债务成本加权；成长/周期股上调。
- `applicable`：缺投入资本明细时为 false。

---

## 3. Piotroski F-Score（0–9，财务健康九项）

| # | 指标 | 得分条件 |
|---|---|---|
| 1 | ROA 为正 | 当年 ROA > 0 |
| 2 | 经营现金流为正 | CFO > 0 |
| 3 | ROA 改善 | 当年 ROA > 上年 |
| 4 | 应计项低 | CFO > 净利（现金含量） |
| 5 | 负债率下降 | 当年杠杆 < 上年 |
| 6 | 流动比率改善 | 当年 > 上年 |
| 7 | 股本未稀释 | 当年股本 ≤ 上年 |
| 8 | 毛利率改善 | 当年 > 上年 |
| 9 | 资产周转率改善 | 当年 > 上年 |

- **≥7 优秀 / 4–6 中性 / ≤3 差**。≤3 触发财务健康警告。

---

## 4. Beneish M-Score（盈余操纵识别）

```
M = −4.84 + 0.92×DSRI + 0.528×GMI + 0.404×AQI + 0.892×SGI
    + 0.115×DEPI − 0.172×SGAI + 4.679×TATA − 0.327×LVGI
```
（DSRI=应收/营收指数, GMI=毛利率指数, AQI=资产质量指数, SGI=营收增长指数, DEPI=折旧指数, SGAI=SG&A指数, TATA=应计总额/资产, LVGI=杠杆指数）

- **M > −1.78**：高概率盈余操纵警示 → 触发一票否决（须 `applicable=true`）。
- **M ≤ −1.78**：未触发。
- 金融股不适用（`applicable=false`）。

---

## 5. Altman Z-Score（破产风险）

```
Z = 1.2×X1 + 1.4×X2 + 3.3×X3 + 0.6×X4 + 1.0×X5
```
- X1=营运资本/总资产, X2=留存收益/总资产, X3=EBIT/总资产, X4=市值/负债, X5=营收/总资产

| Z 区 | 含义 |
|---|---|
| Z > 2.99 | 安全 |
| 1.81 < Z < 2.99 | 灰色区 |
| Z < 1.81 | 破产高危 → 触发一票否决（须 `applicable=true`） |

- 金融股不适用（`applicable=false`）。

---

## 6. 盈余质量（现金含量 / 应计比）

- **现金含量** = 经营现金流 / 净利润。长期 < 1 或持续下滑 → 利润"虚"。
- **应计比** = (净利 − CFO) / 总资产。越高越差。
- 配合 F-Score 第 4 项与 M-Score 第 4 项交叉验证。

---

## 7. 评分卡映射（0–30）

| 模型 | 字段 | 评分指引 |
|---|---|---|
| 杜邦 | `dupont` | 经营驱动加分；高杠杆堆 ROE 警惕 |
| ROIC vs WACC | `roic` | >WACC 加分；<WACC 仍扩张扣分 |
| F-Score | `piotroski_f` | ≥7 / 4–6 / ≤3 → 高分/中/低 |
| 盈余质量 | `earnings_quality` | 现金含量高加分；应计比高扣分 |

> 量化层只提供证据与边界；最终加减分与定性护城河/管理层判断在模块二汇总。
