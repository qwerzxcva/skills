# AI代码安全审计报告模板

> 本模板用于标准化输出代码安全审计结果，可直接复制使用。

## 审计报告概览

```
📋 审计报告概览
├── 文件/代码：{文件名或代码描述}
├── 语言/框架：{编程语言 / 框架名称}
├── 审计时间：{YYYY-MM-DD HH:MM:SS}
├── 审计模式：{在线模式/独立模式}
├── 代码行数：{X}行
├── 漏洞统计：严重{X} 高危{X} 中危{X} 低危{X} 信息{X}
└── 整体风险等级：🔴严重 / 🟠高危 / 🟡中危 / 🟢低危
```

### 风险等级划分标准

| 等级 | 说明 | 典型漏洞 | 处理时限 |
|------|------|---------|---------|
| 严重（Critical） | 远程代码执行、SQL注入、认证绕过、权限完全丧失 | RCE、SQL注入、认证绕过 | 立即修复 |
| 高危（High） | 敏感数据泄露、XSS、SSRF、文件包含 | XSS、SSRF、文件包含 | 上线前修复 |
| 中危（Medium） | 信息泄露、错误配置、CSRF | CSRF、配置错误 | 计划修复 |
| 低危（Low） | 最佳实践违背、轻微信息泄露 | 缺少速率限制 | 排期修复 |
| 信息（Info） | 代码质量建议、最佳实践提示 | 建议使用ORM | 记录跟踪 |

## 漏洞分类参考

> 下表"识别可靠度"为定性说明，**不代表经实测验证的检出率**；实际效果取决于代码质量与上下文，需人工复核。

### 注入类漏洞

| 漏洞类型 | CWE编号 | 识别可靠度（定性） | 典型特征 |
|---------|---------|-----------|---------|
| SQL注入 | CWE-89 | 较可靠（模式典型） | 用户输入直接拼接SQL语句 |
| 命令注入 | CWE-78 | 较可靠 | 用户输入传入系统命令执行函数 |
| NoSQL注入 | CWE-943 | 中等 | 用户输入直接传入NoSQL查询 |
| 代码注入 | CWE-94 | 中等 | 用户输入被作为代码执行 |
| 模板注入 | CWE-1336 | 中等 | 用户输入传入模板引擎渲染 |
| LDAP注入 | CWE-90 | 中等 | 用户输入拼接LDAP查询 |

### 认证授权类漏洞

| 漏洞类型 | CWE编号 | 识别可靠度（定性） | 典型特征 |
|---------|---------|-----------|---------|
| 弱密码 | CWE-521 | 较可靠 | 硬编码密码或弱密码策略 |
| 硬编码凭证 | CWE-798 | 较可靠 | 代码中包含密钥、token等 |
| JWT安全缺陷 | CWE-347 | 中等 | JWT验证不严格或使用弱算法 |
| 权限绕过 | CWE-285 | 需上下文（易漏报） | 缺少鉴权检查或检查不完整 |
| 会话固定 | CWE-384 | 中等 | 登录后未更新会话ID |
| CSRF | CWE-352 | 中等 | 缺少CSRF Token验证 |

### 输入验证类漏洞

| 漏洞类型 | CWE编号 | 识别可靠度（定性） | 典型特征 |
|---------|---------|-----------|---------|
| XSS跨站脚本 | CWE-79 | 较可靠 | 用户输入未转义输出到HTML |
| 文件上传漏洞 | CWE-434 | 中等 | 未验证上传文件类型和内容 |
| SSRF | CWE-918 | 中等 | 用户输入作为URL发起服务端请求 |
| 开放重定向 | CWE-601 | 中等 | 用户输入控制重定向地址 |
