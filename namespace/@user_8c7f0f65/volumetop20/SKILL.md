# SKILL.md - 成交额TOP20数据获取技能

## 技能说明

**名称**: pywencai-topvolume
**功能**: 获取同花顺问财成交额TOP20数据，包含：排名、名称、涨跌幅、成交额、同花顺行业、现价、代码
**触发词**: 成交额TOP20 / 获取成交额数据 / 问财成交额 / top20成交额

---

## 使用方法

### 1. 数据获取（必选）

每次使用需要执行以下步骤：

**步骤1**: 使用浏览器打开 https://www.iwencai.com
**步骤2**: 在搜索框输入查询语句：
```
成交额从大到小排序前20，涨跌幅，成交额，同花顺行业，现价，代码
```
**步骤3**: 获取查询结果，按成交额从大到小排列
**步骤4**: 提取每只股票的数据：排名、名称、涨跌幅、成交额、同花顺行业、现价、代码

### 2. 输出格式

**必须使用标准Markdown表格格式**，输出以下内容：

```
## 📊 成交额TOP20排名

| 排名 | 名称 | 涨跌幅 | 成交额 | 同花顺行业 | 现价 | 代码 |
|---|---|---|---|---|---|---|
| 1 | 新易盛 | -2.10% | 134.37亿 | 通信-通信设备 | 447.41 | 300502 |
...
```

### 3. 板块统计计算

获取数据后，需要计算板块统计：

1. 按一级行业分类统计数量、占比、成交额合计、平均涨跌幅
2. 按成交额从大到小排序
3. 列出代表股票

```
## 📈 板块分布统计

| 板块 | 数量 | 占比 | 成交额 | 均涨幅 | 代表股票 |
|---|---|---|---|---|---|
| 通信设备 | 4只 | 20% | 364.49亿 | -0.20% | 新易盛/中际旭创/天孚通信/亨通光电 |
...
```

### 4. 板块分析

根据板块涨跌幅和成交额，给出评级和逻辑分析：

```
## 🎯 板块分析

| 板块 | 评级 | 逻辑 | 风险提示 |
|---|---|---|---|
| 通信设备/CPO | ⭐⭐⭐ | 成交额最大但今日调整 | 短期涨幅过大 |
...
```

### 5. 数据对比（如需要）

与上次数据对比，检测新增和退出：

- 新进TOP20的股票
- 退出TOP20的股票
- 数据变化提醒

---

## 示例查询

**用户说**: "获取今天的成交额TOP20数据"

**AI执行**:
1. 打开浏览器访问问财
2. 输入查询语句
3. 获取20只股票数据
4. 按标准Markdown格式输出表格
5. 计算板块统计
6. 给出板块分析

---

## 数据字段说明

| 字段 | 说明 |
|------|------|
| 排名 | 按成交额从大到小排序 |
| 名称 | 股票简称 |
| 涨跌幅 | 当日涨跌幅(%) |
| 成交额 | 当日成交额(亿) |
| 同花顺行业 | 三级行业分类 |
| 现价 | 最新收盘价 |
| 代码 | 股票代码 |

---

## 注意事项

1. ⚠️ 需要登录问财账号才能获取完整数据
2. 📅 数据为上一交易日数据（非实时）
3. 🔄 每次查询需要重新获取最新数据
4. 💾 可保存到文件或直接展示给用户
5. 📱 支持推送到微信等平台
