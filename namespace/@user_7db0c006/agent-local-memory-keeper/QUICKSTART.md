# 极简上手 · AI Agent 记忆系统（2 分钟）

> 这是**最短入口**。完整规则与全部命令见 `SKILL.md` + `references/COMMANDS.md`。
> 你**永远不用记命令、不用看输出**——对 AI 说人话即可。

## 你只需要会三句话

| 你想做什么 | 对 AI 说 | 背后命令 |
|---|---|---|
| 存一条经验（踩过的坑 / 验证过的最佳实践） | 「记一下…」 | `deposit` |
| 找之前记过的某条 | 「找一下之前那个…」 | `recall`（语义召回，换说法也能找回） |
| 整理今天记的（去重/纠错/归档） | 「帮我整理今天记的」 | `reflect --auto`（**永远 0 删除**，只归档沉底可找回） |

## 一眼看清：默认就有 / 一句话开 / 需手动开

> 新手最容易混淆「必须装」和「可选装」——其实**绝大多数能力装完即用，只有 2 项需要额外动作**。下表每项都附一句「照抄就能用」的对话实操：

| 分类 | 能力 | 对 AI 说（照抄即可） |
|---|---|---|
| ✅ **默认就有（零配置）** | 记 / 找 / 整理、中文语义召回、自动分类分层、反馈校准、会话结束自动沉淀、每周自动维护 | 「记一下…」「找一下之前那个…」「帮我整理今天记的」；其余自动运行，想看状态说「看看记忆系统状态」 |
| 🔧 **一句话就能开（无配置）** | Dashboard 看板、矛盾修复、聚类、蒸馏原则、关系图谱、`self-heal` 保养 | 「出一张可视化看板」「查查有没有矛盾」「把相似记忆聚个类」「蒸馏成一条原则」「建关系图谱」「帮我整体保养一遍」 |
| 🔒 **需手动开 + 配置（仅 2 项）** | ① IMA 云端同步（需连 IMA 知识库）② 本地 LLM/Ollama（~5GB，吃资源） | 「配 IMA 知识库同步」/「开本地 Ollama 离线增强」 |

> 🔒 **为什么后 2 项故意默认不开**：IMA 会把记忆推上云（推送前强制脱敏，但仍是云端）、Ollama 要下 ~5GB 模型常驻吃内存——不是不好，是要你知情后再开。

### ⚠️ 两条隐藏边界（新手容易忽略，但很重要）

- **🟡 召回质量取决于语义后端（最大的隐性坑）**：**默认就是语义后端**（`fastembed`，首次用到时自动下载约 90MB 模型，之后完全离线），「换种说法问同一件事」也能召回（约 90%+）。但它**会静默降级**——模型下载失败（网络不通 / `HF_ENDPOINT` 缺 `https://` 前缀等）时自动退回词法级，功能看起来正常，但换说法的召回率掉到约 30%，且不报错。**判断自己是不是降级态**：对 AI 说「看看语义后端状态」，看 `doctor` 里的 `fell_back_to_lexical` 是否为 `false`。
- **🟢 "整理"永不删记忆**：`reflect` / `decay` / `archive` 永远是归档沉底、可 `recall --deep` 找回；唯一真删是显式 `delete --yes`。放心用。

> 📌 **完整「❌ 错误做法 → ✅ 正确做法」清单**（例如：把整段对话原文灌进记忆、拿 `delete --yes` 当常规清理、手动改 `memories/*.json`）——完整清单见 `SKILL.md` 顶部「🔴 先读 3 条」与「📌 反模式清单」（单一真源）。
>
> 🗺️ **所有能力一张图看全**（含"整体保养""配云端同步"等高级触发）：见 `references/CAPABILITY_MAP.md`。扫一眼就知道还能让 AI 帮你做什么。

## 五个新能力（一句话触发）

- **跨工具分享**：「把记忆导出成可分享的 learnings 文件」 → `export --format learnings`
  （每条记忆一个 `.md`，git 可 diff，任意支持 `.learnings/` 的工具都能读）
- **经验变 skill**：「把高频经验萃取成一个可复用 skill 脚手架」 → `extract-skill`
  （生成 `SKILL.md` + `references/` + `hooks/`，再用 skill-creator 打磨成正式 skill）
- **溢出到别的 AI 助手**：「把行为规则固化给 GitHub Copilot / Claude」 → `export-rules --rules-target copilot|claude`
  （高频/已确认经验直接成为 Copilot / Claude Code 每轮的行为规则）
- **自动养护**：「帮我把记忆系统整体保养一遍」 → `self-heal [--force]`
  （一键跑完去重/进化/降权/自愈/同步 skill 与行为规则；默认脏驱动、建议每日或调度跑；`--force` 强制全量）
- **看全部命令**：「看所有可用命令」 → `commands`（或 `quickstart` 看极简指引）

## 什么时候该用

- ✅ 沉淀**经验**：坑、纠正过的结论、反复验证的做法。不是录像带，不搬整段对话。
- ✅ 想让 AI **下次不犯同样的错**（行为规则固化）、想**跨工具 / 跨会话 / 跨团队共享**沉淀。

## 装完 / 更新完都要跑一次（激活钩子/守护/自动记忆）

对 AI 说「**帮我一键配好**」，或自己跑一条命令：

```bash
python scripts/keeper_setup.py all
```

装后跑 `doctor` 即可验证是否就绪。🔴 **更新完也要重跑一次**——钩子等部署物不随技能更新自动刷新，不重跑会一直用旧版。

> 🪟 **界面闪「执行中」提示条不是报错**：那是 WorkBuddy 的钩子执行指示器（本 skill 的钩子在后台工作，平台固有行为）。嫌它闪 → 对 AI 说「关掉弹窗」切到 `silent`（默认无弹窗）。
