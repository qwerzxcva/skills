# 能力总图 · 你能让记忆系统做什么（一张图看全）

> **给普通用户**：不用记命令、不用读文档。下面每一项，直接**对 AI 说左边那句话**即可，AI 在后台替你跑对应命令。
> 本表把所有能力收敛到一页——扫一眼就知道"哦，原来还能『整体保养一遍』『配云端同步』『导出给 IMA』"。
> 更细的命令参数、排错索引见 `COMMANDS.md` / `MEM_BRIDGE.md` / `QA.md`（那是给 AI 查的后台资料，你无需通读）。

图例：**✅ 默认就有**（装完即能用）｜**🔧 需先开**（跑一次"帮我一键配好"或对应 setup）｜**🔒 需条件**（IMA 知识库 ID / 神经后端 / DuckDB 等）

## 一、日常核心（✅ 默认就有，记/找/整理）

| 能力 | 对 AI 说什么（一句话触发） | 状态 | 备注 |
|---|---|---|---|
| 记一条经验 | "记一下：金蝶导出用网页版最稳" | ✅ | 自然语言即可，自动分类 |
| 找经验 | "之前关于 skillhub 发布的坑是什么？" | ✅ | 语义召回，中文开箱即用 |
| 纠正旧结论 | "那条结论错了，更正为…" | ✅ | 旧记忆自动标记 superseded，不删 |
| 整理去重纠错 | "帮我整理一下今天的记忆" | ✅ | `reflect --auto`，不删内容 |
| 定期降权冷记忆 | "把老记忆降降权重" | ✅ | `decay --apply` |
| 标为核心原则 | "这条很重要，标核心" | ✅ | `promote --tier core` |
| 关联两条记忆 | "把 A 和 B 关联起来" | ✅ | `link --rel see_also` |
| 删（先归档可找回） | "这条不想要了" | ✅ | 先 `archive`（可找回）；真删 `delete --yes` **不可逆** |
| 看单条为何被召回 | "为什么召回了这条？" | ✅ | `explain --id <id>` |
| 导出备份 | "把记忆导出成 Markdown" | ✅ | `export --format md`（**默认仅 active**，全量加 `--include-archived`） |
| **自动记忆（钩子）** | "开自动记忆" | ✅ | **装后首次跑任意命令即自动注册**（幂等；**重启 WorkBuddy 生效**）；想停说"关掉自动记忆" |
| **看「AI 最近自动记了什么」** | "你最近自动记了什么？给我看看" | ✅ | `working --top 20`（还没回流的活跃经验）；自动暂存项 `confirm --id <id>` 放行入库；命中 secrets 的待复审项 `list_quarantine` / `review_quarantine --id <qid> --action release` |
| **搬到另一台电脑 / 跨设备同步** | "把记忆同步到我另一台电脑" | ✅ | `scripts/keeper_sync.py out` / `in --execute`（合并式，**保留目标机新记忆**）；整库克隆改用 `backup`→`restore --yes`（覆盖式，会丢目标机新记忆）。详见 `QA.md` Q12 |

## 二、体检 / 保养（✅ 默认就有，运维自治）

| 能力 | 对 AI 说什么 | 状态 | 备注 |
|---|---|---|---|
| **整体保养一遍** | **"帮我把记忆系统整体保养一遍"** | ✅ | `self-heal`：合并去重/进化/降权/自愈/同步规则，建议每日或定时跑 |
| 看库的整体状况 | "看看库的整体状况 / 还能开哪些功能" | ✅ | `doctor`（就绪绿红自检）+ `audit`（能力体检+开关建议） |
| 召回分布 / 健康摘要 | "给我出个记忆看板" | ✅ | `report` / `stats` |
| 矛盾 / 重复扫描 | "看看有没有重复矛盾" | 🔧 | `doctor --contradictions`（需神经后端；大库放低频） |
| 一键跑完整自治循环 | "跑一次完整自治" | ✅ | `self-heal [--force]`（强制全量） |
| 索引漂移自检修复 | "索引和文件对不上" | ✅ | `doctor --fix`（以文件为准回填） |

## 四、需要"先开"或"有条件"的能力（🔧🔒）

| 能力 | 对 AI 说什么 | 状态 | 前置条件 |
|---|---|---|---|
| 守护进程常驻（更快召回） | "开守护进程模式" | 🔧 | 跑"帮我一键配好"（`keeper_setup.py hooks --scheduler`）；**停止请用 AI 说"关掉守护进程"，别手动 kill**，避免残留 |
| 一键配好全部 | "帮我一键配好记忆系统" | 🔧 | 装后跑一次即可激活钩子/守护/中文语义 |
| 配 IMA 云端同步 | "把记忆同步到 IMA 知识库" | 🔒 | 需 IMA 知识库 ID（`keeper_setup.py ima --kb-id <ID>`）；同步是"导出脱敏+生成推送指令"，入库由 AI 经 IMA 完成 |
| 导出给 IMA（推送指令） | "把记忆推到 IMA" | 🔒 | 同上；脱敏复检通过才给出可贴指令 |
| 回流原则到 WorkBuddy | "把核心原则写回 WB 记忆" | 🔧 | `distill-to-wb`（单向蒸馏，幂等不重复） |
| 导出 L2 草稿 | "导出高价值经验成 L2 草稿" | 🔧 | `mem_bridge.py to-l2`（默认只预览，不写盘） |
| 投资记忆闭环校验 | "校验投资记忆数值对不对" | 🔒 | 需 DuckDB（`verify-investment`） |
| 配 Ollama 本地大模型 | "用 Ollama 做语义" | 🔒 | 低配机器**不建议**（吃资源） |

## 五、遇到问题怎么办（✅ 默认就有）

| 场景 | 对 AI 说什么 |
|---|---|
| 记不进去了 | "记不进去了" |
| 找不到了 | "找不到了" |
| 召回降级了 | "embedding 降级了" |
| 自动记没生效 | "自动记没生效" |
| 数据不同步 | "数据不同步" |

> AI 会先跑 `doctor`+`audit` 读真实状态、定位原因，用**大白话**告诉你问题在哪 + 问你一个澄清问题 + 给修复命令，你确认后它直接执行。**你不用看懂任何技术报错。**
