# 术语大白话表（看到黑话查这里）

> 这份表只做一件事：**把 skill 文档里的技术黑话翻译成人话**。
> 你不需要记住任何术语——日常只要会说「记一下…」「找一下…」「整理一下」就够了。
> 这份表是给「不小心看到了不懂的词」或「想排查问题」时查的。

---

## 一、召回 / 搜索（找记忆）

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| **语义召回** | 按「意思」找，不是按「字面」。你说「接口很慢」，它能找出记的是「API 响应延迟高」 | 想找一条记过但说法不同的经验 |
| **词法召回** | 按「字面字符重叠」找。说法一换就找不到了 | **这是降级态**，不是正常态。默认本该是语义召回 |
| **降级 / 静默降级** | 语义模型没装上，系统悄悄退回词法级，**不报错**，但「换说法就搜不到」（召回率 ~90% → ~30%） | 「明明记过却搜不到」多半是这个 |
| `fell_back_to_lexical` | 体检报告里的一行字。**`false` = 正常（在用语义）；`true` = 已降级** | 跑 `doctor` 时判断自己有没有中招 |
| **向量 / embedding** | 把一段文字变成一串数字，意思相近的文字数字也相近，这样才能按「意思」找 | 提到「90MB 模型」「重嵌」时 |
| **embedding 覆盖率 / coverage.rate** | 库里有多少记忆已经算好了向量。**正常应为 1.0（100%）** | 跑 `doctor` 看体检 |
| **RRF（多信号融合）** | 把「语义像不像 + 关键词重不重叠 + 最近用没用过」几路结果混在一起排序，比单看一路准 | 想知道「为什么这条排在前面」 |
| **ANN（近似最近邻）** | 记忆多了以后，不再逐条比对，而是先粗筛再细比，更快。**库 ≥50 条自动开，小库反而更慢所以不开** | 库大了以后召回变快 |
| **改写 query 也能召回** | 就是「换种说法问同一件事也能找到」 | 语义召回正常时的表现 |

## 二、存储 / 数据

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| `store/index.db`（SQLite） | 真正的记忆主库（一个数据库文件） | 备份、迁移时 |
| `memories/*.json` | 与数据库**双向同步**的人可读副本，方便你用眼睛看、用 git 管 | 想直接看记忆内容时 |
| `index.json` | 兜底导出。数据库坏了靠它重建 | 几乎不用管 |
| **WAL** | SQLite 的写入机制。所以**别直接复制数据库文件**，会拷出撕裂的半成品 → 用 `backup` 导出 ZIP | 跨设备迁移 |
| **权威源 / 真源** | 以哪个为准。现在以 `index.db` 为准 | 出现「不一致」时 |
| **--flat 模式** | 极简模式：跳过数据库，全落成 Markdown 文件。**代价：没有语义召回** | 只想记个坑、不想装任何东西 |
| **指纹 fingerprint** | 给内容/模型算的一个校验值，用来判断「有没有变过」。变了就重算 | 看到 `#<数字>` 这类后缀时 |
| **漂移** | 数据库和 JSON 副本对不上了。`doctor --fix` 能修 | 手动改过文件后 |

## 三、整理 / 生命周期（记忆的一生）

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| `reflect`（自整理） | 去重 / 纠错 / 晋升 / 归档。**永远 0 删除** | 说「帮我整理一下」 |
| `decay`（沉底 / 降权） | 长期不用的记忆自动降权重、排后面，**不删**，`recall --deep` 还能找回 | 库越来越大、想保持清爽 |
| `archive`（归档） | 软删除：沉到 `archive/` 目录，**随时可找回** | 想清理但怕误删 |
| `superseded`（被取代） | 这条被更新的结论替代了，旧的标记一下但**保留**，可回溯 | 纠正过旧结论后 |
| `promote`（晋升） | 把常用/重要的记忆提为「核心」，召回时优先 | 某条经验特别有用 |
| `distill`（蒸馏） | 把一堆相似记忆提炼成一条通用原则 | 库里同一主题记了很多条 |
| `evolve`（自进化） | 反复被印证的做法，自动提炼成原则（带复核期限） | 想让记忆自己长出结论 |
| **复述加权 rehearsal** | 被反复召回的记忆会自动提权——用得多的更靠前 | 无需操作，默认行为 |
| **冷热分层 / 热量 heat** | 常用的「热」记忆优先，长期不用的「冷」记忆沉底 | 无需操作 |
| **信念强度 belief_strength** | 系统对这条记忆「有多确信」。你回 `good` 加分、`bad` 减分 | 召回后 AI 问「这条有用吗」 |
| `forget`（判错归档） | 明确标记「这条是错的」，停止召回，**内容不删** | 发现某条记错了 |
| **版本 / 快照 / 回滚** | 每次改记忆都会自动留档，可退回历史版本 | 改坏了想撤回 |
| **写入门禁 write_gate** | 覆盖旧内容前必须先留快照，留不下就**中止写入**，防止内容凭空消失 | 无需操作，默认保护 |

## 四、安全

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| `quarantine`（隔离区） | 疑似含密码/密钥的内容**先隔离待你复审**，绝不静默写进库 | 记了含敏感信息的内容 |
| **fail-closed** | 出问题时**选择停下并报错**，而不是硬着头皮继续（安全侧优先） | 写入门禁拦下覆盖、索引不一致时报错 |
| **fail-open** | 出问题时**继续运行但功能打折**（如降级为词法）。好处是不中断，坏处是静默 | 语义模型挂了时的行为 |
| **脱敏** | 推送到云端前自动抹掉密码、真实路径、邮箱 | 配 IMA 同步时 |

## 五、系统 / 运维

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| **钩子 hook** | 在特定时机（如会话结束、命令出错）自动触发的小脚本 | 想要「自动记忆」 |
| **守护进程 daemon** | 常驻后台的进程，让模型不反复加载、召回更快。**可选，不是必需** | 嫌召回慢 |
| **silent 模式** | 钩子默默干活、不弹提示条。**默认就是这个** | 嫌弹窗烦（默认已无弹窗） |
| **注入 inject** | 每轮对话自动把相关记忆塞进上下文。**默认关**，靠 AI 按需召回 | 想要「保证浮现」 |
| **自反馈闸门** | 防止 AI 反复问你「对不对」的限流开关（每会话上限） | AI 陷入反复确认时 |
| **幂等** | 同一个操作重复跑几次，结果都一样、不会重复写入 | 同步、导入时 |
| **dry-run（预演）** | 先跑一遍给你看「会改什么」，**不真改**。加 `--apply`/`--execute` 才落盘 | 不确定后果时 |
| **taxonomy（分类法）** | 记忆的分类体系（类别 / 场景 / 四轴 / 状态） | 想规划分类 |
| **域隔离** | 不同领域（如投资 vs 编程）的记忆分开管理，互不串味 | 多领域混用时 |
| **MCP** | 把记忆库暴露成一个服务，给别的 AI 工具（Claude Desktop / Cursor）连 | 跨工具使用 |
| **IMA 同步** | 把归档记忆镜像到 IMA 知识库（**强制脱敏**） | 想跨工具/跨会话共享 |

## 六、投资域专属

| 黑话 | 大白话 | 你什么时候会碰到 |
|---|---|---|
| `verify-investment` | 从本地 DuckDB 数据库**重新算一遍**数值，校验你记的投资结论对不对 | 记了投资指标后 |
| `needs_setup` | 本该校验但条件不齐（缺数据库或 SQL 映射），**明确标出来而不是假装通过** | 校验报告里 |
| `validated_by` | 这条结论的测试证据链。缺了会在体检里作**可选提示**（hints，非违规） | 投资记忆体检 |

## 遇到问题但不知道叫什么？

| 你的感觉 | 大概率是这个 | 一句话行动 |
|---|---|---|
| 「明明记过却搜不到」 | 语义降级为词法 | 对 AI 说「看看语义后端状态」 |
| 「AI 反复问我确不确认」 | 自反馈闸门 | 说「不用校准」 |
| 「记忆是不是少了」 | 多半是归档沉底，不是删了 | `recall --deep` 找回 |
| 「每次发送都闪一下」 | 钩子弹窗（full 模式） | 说「关掉弹窗」切 silent |
| 「换台电脑记忆没了」 | 存储路径没跟着走 | 设 `AI_MEMORY_STORE` 或用 `keeper_sync.py` |
