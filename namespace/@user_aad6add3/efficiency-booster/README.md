# 效率提升器 (Efficiency Booster)

帮助用户提高做事效率的系统性思维工具。通过"目标-路径-资源-复盘"四步闭环框架，从逻辑思考角度提升执行效率。

## 核心理念

**更聪明地思考，更高效地执行。**

方向对了，慢也是快；方向错了，快也是慢。

## 四步闭环框架

| 步骤 | 核心目标 | 关键工具 | 关键产出 |
|------|---------|---------|---------|
| 1️⃣ **界定** | 做正确的事 | 5W1H、逆向思维 | 问题界定报告 |
| 2️⃣ **拆解** | 降低启动门槛 | WBS、MECE | 任务拆解清单 |
| 3️⃣ **优化** | 寻找最优解 | 二八定律、止损点 | 路径优化方案 |
| 4️⃣ **复盘** | 建立正向反馈 | PDCA、归因分析 | 复盘报告+SOP |

## 第一步：界定问题 (Clarify)

### 5W1H 提问法

- **Why (目的)**：这件事的最终价值是什么？
- **What (标准)**：什么算"做完"？什么算"做好"？
- **Who (责任)**：谁对结果负责？
- **When (节点)**：截止日期是什么？
- **Where (边界)**：资源范围在哪里？
- **How (方法)**：用什么方法做？

### 逆向思维
- 设想最坏的结果
- 如果无法接受，立即停止或调整

## 第二步：拆解任务 (Deconstruct)

### WBS 工作分解结构
将大任务拆解为"无需思考即可执行"的动作。

### MECE 原则
- **M**utually **E**xclusive：相互独立
- **C**ollectively **E**xhaustive：完全穷尽

## 第三步：优化路径 (Optimize)

### 二八定律
找出20%决定80%结果的核心任务，聚焦主要精力。

### 剔除假动作
- 过度准备
- 完美主义
- 逃避行为
- 虚假忙碌

### 设定止损点
对于不确定的任务，设定时间上限，避免死胡同。

## 第四步：动态复盘 (Review)

### PDCA 循环
- **P**lan：计划
- **D**o：执行
- **C**heck：检查
- **A**ct：处理

### 归因分析
- 能力问题 → 学习培训
- 态度问题 → 重新评估
- 环境问题 → 改善环境
- 方法问题 → 优化流程
- 资源问题 → 申请资源

## 快速思考清单

做事前，过一遍这四点：

1. **定目标**：这件事的终局是什么？（Why & What）
2. **拆动作**：第一步能做什么？（Actionable）
3. **排优先级**：哪件事价值最大？（80/20）
4. **看结果**：做完这一步离目标更近了吗？（Feedback）

## 输出成果

**Word文档格式的效率提升方案**，包含：

1. 📄 **封面** - 标题、任务名称、日期
2. 🎯 **问题界定报告** - 5W1H分析、最坏结果检验
3. 📋 **任务拆解清单** - WBS分解、MECE检查
4. ⚡ **路径优化方案** - 二八分析、假动作剔除、止损点
5. 🔄 **动态复盘机制** - PDCA、归因分析
6. 📖 **执行手册** - 快速思考清单、工具模板

## 使用方法

### 1. 安装依赖

```bash
python scripts/install_dependencies.py
```

### 2. 准备数据文件

创建JSON文件，包含四步分析内容。参考 `examples/writing_example.json`

### 3. 生成报告

```bash
python scripts/generate_report.py data.json 效率提升方案.docx
```

## 示例

### 提升写作效率


## 使用场景

- 面对复杂任务不知从何下手
- 感觉忙碌但产出不高
- 项目总是延期
- 想建立个人效率系统
- 团队协作效率低下
- 学习或工作中陷入"假努力"

## 使用建议

1. **先界定再执行**：确保方向正确
2. **拆解到可执行**：任务粒度要细
3. **聚焦核心价值**：80%精力投入20%核心任务
4. **及时止损**：不要在死胡同里浪费时间
5. **持续复盘**：每次任务后都进行复盘
