# 事实查证能力

使用 `tencent-news-cli` 的腾讯较真能力，判断具体说法、资讯、事件或常识的真实性、准确性与可靠性。

## 执行流程

1. 先执行 `sh scripts/run-cli.sh help jiaozhen`；Windows 使用 `powershell scripts/run-cli.ps1 help jiaozhen`。
2. 从当前帮助中选择最匹配的查证命令，并严格按帮助传入命题或文本：
   - 长文本、文章或聊天记录：优先使用整段内容查证能力；当前帮助没有时，提炼 1–3 条核心可核查命题分别执行。
   - 图片或截图：先用视觉理解提取文字和关键信息，再提炼可核查命题；无法清晰识别时请用户提供清晰图片或可复制文本。
   - 当前帮助没有匹配命令时，如实说明当前 CLI 不支持该场景。
3. 所有实际 CLI 调用都通过 `run-cli`，不得直接执行 `platform.cliPath`。命令、参数名、参数顺序和 `--jiaozhen` 的位置均以当前帮助为准，不得猜测。
4. 将 CLI 返回的完整 markdown 作为最终答复主体直接展示。

## 输出规则

- 完整保留 CLI 原文中的 `【查证结论】`、`【查证过程】`、`【查证结论信心评估】`、来源编号、来源标题和来源链接等全部内容。
- 不重新组织、摘要、改写或只提炼结论；不自行补充外部信息或伪造链接。
- 不要把原文藏在“根据查证结果”等转述之后，应直接展示 CLI 返回内容。
- 如确需补充一句说明，只能放在 CLI 原文之后，且不能替代原文。

## CLI 失败处理

CLI 输出为空、非零退出、超时或直接报错时立即停止，不重试、不诊断为其他原因、不换其他数据源继续查证。

1. 优先视为当天 3 次查证额度已用完。
2. 明确告诉用户：当前 CLI 结果为空或执行失败，通常表示今天的较真查证额度已经用完。
3. 引导用户前往 [较真AI-智能查证](https://view.inews.qq.com/ai/agent/UTR2025041800262600?no-redirect=1) 继续查证。
