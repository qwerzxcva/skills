# 天气预警能力

使用 `tencent-news-cli` 当前提供的天气能力，对某地预警或异常天气进行一次性查询。

> 本能力只做“问一次、查一次、答一次”，不提供预警订阅、定时检查或主动推送。单次意图只调用必要的业务查询一次；失败、超时或空结果时不重试、不使用替代数据源。

## 动态发现

每次查询都按当前 CLI 能力执行：

1. 执行 `sh scripts/run-cli.sh help`，定位与天气、气象、预警或灾害天气相关的命令。
2. 执行 `sh scripts/run-cli.sh help <天气命令>`，读取真实用法、参数、地点输入方式和示例。
3. 仅当帮助明确显示预警子命令或参数时，才继续读取相应下一层帮助；不得尝试未显示的命令、参数或值。
4. 当前 CLI 没有可用于天气预警或综合天气结果的能力时，说明“当前 CLI 版本未提供天气预警查询能力”，不做探测性调用。

截至 2026-08-14 核实（CLI v1.0.15），CLI 没有独立预警子命令或参数，仅有统一的 `weather --adcode`；预警只在地点存在生效预警时作为综合结果的独立分段返回。该信息仅供理解，每次仍须重新读取帮助。某次结果没有预警分段并不表示 CLI 不支持预警。

## 类型识别

以下类型只用于理解用户意图和筛选实际返回，除非当前帮助明确支持，否则不得作为 CLI 参数：

| 类型 | 匹配范围 |
|---|---|
| 雨天 | 中雨、大雨、暴雨、大暴雨、特大暴雨、雷阵雨伴冰雹、雨夹雪 |
| 雪天 | 小雪、中雪、大雪、暴雪 |
| 雾霾 | 沙尘暴、强沙尘暴、扬沙、霾、强浓雾、特强浓雾等 |
| 空气质量 | AQI 重度污染预警 |
| 寒潮 | 大幅降温 |
| 高温 | 38°C 高温 |
| 台风 | 台风路径及影响 |

用户笼统询问异常天气时，不预设类型，展示 CLI 实际返回的全部预警/异常天气。

## 查询规则

- 严格按当前帮助组装命令、参数名、顺序和地点格式；用户地点无法映射到支持格式时，先请用户补充。
- 未指定类型时查询全部预警；指定多个类型时优先用一次综合请求后本地筛选，只有帮助明确要求时才拆分必要请求。
- 帮助读取完成后不重复读取；每个业务意图只实际查询一次。
- 只从 CLI 输出中提取预警。没有预警分段或没有匹配项时，说明当前未查询到匹配的有效天气预警，不推断未来安全、不补充外部信息。
- 用户要求订阅、提醒、定时检查或主动通知时，明确当前不支持；建议需要时再次主动询问，不创建任何定时任务。

## 输出规则

- CLI 返回可读文本或 markdown 时原样输出，不删减影响范围、防范建议或信息来源等任何预警正文。
- 结构化结果按地点和预警分别展示实际字段可映射的信息，如颜色等级、编号、类型、发布单位与时间、正文、来源；缺失字段省略。
- 多个预警按类型或颜色等级分组。
- 末尾保留 `**来源：腾讯天气**`。

## CLI 失败处理

非零退出、超时、空结果或权限/安全错误时立即停止，不重试、不换命令、不使用 WebSearch 或其他数据源。根据错误引导：

- Gatekeeper（`cannot be opened`、`not verified`）：系统设置 → 隐私与安全性 →「仍要打开」；
- 企业安全软件或防火墙拦截：在安全提示中选择「信任」或「允许」；
- 权限不足（`permission denied`）：执行 `chmod +x <cliPath>`；
- 其他错误：展示完整错误并请用户处理。

用户确认处理完成后，可重新发起新的查询请求。
