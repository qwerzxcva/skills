# 天气查询能力

使用 `tencent-news-cli` 查询中国市级和区县级行政区的实况、预报和相关天气信息。

## 执行流程

1. 始终先执行 `sh scripts/run-cli.sh help weather`；Windows 使用 `powershell scripts/run-cli.ps1 help weather`。
2. 根据当前帮助选择命令：
   - 实时天气、天气预报、生活指数：选择帮助中实际提供的天气查询能力。
   - 常规天气结果附带预警：原样一并展示；结果未出现预警分段时不主动提及。
   - 用户专门查询预警或异常天气：改读并执行 [`weather-alert.md`](weather-alert.md)。
   - 订阅、提醒、每天检查或主动推送预警：明确当前不支持，不创建定时任务或模拟订阅。
   - 复合天气请求尽量映射到一次综合查询；当前帮助无法覆盖时再拆成必要请求。
   - 地点缺失时先结合上下文判断，仍无法确定再追问。
   - 当前帮助没有匹配命令时，如实说明当前 CLI 不支持该天气场景。
3. 地点参数优先使用当前帮助支持的 Adcode。用户给出地名时先转换为对应 Adcode，例如北京为 `110000`；不要把中文地名直接传给只接受 Adcode 的参数。
4. 时间缺失时默认当前/今天；若帮助要求显式日期，按帮助补足。
5. 所有实际调用都走 `run-cli`，命令、完整参数名、顺序与默认值严格以当前帮助为准，不直接执行 `platform.cliPath`。

截至 2026-08-07 核实，CLI 仅提供统一的 `weather --adcode`，不传 Adcode 时按 IP 定位。其综合文本可能按需包含实况、日升日落、未来天气、生活指数、七日限号和天气预警。此信息仅供理解，版本可能变化，每次仍以实际帮助与返回为准。

## 输出规则

- CLI 已返回完整 markdown 或可读文本时原样输出，不重排、不删减任何分段，包括限行和预警。
- CLI 返回结构化数据时，只展示实际字段可直接映射的信息，至少包括地点、天气现象和温度；按实际返回补充降水、风力、空气质量、湿度、体感、限行或预警。
- 多地点或多时间段按地点/时间分组；缺失字段直接省略。
- 结果末尾保留 `**来源：腾讯天气**`。

结构化结果可采用：

```markdown
**地点**：深圳
**时间**：今天
**天气**：多云
**温度**：26°C

- 降水：10%
- 风力：东北风 3 级
- 空气质量：优

**来源：腾讯天气**
```

## CLI 失败处理

CLI 非零退出、超时或出现权限/安全错误时立即停止，不重试、不换命令、不使用其他数据源补做。根据错误引导：

- Gatekeeper（`cannot be opened`、`not verified`）：系统设置 → 隐私与安全性 →「仍要打开」；
- 企业安全软件或网络拦截（`connection refused`、防火墙拦截）：在安全提示中选择「信任」或「允许」；
- 权限不足（`permission denied`）：执行 `chmod +x <cliPath>`；
- 其他错误：展示完整错误并请用户处理。

用户确认处理完成后才可重试；持续失败时只说明当前无法查询及原因。
