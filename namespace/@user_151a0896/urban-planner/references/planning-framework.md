# 城市规划报告：通用框架与类型化模块

## 一、核心理念：一事一议，但有章可循
城市规划报告没有固定死模板——但你只需输入项目的基本信息（区位、上位规划、资源禀赋、核心诉求），它就能自动套用分析主轴，生成符合国土空间规划语境的完整报告框架。不是随机填空，是按"现状研判—目标定位—空间策略—行动计划—实施保障"的规划逻辑逐层展开；按项目类型（战略/产业/文旅/城市更新/村庄/控规）自动增删模块，不硬套模板。所有报告共享以下分析主轴（可在其基础上按项目类型增删模块、调整章节措辞）：

## 二、通用分析主轴（8 步法）
每个项目均建议覆盖以下逻辑链条（章节编号与标题可据实调整）：

**0. 规划总则**
- 规划依据（见 `references/standards-and-basis.md` 的"四类法"）
- 规划范围与规划期限（基期年 + 近期目标年 / 远期目标年，如 2025 / 2035）
- 技术路线、规划原则

**1. 规划背景 / 工作背景**
- 宏观形势（国际国内、区域协同）
- 政策依据（国家/省/市重大战略、专项政策）
- 上位要求（上级规划对本区域的定位与约束）
- 现实诉求（地方发展痛点、群众/市场主体需求）

**2. 现状研判 / 发展本底**
- 区位条件（地理区位、交通区位、在区域格局中的位置）
- 资源禀赋（自然、人文、产业、空间资源）
- 发展成效（经济社会基础、已有建设成果）
- 问题短板（常用 SWOT 或"优势—劣势—机遇—挑战"矩阵）
- 空间资源盘点（增量 vs 存量、低效用地、更新潜力）

**3. 目标定位**
- 总体定位（一句话发展定位，如"打造成为……"）
- 发展愿景（中长期意象）
- 阶段目标（近期 2025 / 远期 2035，尽量量化）
- 指标体系（见 `references/indicators.md`）

**4. 发展战略 / 策略框架**
- 总体战略思路（如"以……为主线，统筹……"）
- 核心策略（3–5 条，动词开头："坚持……""推动……""构建……"）

**5. 产业 / 功能策划**
- 产业体系（如"3+3""2+4"产业矩阵）
- 产业链 / 功能板块
- 重点方向、功能定位
- 重点项目（名称、规模、选址意向）

**6. 空间结构与用地布局**
- 国土空间格局（落实"三区三线"、生态/农业/城镇空间）
- 空间结构（如"一核两轴三片区"）
- 用地布局与管控（建设用地规模、用地分类、容积率/建筑密度等）
- 用途管制与刚性弹性

**7. 支撑体系**
- 综合交通、公共服务、市政基础设施
- 生态环境 / 绿色低碳
- 文旅 / 数字 / 治理（按类型选配）

**8. 实施保障**
- 近期重点项目库（项目表：名称/内容/规模/时序/责任主体）
- 实施时序（分期：近/中/远）
- 机制创新（如"一岛一策""一园一策""1+3+N"体系）
- 保障措施（组织、政策、资金、用地）

## 三、类型化模块（按项目自选组合）
- **战略规划 / 区域战略**（如思明东部、岛内提升）：重区位研判、十五五衔接、存量与低效用地、城市更新、产业策划、空间资源资产化；常用"一岛一策"。
- **产业规划**（如漳浦）：重 SWOT、产业体系（3+3 等）、产业空间（组团/园区）、"一园一策"、用地保障。
- **城市更新**（如厦门 5-3-1 体系）："五年规划—三年策划—年度实施计划"滚动机制、"1+3+N"体系、存量更新与微改造。
- **全域旅游**（如厦门/晋江）：旅游资源评价（GB/T 18972）、产品体系、产业融合、"一图一表一策"、交通/公服/营销。
- **片区高品质规划**（如前埔）：聚焦精细化、高品质的片区层面空间与功能提升。
- **村庄规划**（如白沙村）：实用性村庄规划、三区三线、人均建设用地（福建上限 120 ㎡/人）、设施/交通/水系/历史文化、近期建设。
- **和美乡村 / 五好两宜**（如集美）：基本思路、建设内容、机制创新、试点目标愿景、实施周期。
- **专题研究**：现状（本底/空间资源/成效）→ 目标 → 产业策划 → 实施路径。

## 四、文风与术语规范
- 章节标题多用偏正/动宾结构："规划背景""现状研判""目标定位""空间结构""实施保障"。
- 定位句常用："打造成为……""建设成为……""构建……新格局"。
- 原则句常用："坚持……与……相结合""以……为引领/主线"。
- 策略句动词开头："推动、构建、完善、强化、盘活、激活、统筹、筑牢"。
- 必用规范术语：多规合一、三区三线、国土空间、低效用地再开发、产城融合、存量优化、实用性村庄规划、"十五五"开局、15 分钟生活圈。
