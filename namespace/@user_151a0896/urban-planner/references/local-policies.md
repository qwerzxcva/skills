# 地方政策差异指引（地域适配）

> 国家规范是底线，**地标/地方规定常严于国标**。撰写「规划依据」与方案时，必须按项目**属地**补充地方要求；拿不准的标注"需核对当地最新规定"。以下为常见加严方向，非穷尽、且政策持续更新，**以属地现行文件为准**。
> 本文件是 architect「地方政策差异指引」的规划侧同版，与 `local_policy_db.json` 对应——两者内容一致，供 `site_analyze.py` 自动读取与对话中人工速查共用。`local_policy_db.json` 现已覆盖全国主要省/市，并按 `aliases`（省/市名）精确匹配，未命中时回退 `other`（全国通用基准）。

## 一、常见加严维度（按属地对照）

| 维度 | 国标底线 | 常见地方加严方向 |
|---|---|---|
| 绿色建筑 | GB/T 50378 基本级起评 | 多地强制二星/三星（见下）；大型公建常要求三星 |
| 装配式 | 鼓励，装配率视项目 | 多地新建建筑强制装配式，装配率 30%~50%+（保障房/公建更高） |
| 停车/新能源 | 新能源车位 ≥10% | 一线/强市新能源比例 20%~30%，并强制预留充电桩条件 |
| 海绵城市 | 鼓励年径流总量控制 | 多地强制控制率（如 75%~85%），下凹绿地、透水铺装入图则 |
| 日照间距 | 大寒日/冬至日底线 | 部分城市对住宅间距、日照有更严系数（如高纬度城市加大间距） |
| 密度/高度 | 按控规 | 城市设计导则常加贴线率、面宽、色彩、天际线管控 |
| 无障碍/适老化 | GB 55019 | 部分城市要求无障碍设施全覆盖到地块与街道衔接 |

## 二、主要城市/地区速查（示例，需核对现行版）

> `local_policy_db.json` 已内置以下主要省/市及全国通用 `other` 基准，脚本按归属地自动注入底线；此处仅列要点供速查，完整数值以 JSON 为准。

- **北京**：《北京市绿色建筑评价标准》多类建筑强制二星；装配式建筑占新建比例要求高；城市设计对老城风貌（高度、色彩、第五立面）管控严；核心区建筑高度严格限低。
- **上海**：《上海市绿色建筑条例》新建建筑全面执行高星级要求；装配式建筑装配率要求高；新能源车位比例高于国标；超高层建筑避难/消防审查严格；黄浦江两岸、历史风貌区有特殊形态管控。
- **深圳**：绿色建筑强制（多数项目二星及以上）；装配式建筑要求高（装配率 50%+ 常见）；海绵城市控制率要求高；密度分区精细（volumetric zoning），地块开发强度按密度分区法定。
- **江苏（南京/苏州等）**：《江苏省绿色建筑发展条例》强制按星级；装配式建筑要求明确；长江沿岸/古城保护有专项风貌要求。
- **浙江（杭州/宁波等）**：绿色建筑强制二星起步；未来社区导向（邻里/教育/健康等九场景）影响公服配置；装配式与数字化建造要求。
- **广州/广东**：夏热冬暖，节能重遮阳通风；绿建强制；部分新区高密度开发强度高，需校核密度分区与公共服务设施配套。

## 三、使用方式

1. 拿到项目先问**属地**（省/市/区），再加载对应地方规定与上位规划（国土空间规划、控规图则、城市设计导则）。
2. 在 JSON 的 `basis` 字段**显式列出属地规定**（如"《上海市绿色建筑条例》：新建建筑执行二星及以上"）。
3. 在 `indicators` 中把地方性底线加入 `limit`（如新能源车位 ≥20%），脚本会按阈值自动核对。
4. 对无法确认的属地条款，结论标注"需核对 XX 市现行规定"，勿杜撰具体数值。
5. 用地分类注意：国土空间语境下并行 **TD/T 1055 用地用海分类**，地块条件以属地控规图则为准；`site_analyze.py` 生成的 `merge.indicators` 已把地方底线并入，供 `build_report.py --site` 自动带入成果。
