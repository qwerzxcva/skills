# 城市规划原理框架（吴志强、李德华 主编，第 4 版，2010）

> 本文件将国家级规划教材《城市规划原理（第 4 版）》的权威方法论提炼为 skill 的"学术骨架"——确定性、规则性的学科共识，正是它处理标准化、规则性工作的底层依据；与本技能既有的"8 步法"策划流程互补：8 步法解决"怎么组织一份报告"，本文件解决"规划学科公认的体系、价值观与分析要素是什么"。
> 教材共 22 章，本文件按"规划体系 → 价值观 → 影响要素 → 规划类型与编制 → 实施"五段式重组，供撰写战略/策划/控规时统一话语。

---

## 一、城市规划体系（法定层级）

依据《城乡规划法》（2019 修正版）与教材"城市规划体制"章：

- **五级体系**：国家/省域城镇体系规划 → 城市总体规划 → 镇/乡规划 → 详细规划 → 修建性详细规划。
- **规划二分**：
  - **总体规划**（含城镇体系规划、城市总体规划）：确定性质、规模、空间结构、用地布局。
  - **详细规划**：分为**控制性详细规划**（法定管理依据，定指标）与**修建性详细规划**（开发建设方案）。
- **国土空间规划改革语境**（2019 起）：原"城乡规划体系"并入"国土空间规划体系"（总体规划—详细规划—专项规划），"三区三线"（生态/农业/城镇空间；生态保护红线、永久基本农田、城镇开发边界）成为新底线；控规纳入"详细规划"范畴，新国标《国土空间详细规划编制技术指南》在制定中（见 `standards-and-basis.md`）。

## 二、城市规划的价值观

教材单列"城市规划的价值观"章，撰写报告时须贯穿：

1. **以人为本**：以满足人的需要、提升生活质量为核心。
2. **公平与共享**：公共资源与设施公平配置，主客共享、代际公平。
3. **可持续发展**：生态优先、集约节约、双碳导向。
4. **宜居与韧性**：安全、健康、活力、有文化底蕴。
5. **系统整体观**：经济—社会—环境—空间协同。

> 用法：报告"前言/目标愿景"应呼应上述价值观，避免纯工程导向。

## 三、五大影响要素（分析主轴）

教材设"生态与环境、经济与产业、人口与社会、历史与文化、技术与信息"五章，是任何现状研判的通用维度：

| 要素 | 核心议题 | 报告落点 |
|---|---|---|
| 生态与环境 | 资源环境承载力、生态安全格局、双碳 | 生态底线、蓝绿空间、海绵 |
| 经济与产业 | 产业结构、增长动力、用地效率 | 产业生态体系、亩均效益 |
| 人口与社会 | 人口规模结构、社区、公共服务 | 人口与设施匹配、生活圈 |
| 历史与文化 | 遗产价值、风貌、文脉 | 保护利用、风貌管控 |
| 技术与信息 | 数字孪生、CIM、智慧治理 | 一张图、智慧化 |

> 用法：现状研判/ SWOT 应覆盖这五维，避免遗漏（例如古城项目重点在"历史与文化"，园区项目重点在"经济与产业"）。

## 四、规划类型与编制内容（对应章节）

教材"城市规划的类型与编制内容"及后续专章，给出各类规划的内容边界，撰写时据项目类型取用：

- **城市总体布局**：功能分区、组团、轴带、道路交通骨架、绿地系统。
- **城市交通与道路系统**：对外交通、公共交通、步行非机动车、道路网等级（对接 GB/T 51328-2018）。
- **城市生态与环境规划**：生态网络、环境容量、绿色低碳。
- **城市工程系统规划**：给水/排水/电力/通信/燃气/供热/环卫（对接 GB 50289 等）。
- **城乡住区规划**：居住区与社区生活圈（对接 GB 50180-2018、TD/T 1062-2021）。
- **城市设计**：形态、风貌、公共空间、天际线。
- **城市遗产保护与城市复兴**：历史文化名城/街区/建筑、紫线（对接 GB/T 50357-2018、保护条例）。
- **城市开发规划**：开发强度、土地经济、运营模式。
- **城市地下空间**：竖向分层、综合管廊。

## 五、规划实施

教材末章强调：规划的生命在"实施"。报告须含：
- 实施路径（策划—规划—建设—运营闭环）；
- 分期时序与重点项目库；
- 实施机制（如"微改造+共生"、公众参与、动态维护）；
- 体检评估（国土空间规划"定期评估+动态维护"）。
