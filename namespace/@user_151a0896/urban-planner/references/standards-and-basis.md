# 规划依据与标准体系引用库

> 把"查规范、对标准"这种重复劳动交给它——本文件为"规划依据"章节提供可直接套用的引用条目，告别手翻规范。组织方式：**规划依据四类法 → 标准全目录（含时效性）→ 四线办法 → 上位规划库 → 控规专项依据 → 标准时效性核查（2026-07）**。
> 标准来源：湘源控规7.0 自带标准库、2021 规范电子版合集、城市规划资料集（11 分册）、国土空间规划体系新标准。
> **时效性说明**：凡标准注明年份的以公布年份为准；标注"〔现行〕"为截至 2026-07 仍有效，"〔废止〕"为已作废须替换，"〔制定中〕"为国家标准计划尚未发布。法定取值以原规范表校核。

---

## 一、规划依据"四类法"（报告固定写法）

每份报告"规划依据"章节按此四类罗列，引用具体文件：

1. **法律法规**：城乡规划法（2019 修正）、土地管理法、文物保护法、非物质文化遗产法、历史文化名城名镇名村保护条例（2017 修订）等。
2. **规范标准**：GB / CJJ / GB/T / TD 系列（见第二节目录，注意时效标注）。
3. **相关文件**：国家/省/市战略规划、专项政策（如"十五五"、文旅经济、城市更新行动、两岸融合）。
4. **上位规划**：国土空间总体规划、分区规划、相关专项规划、已批控规/详细规划。

## 三、四线管理办法（控规刚性边界依据）〔均现行有效〕

| 线 | 全称 / 令号 | 核心规定 |
|---|---|---|
| 紫线 | 《城市紫线管理办法》建设部令第119号（2003，**2011 住建部令第9号修订**） | 历史文化街区、历史建筑保护范围；禁止大拆大建 |
| 绿线 | 《城市绿线管理办法》建设部令第112号（2002） | 各类绿地范围；不得改作他用、不得建无关建筑 |
| 蓝线 | 《城市蓝线管理办法》建设部令第145号（2005） | 江河湖库渠湿地保护界线；禁止填埋占用 |
| 黄线 | 《城市黄线管理办法》建设部令第144号（2005） | 城市基础设施用地控制界线；禁止违规建设、擅自迁移拆毁 |

> 国土空间规划新增"三条控制线"（生态保护红线、永久基本农田、城镇开发边界），与四线并行管控；控规须同时落实四线与三条控制线。

## 四、上位规划与国土空间库

- 国家/省级：国土空间规划、国民经济与社会发展规划（"十五五"等）、主体功能区规划
- 市级：国土空间总体规划（2021—2035）、市级国土空间总体规划编制指南
- 专项：历史文化保护、综合交通、生态/流域、公共服务、市政基础设施等专项规划
- 空间底线：**"三区三线"**（生态空间/农业空间/城镇空间；生态保护红线、永久基本农田、城镇开发边界）
- 厦门/福建语境：岛内"更大提升"、两岸融合发展示范区、闽南文化生态保护区、厦金大桥

## 五、控规专项依据（法定规划层级）〔现行〕

- 《城市、镇控制性详细规划编制审批办法》住建部令第7号（2011）
- 《城市规划编制办法》建设部令第146号（2005）第四十一条~第四十四条
- 控规强制性内容：用地性质、开发强度（密度/高度/容积率/绿地率）、配套设施、四线、地下空间
- 成果：文本 + 图件（图则） + 说明书 + 数据库
- *转型提示*：国土空间规划下"详细规划"为法定规划，控规编制审批办法仍适用，新《国土空间详细规划编制技术指南》制定中将进一步统一。

> 用法：写"规划依据"时，按项目类型从目录挑对应标准；控规/详细规划项目必引"控规编制审批办法 + GB 50137 + GB 50180 + GB/T 50357（遗产类）+ 四线办法 + TD/T 1055（国土空间语境）"。
