本文件汇总股票介绍所所有阶段的输出模板、评分表、确认门文案与出口模块。执行时按对应阶段严格套用。本技能不生成可下载的报告文件，完整报告内容在对话中以快速摘要、完整报告和逆向挑战形式交付。

## 评分基准（执行锚点）

三次评分（初次印象分 / 深入摸底分 / 逆向考察分）统一使用以下锚点。锚点只保证标尺一致，不承诺精确——评分仍属娱乐性质，不构成投资建议。

**通用分数段锚点**（适用于所有维度）：
- **8-10 分**：该维度表现优秀、行业领先或接近最佳实践，无明显短板
- **5-7 分**：中等偏上，有亮点但也有明确隐忧，需要继续跟踪
- **1-4 分**：存在明显缺陷或重大风险，该维度是投资的减分项

**八维度打分侧重**（每个维度围绕一句话侧重给分）：

| 维度 | 打分侧重 |
|------|----------|
| 生意模式 | 赚钱方式是否简单易懂、可持续、难复制 |
| 行业特性 | 行业属性与底层逻辑是否友好、空间、阶段、格局与景气位置、政策环境 |
| 竞争格局 | 差异化优势是否可验证、份额稳定性与竞争烈度（含被颠覆风险） |
| 产业链 | 议价能力、链条中的价值分配地位与地缘韧性 |
| 治理文化 | 股权与实控人是否可靠、激励与股东回报是否相容、文化是否加分 |
| 财务质量 | 利润是否变成真钱、回报是否配得上资本、风险是否可控 |
| 市场博弈 | 估值合理性、预期差与边际信号方向、筹码资金位置 |
| 决策参考 | 底层逻辑是否站得住、情景与安全边际是否充足、跟踪退出是否可操作 |

**一致性约束**：
- 三次评分使用同一把标尺：变化应来自证据变化，而非标尺漂移。
- 初次印象分、深入摸底分的分值在后续对比表中原样沿用，不得重打。
- 数据不足的维度填"N/A（信息不足）"，禁止强行打分。
- 评分表输出纪律：三张评分表均只输出完整表格内容，表前严禁添加"评分联动"等任何前导或说明段落；表后仅按模板输出固定注释，不得另有添加。

**综合分权重规则**（三次评分均适用）：

各维度得分按以下权重加权计算综合分。权重越高，该维度对最终评分的影响越大：

| 权重等级 | 维度 | 权重系数 |
|---|---|---|
| 第一权重 | 生意模式、竞争格局、治理文化 | 3 |
| 第二权重 | 财务质量 | 2 |
| 第三权重 | 行业特性、产业链、市场博弈、决策参考 | 1 |

综合分 = Σ（各维度得分 × 对应权重系数） / Σ（权重系数），结果四舍五入到 0.5 分；有 N/A 的维度不计入，按有效维度权重求平均。

## Phase 7：逆向思维挑战

### 审查原则

从用户指定的角色出发，对完整报告及背后的 8 维度分析结论逐章审查：

- **底线**：质疑观点必须基于合理逻辑和事实依据，**不能为了质疑而质疑，更不能捏造事实**。如果分析论述无误且证据充分，应当如实承认。
- **逻辑漏洞**：推理链是否有跳跃？相关性是否被误读为因果性？有没有幸存者偏差？
- **事实不符**：引用的数据或事实是否有误？有没有遗漏不利的反面证据？
- **数据错误**：计算是否准确？增长率、比率等关键指标是否有口径混淆？
- **偏颇之处**：是否存在过度乐观或过度悲观的倾向？有没有选择性引用有利信息、回避不利信息？
- **辩驳论点**：如果有偏颇，给出相反方向的有力论点，让用户听到"另一边"的声音。
