## 一、医药类

### 1.1 创新药（Biotech / Biopharma）

**核心指标**：
- 研发管线分级：临床前 / I期 / II期 / III期 / NDA / 已上市
- 重磅药物（Blockbuster Drug）预期销售额：>10亿美元/年
- 现金跑道（Runway）：按当前烧钱速度能支撑多少个月
- BD（Business Development）能力：License-in/out 数量与质量

**关键问题**：
- 核心管线是 First-in-class 还是 Me-too？
- 关键适应症的医保谈判预期？
- 专利悬崖：核心产品专利期还有几年？
- 是否过度依赖单一管线（"全部身家压在III期"）？

**典型陷阱**：
- 把临床前/早期管线估值过度乐观
- 忽视监管审批不确定性（FDA 拒绝、CDE 审评）
- 把合作开发收入误认为自主研发能力

**代表公司**：恒瑞医药、百济神州、信达生物、Moderna、Vertex

---

### 1.2 仿制药（Generic Drug）

**核心指标**：
- 品种数量与一致性评价通过率
- 一致性评价（一致性 = 与原研药生物等效）
- 集采中标率与中标价格
- 原料药 - 制剂一体化程度

**关键问题**：
- 核心品种是否进入国家集采？降价幅度？
- 是否被纳入医保目录？
- 制剂 vs 原料药的盈利能力差异？
- 高端仿制药（复杂制剂、长效制剂）布局？

**典型陷阱**：
- 集采降价幅度被低估
- 忽视一致性评价的政策成本
- 把普药当"现金奶牛"，实际毛利快速下行

**代表公司**：复星医药、华海药业、科伦药业、Teva、Mylan

---

### 1.3 CXO（CDMO / CRO）

**核心指标**：
- 订单结构：早期 vs 后期；Pre-clinical vs Commercial
- 产能利用率（核心厂房）
- 资本开支节奏（决定未来供给）
- 前五大客户占比

**关键问题**：
- 是否过度依赖海外大客户？（地缘风险）
- 订单能见度（在手订单年数）
- 技术平台壁垒（ADC、GLP-1、多肽等热门赛道）
- 海外产能布局（应对脱钩）

**典型陷阱**：
- 把订单增速当永续
- 忽视产能过剩周期（行业下行时毛利率骤降）
- 客户集中度风险被低估

**代表公司**：药明康德、康龙化成、凯莱英、Charles River、IQVIA

---

### 1.4 医疗器械

**核心指标**：
- 集采进度（哪些品类已被集采、降幅）
- 国产替代率（高端 vs 低端）
- 研发投入占比 vs 销售费用占比
- 装机量（install base）与耗材消耗

**关键问题**：
- 核心产品是否在医保目录内？
- 医生使用习惯黏性（高值耗材最难替代）
- 出海能力（FDA / CE 认证进度）
- 高端品类（CT/MRI/手术机器人）vs 中低端品类

**典型陷阱**：
- 集采降价被低估（有的品类降价 80%+）
- 忽视医生更换习惯的难度（国产化可能失败）
- 把装机量当收入（耗材才是持续现金流）

**代表公司**：迈瑞医疗、联影医疗、微创医疗、Intuitive Surgical、Medtronic

---

### 1.5 医药商业（流通 / 零售药店）

**核心指标**：
- 应收账款周转天数（流通企业普遍偏长）
- 现金流 / 净利润比（账面利润和真钱差异）
- 集采配送率
- 零售药店：坪效（每平方米销售额）、客单价、复购率

**关键问题**：
- 上游议价能力（是否能拿到大厂独家配送）
- 下游医院回款账期（流通企业命门）
- 零售药店的并购整合质量
- 处方外流政策受益度

**典型陷阱**：
- 把营收增长当利润增长（流通是微利生意）
- 忽视应收账款爆雷风险
- 高估处方外流速度

**代表公司**：上海医药、华润医药、国药控股、老百姓、益丰药房、CVS Health

---

### 1.6 中药

**核心指标**：
- 独家品种数量
- 医保目录覆盖度（甲类 vs 乙类）
- 品牌历史与渠道渗透（三甲医院 vs 基层）
- 中药材价格波动对成本的影响

**关键问题**：
- 核心品种是否进入医保 / 基药目录？
- 是否拥有中药保护品种？
- 上游中药材布局（自有 GAP 基地）？
- 老字号品牌的渠道护城河？

**典型陷阱**：
- 把"国潮"营销红利当长期竞争力
- 忽视中药材涨价对毛利率的吞噬
- 把老字号品牌过度神化（疗效争议风险）

**代表公司**：云南白药、片仔癀、同仁堂、东阿阿胶

---

### 1.7 医疗服务（医院 / 体检 / 口腔 / 眼科）

**核心指标**：
- 单店收入与坪效
- 医师资源（数量与稳定性）
- 医保支付占比 vs 自费占比
- 复诊率与客户黏性

**关键问题**：
- 是否依赖医保？医保结算压力？
- 医师培养周期（眼科、口腔医师是核心资产）
- 门店扩张质量（新店爬坡周期）
- 医疗事故 / 舆情风险

**典型陷阱**：
- 把营收增速当利润增速（扩张期亏损扩大）
- 忽视医疗事故对品牌的毁灭性
- 公立医院挤压下的天花板

**代表公司**：通策医疗、爱尔眼科、美年健康、HCA Healthcare

---

### 1.8 医美

**核心指标**：
- 活跃客户数（不是注册用户数）
- 客单价与复购率（注射类看 6 个月复购）
- 新客获取成本（CAC）
- 产品组合（玻尿酸、肉毒素、胶原蛋白、童颜针）

**关键问题**：
- 上游产品采购集中度（高德、爱美客、华熙生物）
- 终端价格战激烈程度
- 监管对医美广告、医师资质的收紧
- 上游产品迭代（新成分替代）

**典型陷阱**：
- 把行业增速当公司增速（高度分散）
- 忽视医师培养周期
- 高估客户忠诚度（医美消费者高度价格敏感）

**代表公司**：爱美客、华熙生物、华东医药、艾尔建美学（Allergan）

## 二、科技类

### 2.1 SaaS / 软件

**核心指标**：
- NRR（净收入留存率）：>120% 优秀，>100% 健康，<100% 危险
- Gross Retention Rate（毛留存率）：流失底线
- Churn（流失率）：月度/年度差异大
- Rule of 40：增速% + 利润率% ≥ 40% 为健康
- Magic Number：销售效率指标

**关键问题**：
- 收入是订阅型还是项目型？（订阅型估值溢价）
- 客户获取成本（CAC）与生命周期价值（LTV）比
- ARR（年化经常性收入）质量（实际取消率）
- 大客户依赖（>20% 收入来自单一客户危险）

**典型陷阱**：
- 把合同金额当收入（应该按服务期间确认）
- 忽视隐性流失（down-sell 也算流失）
- 销售费用永久高于毛利（增长黑洞）

**代表公司**：Salesforce、Adobe、ServiceNow、用友、金山办公、广联达

---

### 2.2 半导体（设计 / 制造 / 封测 / 设备 / 材料）

**核心指标**：
- 国产替代率（细分领域）
- 制程节点（先进 vs 成熟）
- 资本开支强度（Foundry 是重资产）
- 研发投入占比
- 客户认证进度（流片、量产、入库）

**关键问题**：
- 是设计还是制造？（代工 vs 品牌的资本结构完全不同）
- 是否进入 Tier-1 客户供应链（台积电 / 苹果 / 英伟达）？
- 美国出口管制影响（EUV、DUV、EDA 工具）
- 周期阶段（半导体是强周期）

**典型陷阱**：
- 把国家战略当公司竞争力（政策红利不会永远在）
- 忽视周期下行（库存周期是杀手）
- 高估"国产替代"速度（认证周期长）

**代表公司**：中芯国际、北方华创、海光信息、寒武纪、台积电、ASML、英伟达

---

### 2.3 硬件 / 消费电子（手机 / PC / 可穿戴）

**核心指标**：
- 出货量（不是销售额）
- ASP（平均售价）变化（高端化 vs 低端化）
- 毛利率结构（不同产品线差异）
- 库存周转天数（消费电子命门）

**关键问题**：
- 核心产品市场地位（Top 1/2/3/其他）
- 供应链集中度（依赖单一供应商风险）
- 品牌溢价能力（苹果 vs 安卓）
- 出海能力（海外占比）

**典型陷阱**：
- 把概念机销量当长期出货
- 忽视库存积压（手机行业经典陷阱）
- 高估生态绑定（消费者忠诚度有限）

**代表公司**：立讯精密、歌尔股份、传音控股、Apple、Dell

---

### 2.4 互联网平台（社交 / 电商 / 外卖 / 出行）

**核心指标**：
- DAU / MAU 与使用时长
- ARPU（每用户收入）变化
- 网络效应强度（双边市场壁垒）
- 监管成本（反垄断罚款、上市限制）

**关键问题**：
- 平台的核心飞轮是什么？
- 用户增长是否见顶？（DAU 同比增速）
- 商业化路径（广告 / 电商 / 金融）
- 政策风险（反垄断、数据安全）

**典型陷阱**：
- 把 MAU 当活跃用户（含大量"僵尸"账号）
- 忽视获客成本攀升
- 高估用户黏性（年轻人迁移成本被低估）

**代表公司**：腾讯、阿里、美团、拼多多、Meta、Google

---

### 2.5 游戏

**核心指标**：
- 流水 vs 收入确认（递延收入调节）
- 单游戏生命周期（爆款 = 3-5 年）
- 新游储备（Pipeline）
- 海外收入占比
- ARPPU（每付费用户收入）

**关键问题**：
- 核心 IP 是否长青？（王者荣耀 vs 普通新游）
- 出海能力（中国游戏出海东南亚/欧美）
- 版号节奏（国内政策关键变量）
- 渠道分成（苹果税 30%、安卓商店 50%）

**典型陷阱**：
- 把首月流水当永续
- 忽视研发投入（爆款不可复制）
- 把版号下发当确定性

**代表公司**：腾讯、网易、米哈游、Activision Blizzard、Take-Two

---

### 2.6 传媒（影视 / 出版 / 广告 / 广电）

**核心指标**：
- 票房分账（影视）
- 广告投放行业景气度
- 内容储备的爆款概率
- 渠道议价能力

**关键问题**：
- 内容创作能力（持续输出爆款 vs 押宝式）
- 政策风险（审查、限娱、限薪）
- 现金流（影视项目周期长、应收账款重）
- 平台 vs 内容方（议价能力）

**典型陷阱**：
- 把单部爆款当可持续
- 忽视应收账款（影视公司常见死法）
- 误判政策周期

**代表公司**：万达电影、光线传媒、分众传媒、Disney、Netflix

---

### 2.7 AI / 算法 / 数据

**核心指标**：
- 模型能力与商业化变现能力
- 算力规模（GPU / TPU 数量）
- 数据资产（合规性）
- 客户付费意愿（不是 demo 热闹）

**关键问题**：
- To B 落地能力（场景深度）
- 算力供应（GPU 是否被卡脖子）
- 数据合规（隐私计算、监管）
- 商业模式（按 token 收费 / 解决方案 / 订阅）

**典型陷阱**：
- 把 demo 演示当产品落地
- 高估 GPU 算力持续可得性
- 把"AI 概念"当长期估值依据

**代表公司**：商汤、科大讯飞、百度、阿里云、OpenAI、Anthropic

## 三、消费类

### 3.1 消费品（白酒 / 家电 / 食品 / 饮料 / 美妆 / 服饰 / 宠物）

**核心指标**：
- 品牌力（品牌溢价能力）
- 复购率（高频消费品命门）
- 渠道库存（库存积压是消费行业第一杀手）
- 终端动销（报表 vs 真实销售）

**关键问题**：
- 品牌心智是否稳固（新生代是否还买？）
- 渠道结构（经销 vs 直营 vs 电商占比）
- 提价能力（通胀环境下能否转嫁成本）
- 新品类拓展能力（第二增长曲线）

**典型陷阱**：
- 把报表数据当终端真实销售
- 忽视渠道库存（压货严重时崩盘）
- 高估品牌忠诚度（消费品代际更替快）

**代表公司**：贵州茅台、美的集团、海天味业、Procter & Gamble、L'Oreal

---

### 3.2 汽车（整车 / 零部件 / 经销商 / 售后）

**核心指标**：
- 销量增速与市占率
- 车型结构（高端 vs 中端 vs 低端占比）
- 单车毛利（不是营收）
- 智能化进度（智驾 / 智能座舱）

**关键问题**：
- 产能利用率（行业下行时是杀手）
- 出海能力（新能源车出海是新增量）
- 价格战承受力
- 现金流（造车新势力生死线）

**典型陷阱**：
- 把销量目标当订单
- 高估自动驾驶落地速度

### 3.3 零售（线下 / 电商 / 连锁）

### 3.4 旅游酒店 / 餐饮

## 四、金融类

### 4.1 银行（国有 / 股份 / 城商 / 农商）

**关键问题**：

- 政策风险（让利实体经济）

**典型陷阱**：
- 把规模当质量（资产扩张快 = 风险扩张快）

- 高估零售化转型效果

### 4.2 证券 / 券商

### 4.3 保险

**关键问题**：

**典型陷阱**：

- 高估整机厂利润率（集成环节毛利低，价格战激烈）
- 忽视下游制造业资本开支周期的同步波动

**代表公司**：汇川技术、埃斯顿、绿的谐波、双环传动、FANUC、安川电机

## 七、传统制造类

### 7.1 传统制造通用要点（造纸 / 纺织 / 轮胎 / 玻璃 / 家具 / 包装等）

本节为本文未单列小节的其他传统制造行业提供通用评估框架。先用本小节四个核心抓手定位，再叠加行业自身特性补充：

**四个核心抓手**：
- **产能周期位置**：行业在建/拟建产能占现有产能比例多高？投产高峰在哪一年？（投产高峰前看涨价预期，投产高峰后看价格战风险）
- **成本曲线分位**：公司在行业成本曲线的位置（前 1/4 才能穿越下行周期），原材料/能源自给率多高
- **价格传导能力**：原材料涨价能否提价转嫁？提价的时滞和幅度如何，下游接受度如何
- **资本开支纪律**：管理层历史上是否逆周期乱扩产？自由现金流是否长期为真

**补充观察**：
- 出海产能布局（规避关税/运费/贸易壁垒）与海外工厂爬坡进度
- 需求端的结构性变化（电商化、新能源化、消费降级/升级对品类需求的改造）

**典型陷阱**：
- 把周期顶部利润当常态（传统制造多为价格接受者）
- 低估出海建厂的成本超支与爬坡期风险
- 忽视需求端结构性萎缩（部分品类被新材料/新形态永久替代）

**代表公司**（示例）：太阳纸业（造纸）、申洲国际（纺织制造）、赛轮轮胎（轮胎）、福耀玻璃（汽车玻璃）、欧派家居（家具）、裕同科技（包装）

## 九、农业类

### 9.1 种植业 / 种业

**核心指标**：
- 种植面积（亩 / 公顷）
- 单产水平（产量 / 面积）
- 收购价格（政策定价 vs 市场定价）
- 库存周期

**关键问题**：
- 粮食安全政策（最低收购价）
- 极端天气影响
- 育种技术（转基因政策）

**典型陷阱**：
- 把政策价当市场价（保护价下行时亏损）
- 忽视库存周期
- 高估转基因落地速度

**代表公司**：北大荒、隆平高科、登海种业、Corteva、Bayer

---

### 9.2 养殖业（生猪 / 家禽 / 水产）

**核心指标**：
- 出栏量
- 完全成本（元 / 公斤）
- 头均盈利
- 资产负债率（周期低点关键）

**关键问题**：
- 周期阶段判断（猪周期 3-4 年）
- 疫病冲击（非洲猪瘟）
- 饲料成本（玉米、豆粕）
- 环保政策

**典型陷阱**：
- 把猪价当永续
- 忽视周期下行杀伤力
- 高估产能去化速度

**代表公司**：牧原股份、温氏股份、新希望、WH Group、Tyson Foods

---

## 十、公用事业类

### 10.1 电力（火电 / 水电 / 核电）

**核心指标**：
- 利用小时数
- 上网电价
- 燃料成本（火电）
- 资本开支（核电 vs 水电差异大）

**关键问题**：
- 电价市场化进度
- 煤价波动（火电）
- 来水情况（水电）
- 政策补贴（核电、新能源）

**典型陷阱**：
- 把高利用小时数当永续
- 忽视煤价吞噬火电利润
- 高估分红持续性（核电资本开支重）

**代表公司**：华能国际、长江电力、中国核电、NextEra Energy、Duke Energy

---

### 10.2 燃气 / 供热

**核心指标**：
- 售气量（亿立方米）
- 门站价 vs 终端价
- 接驳费（一次性收入）
- 工商业用户占比

**关键问题**：
- 上游气源（进口 LNG、管道气）
- 季节性需求波动
- 价格管制

**典型陷阱**：
- 忽视上游涨价（城燃利润被压缩）
- 把接驳费当永续（接驳费政策在收）

**代表公司**：中国燃气、新奥能源、华润燃气、ENN Energy

---

### 10.3 水务

**核心指标**：
- 处理能力（万吨 / 日）
- 处理单价
- 特许经营年限
- 应收账款（政府客户）

**关键问题**：
- 地方财政压力
- 水价上调进度
- 提标改造（排放标准升级）

**典型陷阱**：
- 忽视政府应收账款
- 高估水价市场化进度

**代表公司**：首创环保、北控水务、中国水务、American Water Works
