# 8维度投研分析框架

本文件为基本面分析的8个维度提供详细指引，包括每维度需要回答的核心问题、分析要点、数据需求和输出建议。

---

## 维度一：生意模式

### 核心问题

公司的业务怎么运转、怎么获得收入和利润，护城河和脆弱性分别在哪，能否长期持续？

### 分析要点

**1.1 业务运转机制**
- 公司如何创造价值、传递价值、获取价值？（完整价值创造链路的流程图见下方"业务运转与价值主张"块）
- 收入结构：主要产品和服务的收入占比、各业务线增速和毛利率
- 成本结构：固定成本vs变动成本，主要成本项是什么
- 应用场景：产品/服务用在什么场景下，解决什么问题
- 功能价值：帮客户完成什么任务、提高什么效率
- 情绪价值（消费品尤其重要）：给客户带来什么心理满足感、身份认同感
- 社交价值（消费品尤其重要）：品牌是否具有社交属性——产品是否被用于晒单、送礼、身份表达，能否带来圈层认同与自发传播？

**业务运转与价值主张**（以流程图呈现"投入→过程→产出→客户→收入"的完整价值创造链路，并在图下补充，必须逐项输出）：
- 价值主张：[一句话]
- 核心场景：[列举]

**收入结构**（分业务线列出，不得省略）：
| 业务线 | 收入占比 | 毛利率 | 增速 |
|--------|----------|--------|------|
| ... | ... | ... | ... |

**成本结构**：[高固定成本/高变动成本/均衡]，主要成本项为[折旧/原材料/人工/…]（若财报未按性质披露成本拆分，基于资产结构与成本性质作定性判断并标注数据缺口）

**1.2 护城河与脆弱性**
- 公司的核心优势是什么（技术/品牌/渠道/成本/网络效应/牌照/规模等）
- 这些优势能否持续？加大还是缩小？
- 公司的脆弱性是什么——什么情况下护城河会瓦解？
- 与竞争对手的核心差异在哪，能否被轻易复制

**护城河与脆弱性**（分护城河来源列出，不得省略）：
| 护城河来源 | 强度 | 趋势 | 脆弱性 |
|------------|------|------|--------|
| ... | ... | ... | ... |

**1.3 可持续性与战略方向**
- 盈利模式能否长期持续？依赖什么前提假设？单一产品依赖等经营风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」
- 是否具有反脆弱性（在压力下反而变强）？
- 定价模式与提价能力：公司是按产品/服务/订阅/抽成/广告收费？能否持续提价而不明显损失销量？价格弹性如何？
- 商业模式迁移风险：当前盈利模式是否面临被新技术、新渠道、新消费习惯重构的风险？迁移成本有多高？
- 不可逆风险有哪些：需求重构（用户不再需要）、技术颠覆（新技术替代）、政策监管（政策转向打压）
- 公司未来的战略重点是什么？战略选择的理由（为什么选这个方向而非其他）？战略执行可能伴随哪些风险？

### 数据需求

- 分业务线/产品的收入占比、毛利率与增速；固定成本与变动成本结构
- 护城河判断依据：品牌溢价、单位成本、渠道控制、技术/牌照壁垒的对比数据
- 定价模式、提价历史与提价后的销量反应
- 战略规划公告、商业模式演变节点、战略转型节点及其执行进展

## 维度二：行业特性

### 核心问题

行业有什么特性，出现这些特性的底层逻辑是什么？空间多大，处于什么阶段？格局集中还是分散？景气由什么决定？政策与监管规则影响多大？

本维度从目标公司视角出发分析行业——关注「行业环境如何影响目标公司」而非单纯描述行业。分析要点按行业分析的**五个核心问题**组织。
时间有限时，可先用下方「行业本质速判」三问快速定性，避免被细节淹没。

**行业本质速判三问**：

1. **这个行业靠什么赚钱？**（收入模式：差价？订阅？广告？授权？）
2. **赚的钱好不好赚？**（利润率水平、波动性、可持续性）
3. **以后还能不能赚？**（增长空间、壁垒变化、替代风险）

### 分析要点

**2.1 行业本质属性与客户特征**
- 行业核心特性的成因（为什么这个行业是现在这个样子？）
- 行业存在的必要性是什么（满足什么根本需求）
- 行业属性标签：周期型/成长型/防御型/消费型/科技型/资源型/制造型（依据行业历史营收与利润的波动幅度判定；为 8.1 投资属性定位提供输入）
- 资本密集度：重资产还是轻资产？CAPEX/收入（资本开支强度）如何？是否存在"产能诅咒"（扩产后行业供过于求）？
- 技术迭代速度：行业技术变革快还是慢？是否存在技术路线之争或降维打击风险？
- 产业链位置：行业处于微笑曲线哪一端？利润主要被上游、中游还是下游获取？
- 客户结构：下游是B端/C端/G端？需求是刚需还是可选、高频还是低频？决策链长短？需求价格弹性如何（以"提价后销量是否明显受损"定性判断，不单独测算弹性数值）？

**2.2 行业空间与增长**
- 国内外行业空间（TAM/SAM/SOM（总可触达市场/可服务市场/可获得市场））
- 增长驱动：行业增长靠什么推动？人口增长？消费升级？技术渗透？政策推动？
- 当前处于什么发展阶段（导入期/成长期/成熟期/衰退期），四个阶段的特征如下：
  - 导入期（起步期）：市场小但增速快，不确定性高
  - 成长期：市场快速扩大，格局开始形成
  - 成熟期：增速放缓，竞争集中，龙头受益
  - 衰退期：规模萎缩，存量博弈，除非有结构性机会
- 行业渗透率：目前多高，提升空间多大
- 天花板判断：5-10 年后行业规模可能达到多少？是否存在结构性天花板？

**2.3 行业格局与集中度**
- 行业集中度（CR3/CR5/CR10（前3/5/10名企业合计市场份额））：集中还是分散，趋势如何
  - 高集中度（CR3>50%）：龙头定价权强，新进入者难；低集中度：竞争激烈，差异化是关键
- 主要玩家：行业前 3-5 名是谁？各自优势与劣势？市场份额趋势如何？
- 行业进入壁垒：进入壁垒有多高？资金壁垒？技术壁垒？牌照壁垒？品牌壁垒？
- 行业竞争方式：行业竞争靠什么？价格战？技术迭代？品牌心智？渠道覆盖？
- 行业是马太效应（强者恒强、龙头份额持续扩大）还是长尾效应（分散化、小而美也有生存空间）？判断方向决定投资逻辑——马太买龙头，长尾找利基冠军
- 公司是否占据利基市场（小众但稳定的高利润细分市场）的龙头位置？利基业务的进入壁垒与可持续性如何，占总收入/利润的比例及变化趋势？
- 本节仅到行业层面：公司在行业中的竞争地位、差异化来源、与对手的成本曲线差异见维度三「竞争格局」

**2.4 景气度驱动因素**

**常见驱动因素（按行业类型）**——先定位本行业的核心驱动因素（分类口径同 `references/industry-specific-guides.md` 顶部索引的 10 大类）：

| 行业大类 | 核心驱动因素 |
|----------|-------------|
| 医药类 | 研发突破、审批政策、医保支付 |
| 科技类 | 技术迭代周期、用户渗透率、平台效应 |
| 消费类 | 居民收入增长、消费升级趋势、品牌心智 |
| 金融类 | 利率环境、监管政策、经济周期 |
| 能源类 | 补贴政策、技术成本曲线、渗透率拐点、大宗商品价格、产能周期 |
| 高端制造类 | 下游资本开支、技术自主化、订单交付周期 |
| 传统制造类 | 产能周期、原材料价格、下游需求 |
| 基建 / 地产类 | 基建投资、利率水平、政策调控 |
| 农业类 | 农产品价格周期、饲料成本、疫病与收储政策 |
| 公用事业类 | 价格管制、燃料成本、来水与利用小时 |

- 行业景气度受哪些因素影响（核心驱动因素）——找出当前行业的"方向盘"：哪个因素的变化最能影响行业景气
- 方向盘当前指向与周期位置：景气向上/持平/向下？未来是否有拐点迹象？
- 判断逻辑：用数据和事实支撑景气判断
- 供给端现状：产能、产量、新增产能
- 需求端现状：销量趋势、下游需求变化
- 有无供需失衡：供不应求/供过于求
- 供需谁的边际变化更大，未来供需演变如何影响销量和售价
- **下游资本开支周期定位**（需求端先行指标，判断公司订单/业绩可持续性）：
  - 下游客户当前处于资本开支**扩张期还是收缩期**？
  - 这一轮扩张/收缩**已持续多长时间**？
  - **预计还会持续多久**，有无拐点信号（下游CAPEX增速见顶/回升、扩产计划公告）？
  - 对公司的影响**是否有数据验证**（在手订单、合同负债、收入增速与下游CAPEX拐点同步），而非仅凭预期？
- 周期性风险、产能过剩等经营风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」，触发结论须在本节分析中承接

**2.5 政策与监管环境**
- 监管强度：行业是高度监管（牌照制）还是市场化？
- 政策趋势：近期政策是收紧还是放松，鼓励还是限制？
- 政策影响机制：政策如何影响行业——准入门槛？价格管制？税收补贴？环保要求？
- 政策风险：有没有潜在的政策变化可能颠覆行业格局（行业政策收紧等经营风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」）
- 利润池再分配：环保、碳排放、能耗双控等政策是否对产业链某环节的成本冲击更大，从而改变利润分配？

### 数据需求

- 行业历史营收与利润波动幅度（过去 5-10 年，含下行年份的回撤深度）：判定行业属性标签（周期型/成长型/防御型）与周期波动强弱的依据（支撑 2.1）
- 行业资本密集度与技术迭代速度的判断依据：CAPEX/收入、技术路线更替周期（支撑 2.1）
- 下游客户结构（B/C/G端占比）（支撑 2.1）
- 产业链各环节利润率对比与价值分布（判断行业处于微笑曲线哪一端；取数同维度四 4.2「价值分配」）（支撑 2.1）
- 行业规模（TAM/SAM/SOM）、行业增速（过去3年+未来预测）、渗透率（当前+对标发达国家）、增长驱动因素（支撑 2.2）
- 行业集中度（CR3/CR5/CR10）及变化趋势、主要玩家市场份额（支撑 2.3）
- 行业进入壁垒的量化依据（资金门槛、技术门槛、牌照要求、品牌投入）与行业竞争方式（支撑 2.3）
- 利基市场规模、龙头市占率及可持续性（支撑 2.3）
- 行业景气指标的当前值和趋势（支撑 2.4）
- 供给端：产能、产量、新增产能投放计划；需求端：销量趋势、下游需求变化（支撑 2.4）
- 产能利用率/开工率、产成品与渠道库存水平（供不应求/供过于求的直接判据；渠道库存若不可得，可用产成品存货同比 + 经销商调研信息代理，并注明代理关系）（支撑 2.4）
- 下游客户资本开支/扩产周期数据：扩张或收缩、持续时长、拐点信号（支撑 2.4）
- 产品价格趋势（判断供需失衡对售价的影响）（支撑 2.4）
- 行业监管框架、近期政策文件与监管动向；政策对产业链各环节的差异化成本冲击（判断利润池再分配；产业链利润率数据同维度四 4.2「价值分配」）（支撑 2.5）

## 维度三：竞争格局

### 核心问题

与谁竞争，竞争的底层逻辑是什么，公司的差异化优势在哪？

### 分析要点

**3.1 竞争对手画像**
- 列出3-5个主要竞争对手，以段落形式逐一简述：营收规模、市场份额、行业地位、核心优势
- 行业龙头是谁，公司与龙头的差距在哪、在缩小还是扩大
- 差距对应的成长空间：行业增量、存量替代、品类扩张、区域扩张、价值链延伸

**行业对标速览**（三参照系逐项填写，不得留空；缺数据的单元格注明原因）：

| 对比维度 | 行业平均 | 行业龙头 | 本公司 | 公司在行业中的位置 |
|----------|----------|----------|--------|-------------------|
| 营收 | ... | ... | ... | [领先/中等/落后] |
| 营收增速 | ... | ... | ... | [领先/中等/落后] |
| 毛利率 | ... | ... | ... | [领先/中等/落后] |
| 扣非净利率 | ... | ... | ... | [领先/中等/落后] |
| ROE（净资产收益率） | ... | ... | ... | [领先/中等/落后] |
| 研发费用率 | ... | ... | ... | [领先/中等/落后] |

> 对标速览的目的是"三秒定位"——公司在行业中处于什么位置，是一目了然的领先者还是追赶者。

**3.2 竞争本质与差异化优势**
- 这个行业，本质上竞争的是什么（价格？技术？品牌？渠道？服务？规模？）
- 竞争要素成立的逻辑是什么
- 最为核心的竞争要素是哪个
- 公司是否存在产品同质化问题
- **差异化优势逐项检视**：
  - 是否具有可靠的品牌忠诚度（消费者是否愿意为品牌溢价买单？复购率如何？品牌心智是否稳固？）
  - 是否具有规模和成本优势
  - 是否具有渠道话语权（能否掌握渠道定价、铺货节奏、终端陈列等，还是被渠道反制）
  - 是否具有技术壁垒、牌照壁垒或区域壁垒（专利/认证/批文/地理独占等，能否有效阻挡新进入者）
  - 是否具有经济特许权和定价权
  - 是否具有不可替代性
  - 是否具有客户黏性高和转换成本高的特性
  - 是否具有网络效应甚至飞轮效应（用户越多→平台价值越大→吸引更多用户，如电商/社交/操作系统；飞轮=各业务模块互相增强、协同加速）
- **竞争格局结论**（逐项填写，不得省略）：
  - 公司差异化评估：...
  - 定价权：[强/中/弱/无]

**3.3 竞争动态性与跨行业颠覆者**

静态优势不等于动态优势——护城河要在对手反击和跨界冲击的推演中检验：

- **对手反击推演**：面对公司的优势，对手最可能怎么反击？价格战？渠道封锁？专利诉讼？并购对抗？每种反击对公司的杀伤力多大、公司有无应对预案
- **动态稳固性**：公司的静态优势在动态博弈中是否稳固？优势是越打越大（正反馈），还是会被消耗殆尽（消耗战）
- **跨行业颠覆者**：谁最不可能进入这个行业，而它一旦进来就能改变一切？（典型如互联网巨头切入传统行业、上下游巨头跨界整合）其切入的动机、路径和时间窗口是什么
- **颠覆预警信号**：当前是否已出现跨界者试探性进入、技术路线收敛、用户需求迁移等早期信号（竞争加剧、技术颠覆风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」）
- **替代品威胁**：是否存在功能相同但成本更低、体验更好或技术更先进的替代方案？替代品是渐进替代还是降维打击？
- **新进入者威胁**：行业进入壁垒是否在降低？潜在进入者来自上下游延伸、跨界巨头还是技术革命？它们可能以何种方式改变竞争规则？

### 数据需求

- 3-5个主要竞争对手的营收/营收增速/毛利率/扣非净利率/ROE/研发费用率/市场份额，及行业平均与行业龙头同口径基准值（支撑 3.1）
- 客户复购率/留存率（若不可得，可用大客户集中度变化与合同负债/预收款趋势代理，并注明代理关系）、转换成本的具体体现（合同期限、账期结构、迁移代价）、网络效应指标（仅平台型/双边市场公司需填：用户或节点规模、活跃度、双边增长关系；其余业务模式标注"不适用"）（支撑 3.2 差异化优势逐项检视）
- 定价权判断依据：提价历史与提价后的销量反应（同维度一数据需求，为定价权判定的主证据；需求价格弹性直接以该反应定性判断，不单独列取数项）（支撑 3.2 竞争格局结论的定价权判定）
- 对手扩产/降价/并购动向（支撑 3.3）
- 替代品价格/性能/渗透率及技术路线进展
- 潜在新进入者动态（跨界布局、融资、产能规划）

## 维度四：产业链

### 核心问题

公司处于产业链什么位置，上下游分别是谁，价值在链条中如何分配？

### 分析要点

**4.1 产业链上下游与议价能力**
- 上游是谁：供应商类型、集中度、景气度
- 下游是谁：客户类型、集中度、景气度
- 上下游各自的议价能力强弱
- 下游客户对公司产品价格是否敏感
- 是否存在关键供应商依赖（单一供应商占比过高）
- 是否存在大客户依赖（单一客户占比过高）
- 客户/供应商依赖风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」（客户侧：单一客户依赖、客户集中度偏高；供应商侧：单一供应商依赖、供应商集中度偏高）

**4.2 价值分配**
- 利润池分布：利润主要被产业链哪个环节获取
- 利润池迁移：未来3-5年利润池向哪个环节迁移——技术、渠道、品牌、数据谁在抢夺利润？产业链是纵向一体化还是专业化分工？
- 公司处于产业链中价值获取较高的环节还是较低的环节
- 产业链中竞争格局最优的是哪个环节，高价值环节的龙头公司是谁
- 是否有平台型企业重构产业链？渠道变革（电商、直播、DTC/直营）对传统权力结构的影响

**4.3 全球化**
- 公司是否有全球化布局，进展如何
- 国际竞争地位（跟随者/挑战者/领导者）
- 国内外营收分别占比多少
- 业务是否容易受国际地缘冲突影响
- 地缘风险是机遇还是威胁

### 数据需求

- 前五大供应商占比、前五大客户占比
- 上下游行业景气度数据：上游供给格局与下游需求景气（支撑 4.1）
- 下游客户对公司产品价格是否敏感的判断依据（支撑 4.1；可引用维度一"提价历史与提价后的销量反应"）
- 应收/应付/存货周转天数与账期结构（上下游议价能力的代理指标）
- 产业链各环节利润率对比与利润池迁移动向、各环节集中度与主要参与者（判断高价值环节的龙头公司）
- 主要平台型企业及其对产业链权力结构的重构影响
- 渠道结构占比（经销/直营/电商/直播/DTC）、平台费率/渠道扣点（若不可得，可用销售费用中的平台服务费/佣金占比代理，并注明代理关系）、DTC增速与占比
- 国内外营收占比、海外产能/渠道布局情况

## 维度五：治理与文化

### 核心问题

股权是否健康合理，管理层是否值得信任，文化是加分项还是减分项？

### 分析要点

本维度治理类条目（诚信、关联交易、质押、减持、审计意见、母公司风险传导等）与 `references/risk-checklist.md` 「二、治理风险」口径对齐，Phase 3 风险排查结论须在本维度评价中承接体现。

**5.1 实控人与股权结构**
- 实际控制人持股比例、控制方式
- 股权结构是否合理（有无一股独大、家族化等问题）
- 是否诚信守法（有无负面事件记录）、有无治理瑕疵（关联交易、利益输送等）；重大诉讼/处罚风险的识别口径见 `references/risk-checklist.md` 「三、经营风险」
- 有无股权质押风险、有无对个人的过度依赖

**5.2 管理层与企业文化**
- 有无管理层频繁变动、有无管理层频繁减持
- 企业文化有没有值得称道之处，有没有利润之上的追求（使命/愿景是否真诚而非口号）
- 诚信记录：历史上是否有财务造假、美化财报、关联交易或其他损害股东利益的记录
- 财报态度：企业是否能严肃认真地对待财报发布，是否有过敷衍马虎、错误低级的记录
- 审计质量：审计财报的会计师事务所是否信用可靠，审计结论是否是无保留意见

**5.3 人员组织能力**

上下同欲、人尽其才的治理"软实力"，从以下几方面看：

- **人均创利**：人均创利是否优于同行？反映组织整体效率
- **人均薪资**：人均薪资是否优于同行？低于同行可能人才流失，高于同行需看是否匹配产出
- **核心人才稳定性**：核心管理层和关键技术人才流失率是否正常？核心人才离职对业务的影响有多大？
- **高管收入合理性**：高管薪酬与同行相比是否合理？薪酬与绩效是否挂钩？
- **员工流失率**：整体员工流失率是否处于行业正常水平？如有异常波动，原因是什么？
- **员工满意度**：员工满意度反馈如何？有公开信息（如招聘平台评价、社交媒体口碑、员工净推荐值）则据此侧面评估，无公开信息则标注"信息不足/待验证"，不作为评分依据

**5.4 股东回报**
- 是否重视股东回报、是否能保持长期稳定的分红（参考分红募资比：累计分红/累计再融资，长期分红少于融资需警惕）
- 是否有通过回购注销等操作进行市值管理
- **适用前提**：先确认公司是否为高股息标的（股息率与分红水平显著高于同业及自身历史、且分红具备连续性）。适用时先用一句给出判据（当前股息率及与同业/自身历史/无风险利率的对比）再展开三问；不适用时无须声明不适用，直接就与本公司相关的问项作答（如第三问的资本配置取舍：分红/回购/再投资的优先级）
- **高股息可持续性三问**（看到高股息率不要急着当"现金牛"抄底，先逐问回答并给出证据）：
  - 第一问·这份高分红从哪来：是真实盈利与自由现金流支撑，还是靠账上存量现金、甚至举债分红？股利支付率与净利润含金量（经营现金流/净利润）能否说明分红有真金白银兜底，而非透支家底或"借钱发红包"？
  - 第二问·这种高分红能持续多久：盈利与现金流是否稳定、足以支撑未来延续？公司是成熟期现金牛（可持续）还是正处周期景气顶部（盈利见顶后分红难继）？未来有无大额资本开支需求会挤占分红（联动6.2资本开支信号反转）？
  - 第三问·高分红是不是最优资本配置：把利润大比例分掉，是因为没有好的再投资机会（增长见顶，分红是诚实的次优解），还是ROIC明明高于资本成本却不愿投入（可能短视或治理问题）？分红与回购的取舍是否得当——股价低估时回购注销往往比分红更能增厚每股价值（且有利税收递延），公司选对回报工具了吗（呼应本节回购注销项）？高股息率是否只是股价大跌被动抬高的"价值陷阱"（联动7.2估值匹配度）？

**5.5 股权激励**

- 最近一年内是否有股权激励计划推出或行权
- 考核标准是否良性：业绩考核目标是否具有实质挑战性（太低=变相发福利，太高=形同虚设）？考核指标选择是否合理（营收/利润/ROE等是否覆盖核心矛盾）？
- 能否带来实质性业绩提升：激励对象是否覆盖核心业务骨干？激励规模是否足够产生绑定效应？行权价与当前股价的关系（深度实值/虚值传递的信号不同）
- **市场态度**：方案公告后股价反应如何、机构点评观点是认可还是质疑？市场主要质疑点是什么（考核太松、激励过度、利益输送嫌疑）？

**5.6 母公司风险传导**

母公司风险是否传导至上市公司，从触发到影响层层展开：

- **融资平台化风险**：母公司是否将上市公司作为融资平台？是否存在资金占用、违规担保、非公允关联交易？
- **触发条件**：风险在什么情况下会被引爆？—— 母公司债务违约、经营恶化、监管处罚、实控人变更等
- **传导路径**：风险通过什么渠道影响上市公司？—— 担保链条（交叉担保/连带责任）、关联交易（应收应付/资金拆借）、品牌连带（声誉受损）、股权冻结/拍卖
- **影响程度量化**：最坏情况下对上市公司的影响有多大？—— 利润侵蚀比例估计、融资能力受损程度、控制权变更风险、品牌独立性评估

> 核心判断：上市公司在多大程度上能"独立于"母公司生存？如果母公司明天出问题，上市公司能否安然无恙？

### 数据需求

- 实控人/管理层履历和持股、股权质押比例、减持记录、监管处罚/诉讼记录
- 管理层变动记录（近3年）
- 历年审计意见、审计师变更记录、财报更正记录（支撑 5.2）
- 人均创利和人均薪酬（对比同行）
- 董监高薪酬明细与同行对比、薪酬与业绩挂钩情况（支撑 5.3 高管收入合理性）
- 员工人数、员工流失率与核心人才离职记录（流失率若不可得，可用员工人数同比变动 + 招聘岗位数变化代理，并注明代理关系；核心人才离职记录以公告披露范围为限）（支撑 5.3）
- 员工满意度公开信息（招聘平台评价、社交媒体口碑等；支撑 5.3，非白名单信源须标注"⚠️ UGC内容，可能存在偏差"，无公开信息则标注"信息不足/待验证"，不作为评分依据）
- 分红记录和回购注销记录（近5年）
- 股息率、股利支付率、分红募资比（支撑 5.4 高股息可持续性三问）；第一问所需的净利润含金量（经营现金流/净利润）取数同维度六数据需求
- 股权激励方案明细（支撑 5.5；其中"市场态度"问项所需的公告后股价反应与机构点评，见维度七数据需求"近1年股价走势与事件对照""券商一致预期"）
- 母公司资产负债率、有息负债规模与到期债务分布（支撑 5.6）
- 上市公司对外担保明细（被担保方、金额、到期日）、关联交易明细、资金占用与违规担保记录（支撑 5.6）

## 维度六：财务质量

### 核心问题

成长和盈利质量如何，财务有没有隐藏的风险？

> ⏱️ **时间跨度要求**：所有财务指标至少覆盖最近3个完整财年 + 最近4个季度（含最新季报）。仅看单期数据是危险的——趋势比绝对值更重要。同比看方向，环比看边际变化。

### 分析要点

本维度财务风险类条目（盈利质量、应收、存货、商誉、研发资本化、并购、表外负债/或有负债等）与 `references/risk-checklist.md` 「一、财务风险」口径对齐，Phase 3 风险排查结论须在本维度评价中承接体现。

**6.1 成长与盈利质量**
- 盈利质量（毛利率、净利率、ROE（净资产收益率）、ROIC（投入资本回报率））是否优于行业平均
- 用杜邦三要素（净利率、资产周转率、权益乘数）拆解ROE，与对手对比
- 成长能力（营收增速、利润增速、扣非增速）是否优于行业平均
- 扣非净利润增速与营收增速的匹配度：差距拉大说明利润含金量下降
- **适用前提**：先确认公司是否为高增长标的（营收/利润增速显著优于行业平均）。适用时先用一句给出判据（近3年营收/扣非增速及与行业平均的对比）再展开三问；不适用时无须声明不适用，直接就与本公司相关的问项作答（如第一问的增长来源归因：beta/alpha、内生/并购；第三问的再投资强度）
- **成长质量三问**（看到高增长公司不要急着冲进去，先逐问回答并给出证据）：
  - 第一问·为什么能增长这么快：是行业整体爆发（beta）还是自己真的比对手强很多（alpha）？若靠beta，行业退潮它也会被卷走，退路在哪？若靠alpha，有什么护城河（见1.2）能挡住竞争对手蜂拥而入？同时核查来源结构：内生增长还是并购驱动（内生更可持续）？
  - 第二问·这种增速能持续多久：一年两年，还是五年十年？结合3-5年趋势（加速/稳定/放缓）与行业增速、产能/渠道扩张空间判断；若只能持续一两年，当前估值就是在为一两年的景气买单——景气结束后靠什么支撑估值（联动7.2估值匹配度）？
  - 第三问·维持增速需要花多少钱：赚来的利润是自由现金流，还是得马上再投资？若需要不断烧钱才能维持增长，这种增长对股东是价值创造还是价值毁灭（联动6.2 FCF与资本开支信号反转验证、ROIC对比资本成本）？

**6.2 现金流与资本开支**
- 净利润与经营现金流匹配度：长期偏离需探究原因（应收账款过多？收入确认激进？还是商业模式特性）；营运资本占用（应收账款+存货-应付账款）及其占营收比例：占比稳定或下降为健康，持续攀升说明现金被应收/存货占用、现金流质量下降。具体指标口径与常见陷阱见 `references/financial-indicators.md` 「三、现金流与盈利质量」
- 利润为负但现金流为正：深入探究原因——是商业模式特性（如预收款模式）、折旧摊销影响、资产减值，还是其他。识别标准与真伪判断见 `references/financial-indicators.md` 「三、现金流与盈利质量」
- 是否拥有可持续的自由现金流（FCF（自由现金流）= 经营现金流 - 资本支出）
- 资本开支性质：维持性的（维持当前经营，不投就下滑）还是扩张性的（为未来增长，投了能增收）？资本开支/经营现金流比例是否合理？
- 资本开支的信号反转验证：同一笔资本开支既可能是"估值毒药"也可能是"增长引擎"，取决于三个条件是否**同时成立**——① 收入加速增长（营收增速环比抬升，证明需求真实存在）；② 利润率扩张（毛利率/净利率连续环比上行，证明商业模式成立）；③ 未履约订单持续堆厚（在手订单/合同负债环比增长，证明增长可持续）。三者齐备时，市场不再把资本开支视为利润的对立面，而是未来收入的先行指标；缺任何一条，扩张性资本开支仍按"侵蚀自由现金流、产能过剩风险"的传统口径解读，并需额外审视该开支的必要性。

**6.3 运营效率与动能**

运营效率决定公司是"轻装上阵"还是"负重前行"，经营动能决定未来收入是"有底气"还是"看运气":

- 在手订单：当前在手订单金额及同比变化？在手订单/年营收比例多高？订单覆盖倍数上升=未来收入确定性增强，下降=需求可能走弱
- 产能利用率：当前处于什么水平（满产/正常/闲置）？利用率上升说明需求旺盛、规模效应释放；下降意味着需求不足、单位成本上升
- 库存周期位置：处于去库存阶段还是补库存阶段？库存周期的位置对短期业绩有前瞻意义——去库存末尾往往对应利润拐点
- 费用传导效率：费用支出能否正向传导到营业收入？销售费用/管理费用/研发费用的增速是否低于营收增速？费用率趋势是改善还是恶化？如果费用增速持续超过营收增速，说明投入产出效率在下降
- 费用控制能力：销售费用率、管理费用率是否低于同行且趋势稳定 → 反映管理精细化水平
- 资产周转效率：总资产周转率、存货/应收账款周转是否快于同行 → 反映"用同样的资产创造更多收入"的能力
- 折旧摊销对利润的影响：折旧和摊销目前侵蚀了多少利润？占比高说明是重资产模式，利润受折旧政策影响大，且折旧到期后是否需要新一轮资本开支？

## 维度七：市场博弈

### 核心问题

市场如何定价这家公司？悲观预期定价了吗，预期差在哪里，市场在等哪些边际变化与拐点信号？

### 分析要点

**7.1 多空博弈与预期差**

从多空双方的角度审视当前股价，判断市场认知是否存在偏差：

**多头逻辑（看多因素）**：
- 当前市场对公司股价的看多逻辑是什么（列举具体理由和论据）
- 多头的一致预期是什么（营收/利润增速、估值目标）
- 多头的核心假设是什么？这些假设是否合理？

**空头逻辑（看空因素）**：
- 当前市场对公司的看空逻辑是什么（列举具体理由）
- 空头的核心论据是什么？这些论据有没有被近期数据证明或证伪？

**定价与预期差**：
- 当前股价是否已经充分反映了多头和空头的预期？多空双方谁的逻辑更占上风？
- 是否存在未被市场（充分）定价的预期差——无论是未被认知的积极因素，还是被忽视的风险？
- 如果存在预期差，它的来源是什么？（信息不对称？市场偏见？认知滞后？）
- 预期差一旦被市场意识到，对股价的冲击力有多大？

**7.2 估值匹配度**

- **增长质量先行判断**：扣非净利润增速与营收增速的变化趋势是在边际改善还是边际恶化？扣非增速是否跟上营收增速（差距拉大=利润含金量下降）？营收增长但利润增长乏力=规模扩张没有转化为盈利提升，"成长"的成色要打折。连续多期趋势比单期绝对值更重要
- 当前估值（PE（市盈率）/PB（市净率）/PS（市销率）/EV/EBITDA（企业价值/息税折旧摊销前利润）等）是否与公司的成长能力和盈利质量相匹配
- 是否存在价值陷阱（低估值是因为基本面在恶化而非市场误判）
- 估值处于历史什么分位
- **分位联动核查**：PE/PB 处于自身历史 95% 以上分位时，按 `references/risk-checklist.md` 「四、市场风险」口径联动核查（记 🔴 极高估）

**估值参考框架**：见 `references/risk-checklist.md` 「四、市场风险」「估值参考框架（分析用参考）」（分析用参考，不计入报告正文；维度七分析需要时回读该节）。

**7.3 驱动因素与催化剂**
- 当前驱动归因：股价是业绩驱动还是题材驱动？当前业绩增长驱动因素有哪些？
- 历史极值点驱动复盘（把上述归因延伸到历史，验证驱动因素是否可持续、可复制）：
  - 先定位后归因：先锁定历史高/低点的时点与价位（口径见下方「数据需求」），未给出具体时点与价位不得进入归因。
  - 历史高点：由什么驱动（业绩爆发/估值扩张/题材炒作/宏观流动性）？这些因素如今是否仍存在、是否可复制？对当前估值锚定与上行空间是否仍有参考价值？
  - 历史低点：由什么驱动（业绩崩塌/极端悲观/系统性危机）？与当时相比基本面是改善还是恶化？是否出现基本面持续恶化但股价不再创新低的背离现象？
- 未来催化剂：未来3-12个月催化剂（财报、新品、订单、政策、行业会议等）。
- 叙事与预期：市场主流叙事是什么？是否过度乐观/悲观？催化剂是否已被提前交易？

**7.4.2 拐点判断与投资逻辑重构**

逐层判断：

- **拐点确认**：多个指标同向→置信度高；单一指标→偶发波动。拐点性质：周期性（行业景气波动，可逆）vs 结构性（竞争格局改变，不可逆）
- **商业模式是否重构**：边际变化是否大到改变"公司凭什么赚钱"？重构标志：收入结构质变（如卖产品→卖服务）、客户群根本切换（如ToC→ToB）、成本结构颠覆性变化。如果商业模式在重构，新模式下护城河是否更强？
- **投资逻辑是否重构**：原来的投资逻辑还成立吗？如果原来投的是"高成长"，增速中枢下移后逻辑是否变为"价值分红"？如果逻辑变了，新逻辑的核心假设是什么？什么信号能验证新逻辑？
- **估值体系是否重构**：估值锚是否偏移？例如：PEG→PB、PS→PE、成长股折现→股息率锚定。市场是否已开始用新估值体系定价？新旧体系下合理股价区间分别是多少？

## 维度八：决策参考

### 核心问题

公司的投资逻辑与机构观点如何？五端如何演变、三情景下值多少钱，后续跟踪什么、何时重新评估？

### 分析要点

**8.1 底层逻辑与机构观点**
- 从长期视角看，投资这家公司的底层逻辑是什么
- 投资确定性的等级（高/中/低，为什么）
- 投资属性定位（成长/价值/周期/防御/困境反转）：主属性、次属性及定位理由
- 外资（如适用）对该公司持怎样的投资观点
- 公募基金对该公司持怎样的投资观点
- 私募/游资对该公司持怎样的投资观点
- **主要分歧点**：不同机构之间的核心分歧是什么？分歧的本质是对什么变量的判断不同（行业景气/公司竞争力/管理层/估值）？
- **各方关注的拐点信号**：多头在等什么信号来验证判断？空头在等什么信号来改变看法？市场共识的拐点触发条件是什么？（例如：单季利润转正、新产能投产、政策落地、管理层变动等具体可观测事件）
- 机构观点分歧的启示：分歧大→市场未形成共识，股价波动空间大，超额收益来自正确判断方向；分歧小→市场预期趋于一致，超额收益来自对一致预期的证伪
- **本报告判断与市场共识的差异**：本报告结论与市场共识（券商一致预期、主流叙事、机构多空倾向）的分歧在哪、本报告站在哪一侧？凭什么本报告更对？若判断成立，价格将何时、如何修正（触发条件与时间窗口）？（预期差的来源与量级已在 7.1 分析，本条用于明确本报告自身的立场）

**8.2 投资大师匹配**

> 输出要求（固定两段，按序输出；下方 10 位大师为**分析核对清单**——分析时逐位核对、不得省略，但严禁在报告中逐位罗列输出）：
> - **最像的大师（1-3 位）**：每位一行——大师姓名 + 命中的关键特征 + 一句话理由
> - **明确不符**：一行点名（如"与格雷厄姆、施洛斯、邓普顿的偏好明显不符"），不逐位展开
>
> 若 10 位全部不符，明写"无大师偏好与本标的特征匹配"，并补上最接近的一位及其差距。

从商业模式和资产质量角度，判断该公司更接近哪位投资大师的偏好。这不是选股推荐，而是通过大师视角帮助理解公司的基因：

- **沃伦·巴菲特**偏好：强护城河+高ROE+稳定现金流+消费垄断属性+简单易懂的生意 → 公司是否有这些特征？
- **查理·芒格**偏好：高质量+合理价格+优秀管理层+不做傻事 → 公司是否符合"以合理价格买好公司"？
- **段永平**偏好：好生意+好文化+好价格+足够大的护城河 → 公司的商业模式和文化是否"一眼看上去就知道是好的"？
- **彼得·林奇**偏好：成长性+PEG合理+身边可感知+业务简单 → 公司是否属于"从生活中发现的成长股"？
- **霍华德·马克斯**偏好：逆向思维+低预期+安全边际+周期判断 → 公司当前是否处于"别人恐惧时我贪婪"的时点？
- **本杰明·格雷厄姆**偏好：极度低估+高安全边际+净资产折价+烟蒂股 → 公司是否足够便宜（不关心质地）？
- **沃尔特·施洛斯**偏好：低PB+分散+耐心+不关心"故事" → 纯粹从估值角度，是否有施洛斯式吸引力？
- **瑞·达利欧**偏好：债务周期+全天候思维+风险平价+宏观视角 → 公司处于债务周期和宏观周期的什么位置？资产负债表是否经得起极端情景压力测试？
- **约翰·邓普顿**偏好：极度悲观+全球视野+逆向抄底 → 公司是否正处于"最大悲观点"，被情绪错杀？
- **乔治·索罗斯**偏好：反身性+趋势强化+泡沫参与+拐点识别 → 价格和基本面之间是否存在自我强化的正反馈？

> 核心价值：大师匹配不是贴标签，而是借大师框架审视公司——"如果XX大师看到这家公司，他会问的第一个问题是什么？"


**8.3 五维度推演与情景分析**（五维推演逐端、三情景逐行，均不得省略）
- **五维度推演**（段落形式输出，不得省略；逐一推演以下五个端未来 1-3 年的变化，每端写明四要素：变化方向（↑/↓/→）、对公司营收的影响、对公司利润的影响、支撑逻辑和数据）：
  - 供给端：[变化方向；对营收/利润的影响；支撑逻辑和数据]
  - 需求端：[变化方向；对营收/利润的影响；支撑逻辑和数据]
  - 价格端：[变化方向；对营收/利润的影响；支撑逻辑和数据]
  - 销量端：[变化方向；对营收/利润的影响；支撑逻辑和数据]
  - 成本端：[变化方向；对利润的影响；支撑逻辑和数据]（成本端变化不直接影响营收）

- **情景分析**（用乐观/中性/悲观三种情景推演三年后的利润与估值，检验安全边际是否真正成立）：

  | 情景 | 核心假设 | 三年后利润 | 对应估值 | 隐含回报 |
  |------|----------|-----------|----------|----------|
  | 乐观 | [向好的关键假设变量] | ... | ... | ... |
  | 中性 | [最可能发生的假设] | ... | ... | ... |
  | 悲观 | [风险兑现后的假设] | ... | ... | ... |

  - **假设透明**：每个情景写明核心假设变量（增速/利润率/估值倍数），不靠调结论而靠调假设
  - **悲观情景检验**：悲观情景下仍可接受，安全边际才真正成立；若连中性情景都依赖激进假设，需谨慎
  - **赔率不对称性**：乐观情景的上行空间是否明显大于悲观情景的下行风险，不对称性越强越好
  - **回报预期**：情景分析基础上，设立合理的年化收益率目标，并说明该预期基于什么假设

## 使用说明

- 8个维度在快速摘要阶段仅需一句话速览，完整报告阶段在对话中全维度展开
- 不同行业侧重点不同：消费行业重品牌心智和情绪价值（维度一），制造行业重产能周期和成本结构（维度二+六），科技行业重技术颠覆和竞争本质（维度三），周期行业重供需格局和价格弹性（维度二+八）
- 每个维度的分析深度可根据信息可获取程度灵活调整；数据不可直接获得时按 `references/data-sources.md`「降级策略」处理（代理指标优先、确无路径则标注待验证），**不得估算、不得编造数值，也不得以行业数据冒充公司数据**
- 各维度之间存在交叉关联，分析时应关注交叉验证（如维度一的"战略方向"与维度八的"五维度推演"需逻辑一致）
