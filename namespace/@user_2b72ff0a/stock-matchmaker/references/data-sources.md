# 数据源白名单

本文件定义基本面分析优先使用的数据来源。分析时遵循白名单优先原则——同一类数据，优先从以下来源获取；白名单无法覆盖时，再用通用搜索补充，但须标注信源。

---

## 一类：公告与财报（一级信源，最优先）

| 用途 | 来源 | 说明 |
|------|------|------|
| 公告/年报/季报原文 | **巨潮资讯网** (cninfo.com.cn) | 证监会指定信息披露平台，最权威 |
| 招股说明书 | **巨潮资讯网** | 了解公司商业模式、行业地位、历史沿革的一手资料 |
| 财务数据 | **东方财富** (eastmoney.com) | 财报数据、财务指标；旗下天天基金 (fund.eastmoney.com) 可查公募基金持仓变化 |
| 财务数据 | **同花顺** (10jqka.com.cn) | 财报数据、财务指标 |
| 财务数据 | **万得/Wind** | 机构一致预期、盈利预测、财务比率 |
| 问询函/监管函原文 | **交易所监管信息页**（上交所/深交所官网） | 问询函与回复、监管措施的一手来源 |
| 行政处罚/立案调查原文 | **证监会及地方证监局官网** (csrc.gov.cn) | 行政处罚决定书、立案告知的一手来源 |
| 诉讼判决原文 | **裁判文书网** (wenshu.court.gov.cn) | 重大诉讼核查的一手来源 |
| 被执行/失信记录 | **中国执行信息公开网** (zxgk.court.gov.cn) | 被执行人、失信被执行人查询（母公司信用状况核查） |

> 原则：营收/利润/ROE/毛利率等核心财务数据必须追溯至年报/季报原文或上述白名单，不得使用二手引用。公司商业模式、行业地位等定性信息应优先查阅招股说明书。
>
> 信源分级：巨潮资讯网/交易所监管信息页/证监会官网/裁判文书网/中国执行信息公开网为**原文级**（法定披露或一手文件）；东方财富/同花顺/万得为**聚合级**（二手数据平台）。聚合级数据与原文冲突时以原文为准；"已溯源至原文"仅指核对过原文级信源，引用聚合级数据不视为已完成溯源。

## 二类：研报数据

| 来源 | 定位 | 使用原则 |
|------|------|----------|
| **东方财富研报中心** | 覆盖面广，免费 | 提取数据和逻辑，不直接采信结论 |
| **万得/Wind** | 机构一致预期、盈利预测汇总 | 一致性数据最有价值 |
| 慧博资讯 | 多机构覆盖 | 补充参考 |
| 萝卜投研 | 研报聚合 | 补充参考 |

> ⚠️ 研报使用规则：
> - 不直接采纳研报结论，独立判断
> - 标注具体机构名称和报告日期
> - 注意券商覆盖标的的天然乐观倾向——研报很少给"卖出"评级
> - 时效约束：引用超过6个月的研报须标注"⚠️ 观点可能过时"；估值与盈利预测类数据以3个月内的研报为主，超期数据仅作趋势参考

## 三类：财务风险评估

| 来源 | 覆盖内容 | 定位 |
|------|----------|------|
| **企业预警通** | 债务违约、评级下调、负面舆情、关联交易预警 | 主力 |
| **天眼查/企查查** | 股权结构、诉讼记录、行政处罚、关联方网络 | 治理核查 |
| **同花顺问财/iFinD** | 财务异常信号自动识别（大存大贷、存贷双高、商誉占比等） | 主力 |
| **新浪财经鹰眼预警** | 财报异常指标自动预警、财务粉饰风险提示 | 辅助 |

> 使用策略：
> - 白名单前三项（企业预警通/企查查/问财）作为主要风评来源
> - 鹰眼预警作为交叉验证的辅助平台
> - 如果多平台同时预警同一风险，置信度显著提高

## 四类：实时资讯

| 来源 | 定位 | 可信度 |
|------|------|--------|
| **巨潮资讯** | 官方法定披露平台 | ⭐⭐⭐⭐⭐ |
| **财联社** | 实时快讯、政策解读 | ⭐⭐⭐⭐ |
| 东方财富快讯 | 覆盖面广 | ⭐⭐⭐（警惕标题党） |
| **腾讯财经** (gu.qq.com) | 门户资讯+行情数据；行情页对页面读取工具友好（服务端渲染、反爬弱），东财/同花顺JS重页面被拦截时的备选取数路径 | ⭐⭐⭐ |
| **财新/21财经/四大证券报** | 深度调查报道、负面信息挖掘 | ⭐⭐⭐⭐（机构媒体；事实性内容仍需追溯公告原文） |
| 雪球 | 市场情绪、民间分析 | ⭐⭐（仅作情绪参考，不作为事实依据） |
| 格隆汇 | 港股/A股深度分析、市场情绪 | ⭐⭐（仅作情绪参考，不作为事实依据） |

> ⚠️ 资讯使用原则：
> - 事实性信息：优先巨潮资讯、财联社
> - 深度调查与负面信息挖掘：优先财新/21财经/四大证券报等机构媒体（负面信息对称检查的执行抓手）
> - 市场情绪观察：可用雪球，但必须标注"UGC，可能存在偏差"
> - 所有事实性判断仍需追溯至公告原文

## 五类：投资者沟通

| 来源 | 覆盖内容 | 可信度 | 说明 |
|------|----------|--------|------|
| **巨潮资讯网** | 投资者关系活动记录表、调研纪要 | ⭐⭐⭐⭐⭐ | 记录表按交易所规则经巨潮统一披露，2个工作日内公告 |
| **深交所互动易** | 投资者提问与公司回复 | ⭐⭐⭐⭐⭐ | 深市公司专用，实时公开 |

| **万得/Wind** | 机构调研记录、电话会议纪要、路演材料 | ⭐⭐⭐⭐ | 搜索功能最强，归档完整 |
| 格隆汇 | 机构调研速递（摘要式） | ⭐⭐⭐ | 辅助参考 |
| 雪球 | 用户整理版调研纪要、会议笔记 | ⭐⭐ | UGC，准确性需核实，至少找两个独立信源交叉验证 |

> 使用原则：
> - 优先查巨潮的记录表原文和互动易/e互动的一手问答
> - ⚠️ 上交所公司披露不如深交所完整，沪市公司调研信息可能需依赖Wind或雪球补充
> - 雪球整理的调研纪要仅作线索，关键信息必须回溯到官方记录表或公告验证

## 六类：行业与宏观数据

行业规模、增速、集中度等数据的指定信源，补足公司维度信源无法覆盖的行业口径：

| 来源 | 用途 | 说明 |
|------|------|------|
| **国家统计局** (stats.gov.cn) | 宏观总量、行业产值与产量 | 官方口径，最权威 |
| **央行/海关总署** | 货币金融数据、进出口数据 | 宏观与外向型行业核心变量 |
| **上市公司招股书行业章节** | 细分市场规模、竞争格局、市占率 | 保荐机构核查过的行业数据，可信度高于一般研报 |
| **行业协会年报/主管部门**（工信部等） | 行业口径统计、产业政策 | 注意协会口径可能与上市公司口径不一致 |
| **中国信通院** (caict.ac.cn) | TMT行业数据（手机出货量、5G、云计算） | 工信部直属科研机构，科技行业高频数据主力 |
| **乘联会/中汽协** | 汽车月度销量、新能源渗透率 | 汽车类标的行业景气的指定信源 |
| 付费咨询（艾瑞/IDC/弗若斯特沙利文等） | 细分行业深度数据 | 通常不可及，降级路径：以招股书行业章节+多家券商研报双源替代，标注"⚠️ 行业数据为估算口径" |

## 港股专区

港股与A股信披体系不同，以下为港股专属白名单：

| 类别 | A股白名单 | 港股白名单 |
|------|----------|-----------|
| **公告与财报原文** | 巨潮资讯网 | **港交所披露易** (hkexnews.hk) — 法定披露平台，最权威 |
| **招股说明书** | 巨潮资讯网 | **港交所披露易** — 商业模式、行业分析的一手资料 |
| **财报数据** | 东方财富/同花顺/万得 | **阿斯达克** (aastocks.com) / **经济通** (etnet.com.hk) / 万得 |
| **专业终端** | 万得 | 万得（港股覆盖完整）/ **彭博** (Bloomberg) |
| **研报** | 东方财富研报中心 | 万得 / **格隆汇**（港股起家，深度覆盖更优） |
| **风险评估** | 企业预警通/企查查/问财 | 惠誉/穆迪评级跟踪 / 港交所纪律处分公告 / 企业预警通（部分覆盖）/ **港交所CCASS股权集中度查询**（老千股排查核心工具） |
| **投资者沟通** | 互动易/e互动 + 巨潮记录表 | ⚠️ 港股无对等实时互动平台，依赖披露易（业绩公告/通函）+ 业绩会纪要 + Wind |
| **实时资讯** | 巨潮/财联社 | **阿斯达克** / **经济通** / **信报** |
| **市场情绪** | 雪球/格隆汇 | 雪球（有港股讨论区）/ **格隆汇**（港股起家，深度更强） |

**港股特有注意事项**：

| 差异点 | 说明 |
|--------|------|
| **财报准则** | 港股使用香港财务报告准则（HKFRS），与A股企业会计准则有细节差异，跨市场对比需注意口径 |
| **信披强度** | 港股无强制披露投资者关系活动记录表的规则，机构调研信息透明度不如深市 |
| **做空机制** | 港股做空成熟，需额外关注：沽空比例（每日披露）、衍生品持仓、淡仓申报 |
| **注册地** | 大量港股公司注册于开曼/百慕大/BVI，实际业务在中国大陆，法律主体与经营主体分离——股权穿透和管辖权判断需格外注意 |
| **停复牌制度** | 港交所停牌触发条件与A股不同，长期停牌风险更大 |
| **老千股风险** | 港股存在合股/供股/频繁更名等A股罕见的老千手法，财务风评需额外警惕 |

## 付费信源降级方案

以下付费终端在自动执行时通常无法直接访问（需账号授权），当它们不可及时，按下方降级路径获取替代数据，并在输出中标注"⚠️ 付费信源不可及，已降级至 [替代源]"。

### A股降级路径

| 付费信源 | 原用途 | 降级替代 | 说明 |
|----------|--------|----------|------|
| **万得/Wind** | 机构一致预期、盈利预测汇总 | 东方财富研报中心（多家券商盈利预测汇总）/ 同花顺iFinD | 免费源覆盖度略低，需手动汇总多家券商预测取中位数 |
| **万得/Wind** | 财务数据、财务比率 | 东方财富 / 同花顺 | 免费源财务数据完整性足够，比率可自行计算 |
| **万得/Wind** | 机构调研记录、电话会议纪要 | 巨潮资讯网（投资者关系活动记录表）/ 互动易·e互动 | 深市记录表覆盖完整；沪市可能需雪球补充（标注UGC） |

### 港股降级路径

| 付费信源 | 原用途 | 降级替代 | 说明 |
|----------|--------|----------|------|
| **彭博/Bloomberg** | 港股专业终端数据 | 阿斯达克 (aastocks.com) / 经济通 (etnet.com.hk) | 免费源覆盖基本面数据，深度不如彭博 |
| **万得/Wind** | 港股研报、一致预期 | 格隆汇（港股深度覆盖）/ 阿斯达克 | 格隆汇港股起家，免费内容质量较高 |

### 反爬拦截降级

当白名单网站（巨潮/东方财富/同花顺等）被反爬机制拦截、页面读取工具无法直接获取时：

1. **优先尝试搜索引擎缓存**：通过通用网络搜索"公司代码 + 年报 + 巨潮"，获取可访问的页面快照。缓存快照仅限静态披露文件（年报/公告/招股书）；实时行情与估值数据禁用缓存，缓存值不得作为估值或行情依据。
2. **降级到同类白名单信源**：如巨潮不可用，改用东方财富/同花顺获取同一财务数据。
3. **标注降级**：输出中注明"⚠️ 原信源 [X] 不可及，已降级至 [Y]，数据一致性待核实"。
4. **兜底**：若所有白名单均不可及，用通用搜索补充，并严格标注"⚠️ 非白名单信源，建议用户自行核实"。

## 工具与取数映射

白名单回答"真相在哪"，本表回答"用什么方式去取"。执行时按数据类型走"首选 → 降级 → 兜底"优先链；降级时按标注规则注明，**不停下来询问用户**。

| 数据类型 | 首选取数方式 | 失败时降级 | 标注要求 |
|----------|--------------|------------|----------|
| 实时行情（现价、市值、换手率） | 页面读取工具访问白名单站点行情页（东方财富、同花顺、腾讯财经等，腾讯财经行情页为反爬备选）；如环境提供命令行财经数据库（如AKShare），优先直接取结构化数据 | 通用网络搜索"代码 最新行情"，采用搜索结果快照 | 必须带时间戳（截至时点） |
| 估值与历史分位（PE/PB/PS及历史分位） | 页面读取工具访问白名单站点估值/数据页（如东方财富个股页） | 两个信源数据页交叉，或汇总多篇研报 | 历史分位是时间序列结论；单点数据标注"单一信源，待验证" |
| 公告/年报/招股书原文 | 页面读取工具访问巨潮资讯网、港交所披露易的公告详情页；必要时下载PDF解析 | 搜索引擎缓存快照；或改用东方财富/同花顺的同一披露文件 | 使用缓存时标注"非原文快照" |
| 结构化财务数据（三表与比率） | 页面读取工具访问东方财富/同花顺财务页 | 检索含该数据的研报，双信源汇总 | 两个出处交叉验证；每个数字附报告期 |
| 券商一致预期 | 万得默认不可达 → 直接走东方财富研报中心，汇总多家券商盈利预测取中位数 | 通用网络搜索近期多家券商评级与目标价汇总 | 标注"⚠️ 付费信源不可及，已降级至 [替代源]" |
| 风险与治理信号 | 页面读取工具访问企业预警通类平台页面 + 公告关键词排查（质押、减持、问询函、立案等） | 通用网络搜索负面新闻，两个信源交叉 | UGC信源标注"仅供参考" |
| 资金流与筹码（北向、融资、股东户数、解禁） | 页面读取工具访问东方财富/同花顺数据页 | 通用网络搜索 | 标注截至日期 |

**使用规则**：

1. 按数据类型走优先链，失败自动降级并标注，不停下来询问用户。
2. 所有取数结果携带两个字段：来源 + 截至日期（或报告期）。
3. 页面读取工具遇到JS重页面返回空内容时，优先改用该站点的移动版/简版页面或搜索缓存；若环境提供浏览器自动化工具，用浏览器工具取数。
4. 本表只规定优先链，不依赖任何特定第三方接口的稳定性；某条路径失效时立即切换。

## 白名单使用规范

**标注规则**：

| 信源等级 | 标注方式 |
|----------|----------|
| ✅ 白名单一级（公告/财报原文） | 直接引用，注明来源 |
| ✅ 白名单二级（研报/风评平台） | 引用并标注"仅供参考，不构成独立结论" |
| ⚠️ 通用搜索补充 | 标注"⚠️ 非白名单信源，建议核实" |
| ⚠️ UGC平台（雪球/格隆汇/知乎等） | 标注"⚠️ UGC内容，可能存在偏差，不作为事实依据" |

**交叉验证要求**：
- 关键结论不得仅依赖单一信源
- **行业数据（市场规模、增长率、集中度等）和核心财务数据（营收、利润、ROE等）至少需要两个独立出处交叉验证**，单一信源的行业/财务数据标注"⚠️ 单一信源，待验证"
- 财务风险评估结论需至少两个平台交叉验证
- 存在冲突的数据，标注差异并提示用户自行核实；判定以信源等级优先——原文级 > 聚合级 > 研报 > 通用搜索，同级冲突以最新报告期为准

## 搜集执行指引

Phase 1 数据搜集的执行依据：搜什么、受限怎么办。

### 搜集方向

使用网页搜索工具搜索以下七类信息。数据源遵循白名单优先：先查白名单来源，白名单无法覆盖时再用通用搜索补充。**港股标的**按上文「港股专区」取数（港交所披露易为一级信源；注意 HKFRS 准则口径差异与港股特有风险）。

1. **行业信息**：行业规模、增长趋势、竞争格局、供需状况、政策环境、景气周期。**优先从国家统计局/央行/海关总署、招股书行业章节、行业协会年报获取（见「六类：行业与宏观数据」）**
2. **公司信息**：主营业务、产品/服务、商业模式、护城河来源、战略方向
3. **财务数据**：营收、利润、ROE、毛利率、负债率、现金流、自由现金流、应收/存货/商誉等关键指标。**优先从巨潮（公告）、东方财富/同花顺/万得（财报数据）获取**
4. **风险信号**：负面新闻、诉讼纠纷、监管处罚、管理层变动、关联交易、减持记录。**优先从企业预警通、天眼查/企查查、同花顺问财获取；鹰眼预警作为交叉验证辅助**
5. **产业链**：上下游集中度、议价能力、全球化布局、地缘风险
6. **治理文化**：股权结构、管理层履历、诚信记录、分红回购、企业文化
7. **市场预期**：券商研报观点、机构持仓变化、做空因素、近期催化剂。**研报数据优先从东方财富研报中心、万得获取；实时资讯优先从巨潮、财联社获取**

**最常漏项提示**：以下细项在通用搜索中最易被跳过，却直接决定 Phase 4 若干表格能否填出。筛选标准是"非显而易见、藏在财报附注、或需跨期/跨公司/跨主体取数"，常规指标不列。搜集时逐项确认，缺项按「降级策略」处理并标注"信息不足/待验证"。

- **附注级**：存货结构（原材料·在产品·产成品）、应收账款账龄与坏账准备、预收款/合同负债余额、对外担保明细与资金占用
- **跨公司同口径**：3-5家主要对手的营收·毛利率·净利率·总资产周转率·权益乘数·销售与研发费用率·ROE·市场份额，外加行业平均与行业龙头基准值；杜邦三要素；人均创利与人均薪酬对比同行；董监高薪酬对比同行及与业绩挂钩情况
- **跨期与最新一期**：单季利润·毛利率·经营现金流·新增订单·合同负债·资本开支与在建工程；PE/PB/PS历史分位；提价历史及提价后的销量反应；下游客户资本开支/扩产周期（扩张或收缩、持续时长、拐点信号）
- **易被当作非财务项漏掉**：在手订单与产能利用率、限售股解禁时间表、股东户数与人均持股变化、分红募资比（累计分红/累计再融资）、母公司资产负债率、净现金与可变现资产、渠道结构占比（经销/直营/电商/直播/DTC）与平台费率、客户复购率/留存率与转换成本的具体体现、无风险利率与股权风险溢价（或WACC，用于ROIC对比资本成本）

> 逐维度完整清单以 `references/analysis-framework.md` 各维度「数据需求」小节为权威依据（Phase 4 读取），**Phase 1 不必读取该文件**；本提示只用于防止搜集阶段漏项，两边若有出入以框架文件为准。

### 降级策略

除上文「付费信源降级方案」与「反爬拦截降级」的降级路径外，搜集条件受限时按以下策略继续，不因单点失败中止流程，并将降级事实记入 Phase 5 前置反馈的"降级说明"：

- **网页搜索工具不可用或网络受限**：基于已掌握的可靠信息与模型既有知识继续分析，并全局标注"⚠️ 未经实时检索验证，数据可能滞后"，相关结论降为"信息不足/待验证"
- **最新报告尚未披露**：以最近一期已披露的年报/季报为准，并在数据截至日期中明示报告期
- **数据不可直接获得（如客户复购率、渠道库存、员工流失率、平台费率等）**：优先改用可得的代理指标并注明代理关系（如"以合同负债/预收款趋势代理复购率""以员工人数同比变动代理流失率""以销售费用中的平台服务费占比代理渠道扣点"）；确无代理路径的，标注"信息不足/待验证"并说明对结论的影响

## 数据可靠性自查细则

数据是分析的基石——数据不可靠，结论就是空中楼阁。本阶段对应 SKILL.md 的 Phase 2，仅内部执行，不单独输出可靠性报告，但必须按 `references/output-templates.md` Phase 5「前置反馈：简要进度反馈」模板输出自查痕迹（≤10行，逐项标注 ✅/⚠️）。逐条核验以下四项，不通过则按右列处理：

### 1. 核心财务数据溯源

| 检查项 | 通过标准 | 不通过处理 |
|--------|----------|-----------|
| 营收/利润/ROE/毛利率等核心指标 | 来自年报/季报原文或官方公告，非二手引用 | 标注"⚠️ 二手引用，建议核查原文" |
| 是否是最近一期数据 | 已确认引用的是最新一期年报/季报 | 标注"⚠️ 数据可能滞后，最新报告尚未纳入" |

### 2. 信源等级检查

- 核心财务数据是否来自白名单信源（原文级：巨潮/交易所监管信息页/证监会官网/裁判文书网/中国执行信息公开网；聚合级：东方财富/同花顺/万得；港股以港交所披露易为准）？非白名单来源标注"⚠️ 非白名单信源，建议核实"
- 行业数据（市场规模、增长率、集中度等）是否标注了具体来源和年份？
- 管理层信息（履历、持股、薪酬等）是否可追溯到公告或可靠数据库？
- 券商观点是否标注了具体机构名称和报告日期？
- UGC平台内容（雪球/知乎等）是否已标注"⚠️ UGC内容，不作为事实依据"？
- 关键数据是否均已标注"来源 + 截至日期（或报告期）"？缺失的补齐后再进入分析

### 3. 单信源依赖检查

- 行业数据与核心财务数据是否各有至少两个独立出处？仅一个信源则标注"⚠️ 单一信源，待验证：[信源名称]"
- 特别警惕：仅来自雪球/格隆汇/知乎等UGC平台的判断，不得作为关键结论的唯一依据

### 4. 负面信息对称检查

- 是否主动搜索了目标公司的负面新闻、诉讼、处罚记录？
- 是否搜索了同业可比公司的重大风险事件（作为参照）？
- 是否存在明显的"报喜不报忧"倾向？如有，补充搜索负面信息

**执行规则**：若自查发现核心数据依赖二手引用或单一信源，后续分析中必须提示用户"该结论基于有限信源，建议核实"。
