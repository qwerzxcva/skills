# 风险排查清单

本清单用于基本面分析的风险前置排查。按照"先避坑再选优"的原则，在价值分析之前系统性扫描风险信号。本阶段对应 SKILL.md 的 Phase 3，仅内部执行，不单独输出风险排查报告；排查出的风险分级结果融入「快速摘要」的「关键风险清单」和后续各维度分析中，带着风险意识做后续判断。

---

## Phase 3 数据需求

风险排查不是空中楼阁，以下数据是识别红/黄/绿灯信号的最小数据集。执行时优先从年报/季报原文、交易所公告、审计报告中提取；具体财务指标口径与阈值见 `references/financial-indicators.md`；跨维度的深度数据需求见 `references/analysis-framework.md` 对应维度。

### 财务与会计数据

- 最近 3 个完整财年 + 最新 4 个季度：资产负债表、利润表、现金流量表及财务报表附注
- 审计报告（审计意见类型、关键审计事项、审计师变更记录）
- 应收账款/存货/商誉/有息负债明细与账龄结构
- 表外负债线索：对外担保、未决诉讼、融资租赁、明股实债、隐性回购义务
- 税收优惠明细与有效税率

### 治理与股东行为数据

- 实控人/大股东股权质押比例、司法冻结/拍卖记录
- 关联交易规模、资金占用/违规担保、关联方往来明细
- 管理层与关键岗位（CFO/董秘）变动记录
- 董监高薪酬明细（与业绩挂钩情况、与同行对比）
- 董事会/独立董事运作记录、信息披露违规或立案记录

### 经营与行业数据

- 前五大客户/供应商集中度与变动
- 重大在手订单、产能利用率、库存周期位置
- 所处行业政策、监管动向、竞争格局变化
- 公司历史并购/投资标的业绩承诺与完成情况

### 市场与估值数据

- 当前 PE/PB/PS 及自身历史分位、可比公司估值区间
- 分析师覆盖、评级分布、一致预期变动
- 近 1 年股价走势、重要股东/管理层增减持、回购计划
- 解禁/减持/配股/可转债转股时间表

### 最新报告边际数据

- 最近一期季报/半年报：单季利润、毛利率、经营现金流、管理层经营评述
- 交易所问询函、业绩说明会纪要、业绩预告/快报

## 一、财务风险

> 分工锚点：本节管 Phase 3 风险排查的红/黄/绿灯信号判定（"排雷"）；财务指标的计算口径与优秀标准以 `references/financial-indicators.md`「四、财务健康」「一、盈利质量」为准，两处阈值已对齐且互补（如资产负债率 >70% 警惕、流动比率 <1 资金链紧张、研发资本化率 >30% 虚增利润）。Phase 4 维度六按 financial-indicators.md 做量化深查，并承接本节排查结论（见 analysis-framework.md 维度六承接声明）。

### 🔴 重大风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 连续亏损 | 最近2年以上净利润为负 | 企业生存能力存疑 |
| 经营现金流持续为负 | 连续2年以上经营现金流为负 | 靠融资维持，造血能力丧失 |
| 资产负债率>70%（非金融地产） | 且趋势上升 | 债务危机风险高 |
| 短期偿债危机 | 流动比率<1，现金<短期有息负债 | 可能面临资金链断裂 |
| 巨额商誉 | 商誉/净资产>30%，或并购标的业绩承诺未达标 | 减值风险极大，可能一次性吞噬多年利润 |

### 🟡 中等风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 盈利波动大 | 净利润同比波动>50%（非周期行业） | 盈利质量不稳 |
| 毛利率持续下滑 | 连续3年以上毛利率下降 | 竞争加剧或定价权丧失 |
| 净利润含金量低 | 经营现金流/净利润持续<0.7 | 利润停留在账面 |
| 应收账款增速>营收增速 | 且占比持续上升 | 回款困难，坏账风险 |
| 应收账款账龄结构恶化 | 1年以上应收占比过高或长账龄占比上升，坏账准备计提不充分覆盖长账龄应收（查财报附注） | 坏账减值风险 |
| 研发资本化率过高 | 研发支出资本化率>30%且趋势上升 | 将应费用化的研发支出资本化，虚增当期利润，后续面临减值风险 |
| 有息负债过重 | 有息负债率过高，或利息保障倍数<3（<1.5 为危险，计算口径见 `references/financial-indicators.md`） | 偿债压力大，利润被利息侵蚀 |
| 营运资金链承压 | “大存大贷”（货币资金与有息负债双高，资金使用效率存疑）或“存贷双低但应付账款高企”（占用供应商资金维持运转），或营运资金周转天数持续拉长 | 营运资金链脆弱 |
| 存货异常增长 | 存货周转天数持续上升；财报附注中产成品占比异常上升、库存商品账龄>1年的比例过高、跌价准备计提不充分 | 销售放缓或库存积压，滞销风险 |
| 并购整合存疑 | 并购标的业绩承诺期刚结束即变脸，或频繁跨界并购 | 商誉减值隐患，管理层并购能力存疑 |
| 表外负债与或有负债 | 存在大额对外担保、未决诉讼、ABS/融资租赁出表、明股实债、隐性回购义务等；或有负债/净资产>20% | 潜在偿债或现金流出未被资产负债表充分反映 |

### 🟢 轻微风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 单季业绩波动 | 个别季度低于预期 | 正常经营波动 |
| 研发投入下降 | 但核心业务仍健康 | 需关注长期竞争力 |
| 一次性损益 | 非经常性损益影响利润 | 核心盈利能力不受影响 |

## 二、治理风险

### ⛔ 治理红线（一票否决级）

以下红线命中不终止分析流程，但必须在快速摘要"关键风险清单"置顶、完整报告维度五开篇显式说明；识别标准单点维护在对应排查条目中（无对应条目的在表内注明独立标准）：

| 红线项 | 对应排查条目 | 命中后果 |
|--------|-------------|---------|
| 管理层诚信问题 | 本表独立标准：虚增收入、财务造假、挪用资金历史 | 信任崩塌，直接否决 |
| 审计意见保留或更差 | 审计意见带强调事项（保留或更差升级按本线处理） | 财务数据严重失真风险 |
| 信息披露重大违规/被立案调查 | 本表独立标准：信息披露重大缺陷、被监管立案 | 直接否决 |
| 实控人股份被司法冻结 | 本表独立标准：实控人所持股份被司法冻结或轮候冻结 | 资金链危机暴露，控制权变更风险 |

> 红线只负责标注，不负责判决——最终投资判断仍由用户自行决定。

### 🔴 重大风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 关联交易异常 | 关联交易占比>30%，定价不合理 | 利益输送嫌疑 |
| 实控人高比例质押 | 持股质押率>70% | 强制平仓风险，控制权不稳 |
| 高管/大股东集体减持或异常减持 | 高管或大股东集体减持，或频繁减持且无合理理由 | 内部人对企业前景信心不足 |
| 股权过度集中 | 单一股东>50%，缺乏制衡 | 决策风险集中，小股东利益可能被忽视 |
| 母公司风险传导 | 母公司高负债/亏损，上市公司存在资金占用、违规担保或大额关联交易嫌疑（分析框架见 `references/analysis-framework.md` 5.6） | 风险沿担保链/关联交易传导，影响上市公司融资能力和独立性 |

### 🟡 中等风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 管理层频繁变动 | 近1-2年核心管理层多次更换 | 战略稳定性存疑 |
| 独立董事形同虚设 | 独立董事全由实控人提名且无异议记录 | 治理监督缺位 |
| 审计意见带强调事项 | 审计报告带强调事项段（持续经营、重大不确定等） | 财务数据可信度打折，需逐项核实强调事项 |
| 薪酬与业绩脱钩 | 管理层薪酬持续增长但业绩下滑 | 激励机制扭曲 |
| 股权质押比例偏高 | 实控人质押比例50%-70%（>70% 见上方重大风险信号） | 平仓与控制权风险需关注 |

## 三、经营风险

### 🔴 重大风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 单一客户依赖 | 前五大客户营收占比>60% | 客户流失即致命打击 |
| 单一供应商依赖 | 第一大供应商采购占比>50%，或关键原材料/零部件单一来源供应 | 供应中断、提价直接冲击生产与毛利率 |
| 单一产品依赖 | 核心产品营收占比>80% | 产品被替代即致命打击 |
| 技术颠覆风险 | 行业出现颠覆性替代技术 | 护城河可能瞬间瓦解 |
| 重大诉讼/处罚 | 涉及金额>年利润20% | 直接冲击经营和声誉 |

### 🟡 中等风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 行业政策收紧 | 近期出台限制性政策 | 行业天花板可能下降 |
| 竞争加剧 | 行业新进入者增多、价格战 | 利润率可能承压 |
| 客户集中度偏高 | 前五大客户占比40-60% | 客户变动风险较大 |
| 供应商集中度偏高 | 前五大供应商采购占比>70% | 采购议价能力弱，成本波动风险较大 |
| 周期性风险 | 行业处于周期高点 | 业绩可能周期性回落 |
| 产能过剩 | 行业整体产能利用率<70% | 行业景气度低迷 |

## 四、市场风险

> 分工锚点：本节管 Phase 3 的**市场面**排雷（估值状态、情绪与筹码结构、上市地位），与 `references/analysis-framework.md` 维度七「市场博弈」口径对齐；估值方法的适用场景与计算要点见下方「估值参考框架（分析用参考）」，维度七 7.2「估值匹配度结论」表据此填写。

### 🔴 重大风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 退市风险警示 | 被实施 *ST/ST，或财务类/交易类指标濒临退市条款触发 | 生存危机，流动性与估值双杀 |
| 估值处于历史极端高位 | PE/PB处于自身历史95%以上分位 | 极高估，回调风险极大 |
| 市场情绪过热 | 融资余额暴增、媒体狂热、散户涌入 | 泡沫风险 |
| 估值与增速严重不匹配 | PEG>3（高PE但低增速） | 增速无法支撑估值 |
| 主流叙事过度拥挤 | 一致预期高度一致、分析师目标价趋同、持仓过度集中 | 一旦预期差出现，反转剧烈 |
| 重大解禁/减持临近 | 未来 6 个月解禁规模>流通股本的 20%，或大股东/核心高管宣布大额减持 | 流动性冲击可能导致股价大幅波动 |

### 🟡 中等风险信号

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 估值高于行业平均 | PE/PB明显高于同行业可比公司 | 需要更强的增长来支撑 |
| 估值假设乐观 | DCF模型假设增速>行业平均 | 假设不达预期则估值下调 |
| 机构分歧大 | 券商目标价差异>30% | 未来方向不确定性高 |
| 业绩承诺到期 | 大额并购标的业绩承诺期即将结束，标的历史完成率贴线或下滑 | 承诺期后业绩变脸风险 |

### 🟡 港股特有风险信号（仅适用于港股标的）

| 风险项 | 识别标准 | 影响 |
|--------|----------|------|
| 老千股手法信号 | 合股/供股/频繁更名等操作，伴随流动性下降 | 股东权益被摊薄，港股特有的典型手法 |
| 除牌风险 | 触发港交所除牌程序，或不满足持续上市准则 | 港股无A股式前置预警阶段，除牌缓冲少 |
| 长期停牌 | 因不满足上市规则被长期停牌，复牌进展停滞 | 港交所复牌时限严格，久停可能导向除牌 |

> 港股信源与市场制度差异见 `references/data-sources.md` 的"港股专区"；除牌风险等涉及港股退市判断时按 🔴（重大风险信号）处理。

### 估值参考框架（分析用参考）

| 估值方法 | 适用场景 | 计算要点 |
|----------|----------|----------|
| PE（市盈率） | 盈利稳定的公司 | 当前PE vs 历史5年分位 vs 行业均值；注意剔除一次性损益 |
| PEG | 成长型公司 | PE / 未来2-3年扣非净利润复合增速；PEG<1=可能低估，>2 需警惕（提示性），>3 记重大风险（见上文 🔴「估值与增速严重不匹配」） |
| PB（市净率） | 重资产/金融行业 | 当前PB vs 历史分位 vs ROE水平；低PB+低ROE=价值陷阱 |
| PS（市销率） | 高成长但未盈利 | 适用于早期科技/生物医药；需结合毛利率评估 |
| EV/EBITDA | 资本密集型 | 剔除了资本结构和折旧政策的影响，适合跨行业比较 |
| 可比公司估值 | 所有行业 | 选取3-5家可比公司，对比PE/PB/PS/EV/EBITDA，分析差异原因 |
| 股息率锚定 | 高分红公司 | 当前股息率 vs 历史均值 vs 无风险利率；股息率高于无风险利率+2%=安全边际较好 |
| DCF（现金流折现） | 现金流稳定可预测的公司（估值的理论基准） | 关键看假设——永续增长率、折现率（WACC）、终值；假设显著乐观于行业平均时与本节"估值假设乐观"风险信号联动核查 |

> 估值不是精确科学。核心是找到"当前估值隐含了什么假设"——如果隐含的假设是永续高增长而公司护城河正在削弱，那就不匹配。

## 五、最新报告边际信号检查

风险排查不能只看"有没有老问题"，还要专门检查**最新一期年报和最近季报**中暴露的边际变化——**风险（恶化）和亮点（改善）都要看**，并判断是否构成拐点信号。

### 风险侧——边际恶化信号

- **最新一期报告**中是否有之前年度未出现的新风险信号？例如：首次利润下滑、单季亏损、毛利率骤降、经营现金流突然转负、应收账款/存货跳升等
- **趋势是否在加速恶化**：已有风险在最新一期是缓解还是加剧？用连续多期数据判断方向
- **管理层在最新报告中的措辞变化**：年报/季报的"经营评述"部分语气是否变得谨慎？是否首次承认某些压力？

### 亮点侧——边际改善信号

- **最新一期报告**中是否出现之前未见的积极变化？例如：毛利率触底回升、经营现金流明显改善、应收账款周转加快、费用率下降、新业务放量等
- **未来收入是否已在堆积**：新增订单、合同负债是否连续回升，资本开支是否与收入增速、利润率同步扩张（三条件见 `references/analysis-framework.md` 6.2）？这类领先于利润表的信号确认越早，改善的成色越高
- **边际改善是否具备持续性**：改善是单季偶发还是连续两个季度以上？改善的驱动力是什么（一次性/结构性）？
- **管理层是否释放积极信号**：是否上调经营目标、提高分红、启动回购等？

### 拐点判断

- 综合边际风险和边际亮点，是否形成向上拐点（改善信号>恶化信号）或向下拐点（恶化信号>改善信号）？
- 拐点的驱动因素是周期性的（可逆）还是结构性的（不可逆）？
- 用数据量化拐点的置信度：多个指标同时指向同一方向时，拐点信号更可靠

> 这一步的目的是捕捉"正在发生的变化"——无论是变好还是变坏——而不只是"已经知道的毛病"。边际信号属基本面侧；市场面的筹码结构与资金博弈见 `references/analysis-framework.md` 维度七"7.4 边际变化"与"7.5 市场博弈"。恶化信号并入快速摘要"关键风险清单"，改善信号在完整报告维度七中说明。

## 使用说明

- 重大风险(🔴)只要出现一项，就要在快速摘要中重点标注，并详细说明影响
- 中等风险(🟡)需要综合判断——多项中等风险叠加可能升级为重大风险
- 轻微风险(🟢)正常提及即可，不作为主要决策依据
- 不同行业风险侧重不同：消费行业关注品牌护城河变化，科技行业关注技术替代，金融行业关注监管和资产质量
- 风险排查的目的是"排雷"而非"否定"——排查出风险后，要看风险是否可接受、可对冲、可控制
