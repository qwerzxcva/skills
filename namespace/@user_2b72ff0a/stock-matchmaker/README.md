# 股票介绍所 / The Stock Matchmaker

## 简介

「股票介绍所」是一个基本面深度分析技能，采用"婚姻介绍所"式投研框架：像帮你看清一个人那样看清一家公司，再决定要不要"迎娶"（投资）。

输入一家 **A 股 / 港股** 上市公司的公司名称或股票代码，自动生成覆盖 8 个维度的基本面研究报告：

**生意模式 → 行业特性 → 竞争格局 → 产业链 → 治理文化 → 财务质量 → 市场博弈 → 决策参考**

核心流程分为 7 个环节：

```
数据搜集 → 可靠性自查 → 风险排查 → 8 维度分析
  → 快速摘要 → 完整报告 → 逆向思维挑战
```

核心特色：

1. **数据源白名单**：优先巨潮 / 万得 / 东方财富 / 同花顺等官方或一级信源。
2. **8 维度框架**：覆盖生意模式、行业特性、竞争格局、产业链、治理文化、财务质量、市场博弈、决策参考，每个维度既追问本质，也要求数据交叉验证。
3. **逆向思维挑战**：提供 13 种挑战角色，系统性挑刺。
4. **三次评分层层递进**：初次印象分 → 深入摸底分 → 逆向考察分。

## 安装与使用

### 安装方式

**方式一：技能目录安装（推荐）**

1. 下载本技能包压缩文件并解压。
2. 将整个技能包文件夹放入宿主软件的技能目录，例如 WorkBuddy 用户级技能目录 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）或 Qoder 用户级技能目录 `~/.qoder-cn/skills/`（Windows 为 `%USERPROFILE%\.qoder-cn\skills\`）。
3. 重启宿主软件或在技能管理中刷新，确认 `the-stock-matchmaker` 出现在可用技能列表中。

**方式二：管理界面导入**

若你的宿主软件提供技能管理界面，选择"导入本地 Skill"，选中本技能包文件夹或 zip 文件完成导入。

### 触发方式

当你明确表达基本面分析意图时，技能会自动触发，例如：

- "分析股票 XX" / "分析公司 XX"
- "看看 XX 公司基本面"
- "XX 股票怎么样" / "这家公司值得买吗"
- "帮我尽调 XX" / "投资前了解 XX"
- 以"分析/研究/尽调 + 公司名称或股票代码"的方式给出标的

> ℹ️ 仅在对话中提及公司名称而未表达分析意图时，不会触发本技能。
