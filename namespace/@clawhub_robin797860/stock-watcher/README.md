# 股票疯子（stock-watcher）技能包

全天股票盯盘与分析助手，覆盖 A股 / 港股 / 美股：个股行情与技术面分析（8 维评分）、
涨幅排行、买卖参考、K 线与分时量能、支撑压力位、板块与财务数据、龙虎榜与资金流向、
异动与传闻核查、定时盯盘与预警、多源资讯检索、组合持仓梳理、经验复盘。

> 安装后在技能列表中显示名为「股票疯子」，内部标识 `stock-watcher`。

## 一、安装方法（任选其一）

**方式 A：直接放入技能目录（推荐）**
1. 将本目录整体复制为 `~/.workbuddy/skills/stock-watcher/`
   （Windows：`C:\Users\<你的用户名>\.workbuddy\skills\stock-watcher\`）。
2. 重启 / 刷新 WorkBuddy，技能即自动启用，无需任何配置。

**方式 B：通过 zip 导入**
1. 使用打包生成的 `stock-watcher.zip`。
2. 在 WorkBuddy 的「技能」面板选择「从本地文件导入」，选中该 zip 即可。

## 二、依赖说明

**无需安装任何依赖，也无需 API Key。**
本技能不自带脚本，取数走 WorkBuddy 内置能力：优先用内置金融数据工具 /
联网检索，必要时读取用户本地持仓文件或依据用户口述。取不到的数据一律标
「数据缺失」，绝不强编。

## 三、快速使用

| 用户说 | 技能做什么 |
|---|---|
| 帮我看看贵州茅台 | 8 维评分 + 技术面 + 买卖参考 |
| 今天什么股涨得好 | 涨幅排行 / 热门扫描 |
| 加入盯盘 / 我的盯盘列表 | 维护持仓与预警列表 |
| 复盘 / 我的胜率 | 交易经验梳理 |

## 五、注意事项

- 所有结论为分析参考，非投资建议；涉及买卖请结合自身判断。
- 行情数据存在延迟，以交易所 / 券商实际数据为准。
- 若内置数据工具不可用时，技能会提示改用联网检索或用户提供文件，不会卡死。
