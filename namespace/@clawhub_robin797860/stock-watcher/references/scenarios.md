# 场景执行细则（A–S）

> 本文件是 `SKILL.md` 的展开卷。SKILL.md 只留导航与硬规则，具体执行看这里。
>
> **通用前置**：每个场景开工前先确认数据来源可用（见 SKILL.md「数据获取路径」）。
> 任何字段取不到就写「数据缺失」，**不要用估算值、上一交易日值或推测值填充**。

---

## 场景A：个股查询（「看XX」）

**触发词**：看、看看、查一下、帮我看看 + 股票名/代码

**步骤**

1. 用户给的是名称而非代码 → 先解析出代码与市场（A股 6 位、港股 5 位、美股字母）
2. 取行情快照 + 近 60 根日K
3. 按 `references/scoring.md` 的 8 维评分表逐项打分
4. 按下方模板输出

**输出模板**

```
📊 【名称·代码】实时分析
━━━━━━━━━━━━━━━━━━
💰 现价 XX.XX | 涨幅 +X.XX% | 换手 X.X%
📈 趋势：多头/空头/震荡 | MACD：金叉/死叉
   MA5:XX MA20:XX | RSI:XX | 布林：上轨/中轨/下轨
🎯 压力 XX.XX | 支撑 XX.XX
📊 评分：XX/100 → [买入/持有/观望/回避]
💡 目标 XX.XX(+5%) | 止损 XX.XX(-5%) | 仓位 X成
⚠️ 仅供参考，不构成投资建议
```

**🔴 CHECKPOINT**：若该股评分落在「买入」区（≥75），输出前必须显式写明三条前提——
① 该结论仅基于技术面，未含基本面与消息面；② 目标/止损位为按 ATR 或均线推算的参考值，非交易依据；
③ 单一技术评分不构成投资建议。**三句缺一不可。**

## 场景C：买卖建议（「能买吗」「听建议」）

**触发词**：能买吗、该不该买、值得买、听建议、推荐、操作建议

1. 先做场景 A 的完整分析
2. 重点展示评分与决策理由
3. 一句话总结：「因为 XX 指标 XX，所以建议 XX」

**禁止**：给出「一定涨」「包赚」「无风险」等绝对化表述。禁止直接给出满仓指令。

## 场景D：K线分析（「看日K」「周K」）

**触发词**：日K、周K、月K、K线、技术面、技术分析

取近 60 根K线，重点展示：趋势形态、金叉死叉位置、支撑压力、成交量异动。

**周期口径**：日K=60根；周K=52根；月K=36根。周期不同结论可能相反，需注明所用周期。

## 场景E：全天盯盘（「帮我盯盘」）

**触发词**：盯盘、自动盯盘、全天盯盘、监控

用宿主定时任务能力创建，参数：

| 项 | 值 |
|---|---|
| 名称 | `stock-watcher-daily` |
| 频率 | 交易日交易时段，每 30 分钟 |
| 时间点 | 9:35、10:05、10:35、11:05、13:35、14:05、14:35、15:05 |
| 任务内容 | 扫描自选股，检测涨跌幅 ≥5% 或量比 ≥3 的异动 |

**RRULE（合法形式，按 RFC 5545）**：

```
FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR;BYHOUR=9,10,11,13,14,15;BYMINUTE=5,35
```

> ⚠️ **不要用 `FREQ=HOURLY` + `BYHOUR` 的组合**：HOURLY 频率本身已按小时重复，再叠加 BYHOUR 语义冲突，会创建出错误的触发规则。

**必须先确认再创建**：① 用户是否真的需要定时任务（会持续消耗配额）② 宿主是否支持定时任务。
不支持时如实告知，并给出「手动执行」替代方案。

## 场景H：舆情与全面分析（「全面分析」「有什么消息」）

**触发词**：全面分析、深度分析、有什么消息、搜新闻、搜公告、研报

技术面 + 消息面融合。**消息面每条必须带来源与日期**，无来源的消息不得进入结论。

```
🔍 【名称·代码】综合深度分析
━━━━━━━━━━━━━━━━━━━━━━━━
📊 技术面（评分 78/100）：
   💰 现价 XX | 涨幅 +X% | 换手 X%
   📈 趋势多头 | MACD金叉 | RSI中性
   📊 评分明细：趋势22 动能18 量价20 风险18

📰 消息面（截至 YYYY-MM-DD）：
   舆情方向：偏多
   👍 利好（2条）：
      · [来源·日期] XX机构给予"买入"评级，目标价上调至XX
   👎 利空（1条）：
      · [来源·日期] 大股东减持XX万股
   ⚠️ 未核实传闻：不计入方向判断

━━━━━━━━━━━━━━━━━━━━━━━━
🎯 综合判断：
   技术面：偏多（78分）+ 消息面：正面
   → 倾向积极 | 参考仓位 6-8成
   → 理由：技术面强势+消息面利好共振
```

**🔴 CHECKPOINT**：消息面结论输出前必须逐条标注来源与日期。
无法确认来源的消息一律归入「未核实传闻」且**不参与方向判断**。禁止把传闻当利好或利空。

## 场景L：分时量能分析（「主力动向」）

**触发词**：主力动向、分时分析、看量能、早盘放量、尾盘异动、封板、分时图

```
⚡【分时量能分析】贵州茅台(600519)
  现价: 1680.50  涨幅: +1.23% | 最高 1695.00 最低 1670.00
  全天成交: 52180手 (87650.2万元)
  日内方向: 震荡上行 (+1.20%)

  成交分布:
    早盘30分(9:30-10:00): 18235手 (34.9%)
    上午中段(10:00-11:30): 15320手 (29.4%)
    下午中段(13:00-14:30): 11050手 (21.2%)
    尾盘30分(14:30-15:00):  7575手 (14.5%)

  【量能判断】
    📌 早盘放量34.9%，量能集中在前段
```

**判断口径**：放量时段占比 >35% 记为「早盘主导」；<15% 记为「尾盘主导」；其余记为「分布均衡」。
「主力抢筹/出货」这类推断**必须标注为推断并给出依据**，不得作为事实陈述。

## 场景P：预警规则（「智能监控」「设置预警」）

**7 大预警规则**

| 规则 | 触发条件 | 权重 |
|------|----------|------|
| 成本百分比 | 盈利 +15% / 亏损 -12% | ⭐⭐⭐ |
| 日内涨跌幅 | 个股 ±4% / ETF ±2% / 黄金 ±2.5% | ⭐⭐ |
| 成交量异动 | 放量 >2倍均量 / 缩量 <0.5倍 | ⭐⭐ |
| 均线金叉/死叉 | MA5 上穿/下穿 MA10 | ⭐⭐⭐ |
| RSI 超买超卖 | RSI>70 / RSI<30 | ⭐⭐ |
| 跳空缺口 | 向上/向下跳空 >1% | ⭐⭐ |
| 动态止盈 | 盈利 10%+ 后回撤 5%/10% | ⭐⭐⭐ |

**分级**：🚨 紧急（≥3 条件共振）/ ⚠️ 警告（2 条件）/ 📢 提醒（1 条件）

**标的类型差异化**

| 类型 | 日内异动阈值 | 成交量阈值 |
|------|-------------|-----------|
| individual（个股） | ±4% | 2.0倍 |
| etf（ETF） | ±2% | 1.8倍 |
| gold（黄金） | ±2.5% | 无 |

**建议监控频率**

| 时段 | 频率 | 标的范围 |
|------|------|----------|
| 9:30-11:30 / 13:00-15:00 | 每 5 分钟 | 全部 + 技术指标 |
| 11:30-13:00 | 每 10 分钟 | 全部 |
| 15:00-24:00 | 每 30 分钟 | 全部（日线） |
| 0:00-9:30 / 周末 | 每 1 小时 | 仅黄金 |

## 场景R：经验与复盘（「复盘」「我的胜率」）

**触发词**：记一笔、投资笔记、复盘、我的胜率、学了什么

```
🧠 经验回放 — 贵州茅台(600519)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 累计记录: 8 笔 | 自评胜率: 62.5%（口径：按用户自己标注的盈亏，非系统核验）

✅ 买入@1650 | MACD金叉+放量 → 金叉确认后放量突破关键均线
❌ 买入@1720 | RSI超买追高 → RSI>70 时追高风险大，应等回调
```

**🔴 CHECKPOINT（必读）**：胜率是**用户自评**，样本量小、无统计意义。
必须明确标注「样本 n=8，样本量不足，不构成统计结论」，禁止把它当作策略有效性证据。
禁止自动建立用户交易档案——只在用户主动要求时记录。
