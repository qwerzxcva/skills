# 8 维评分体系与决策矩阵

> 本文件定义「股票疯子」的打分口径。**任何评分输出必须能追溯到本表的计算规则。**

---

## 一、数据前置要求

打分前必须先取到以下字段。**缺任一字段 → 对应维度标「数据缺失」并按 0 分计入，绝不用估算值代替**：

| 维度 | 必需字段 |
|---|---|
| 趋势分析 | 近 60 根日K 的收盘价 |
| 动能指标 | 同上（用于计算 MACD/KDJ/RSI） |
| 量价关系 | 成交量、换手率、量比 |
| 风险控制 | 近 60 根收盘价（算波动率、最大回撤） |
| 支撑压力 | 近 60 根最高/最低价 |
| 市场环境 | 指数近 20 根走势 |
| 舆情信号 | 新闻/公告（可缺，缺则按中性 5分并标注） |
| 资金流向 | 主力净流入（可缺，缺则按中性 5 分并标注） |

---

## 二、维度定义与算法

### 1. 趋势分析（20分）

按均线多头排列程度与价格相对位置打分：

| 条件 | 得分 |
|---|---|
| MA5>MA10>MA20>MA60（完全多头） | 20 |
| 三线多头、MA60 未跟上 | 16 |
| 均线纠缠（各线差值 <2%） | 10 |
| 三线空头排列 | 4 |
| 价格跌破 MA60 且 MA20 下行 | 0 |

### 2. 动能指标（20分）

MACD（12,26,9）+ RSI（14）+ KDJ（9,3,3）三项各取 0–20 分后除以 3 向上取整：

| 指标 | 多头信号 | 中性 | 空头信号 |
|---|---|---|---|
| MACD | DIF>DEA 且柱状线连续 3 日放大 | DIF/DEA 缠绕 | DIF<DEA 且柱状线连续 3 日收缩 |
| RSI | 50<RSI<70（强势未超买） | 30<RSI<50 或 70<RSI<80 | RSI<30 或 >80 |
| KDJ | K>D 且 J 上行 | K≈D | K<D 且 J 下行 |

> ⚠️ RSI>70 记为「超买」而非「最强」。追高风险已在风险控制维度扣分，此处不重复加分。

### 3. 量价关系（20分）

| 条件 | 得分 |
|---|---|
| 放量（量比>1.5）且价涨 | 20 |
| 量比 1.0–1.5 且价涨 | 14 |
| 量价背离（价涨量缩） | 6 |
| 缩量（量比<0.7）且价跌 | 4 |
| 放量下跌（量比>1.5 且价跌） | 0 |

### 4. 风险控制（15分）

从**波动率**与**最大回撤**两个角度扣分（高分=低风险）：

| 条件 | 得分 |
|---|---|
| 近 20 日最大回撤 <8%且日均波动 <2% | 15 |
| 回撤 8%–15% | 10 |
| 回撤 15%–25% | 5 |
| 回撤 >25% | 0 |

### 5. 支撑压力（10分）

以近 60 日最高/最低价为基准，评估当前价所处位置：

| 条件 | 得分 |
|---|---|
| 价格在布林中轨上方且未触及上轨 | 10 |
| 价格贴近上轨（超买区） | 5 |
| 价格贴近下轨（超卖区，有反弹空间） | 7 |
| 跌破下轨 | 2 |

### 6. 市场环境（5分）

| 条件 | 得分 |
|---|---|
| 指数在 MA20 上方且 5 日上涨 | 5 |
| 指数横盘 | 3 |
| 指数在 MA20 下方且 5 日下跌 | 0 |

### 7. 舆情信号（5分）

| 状态 | 得分 |
|---|---|
| 近 7 日利好 ≥3 条且无利空（须有来源） | 5 |
| 利好利空均衡 | 3 |
| 利空 ≥2 条，或含未核实传闻 | 0–1 |

### 8. 资金流向（5分）

| 状态 | 得分 |
|---|---|
| 主力净流入且占成交额 >5% | 5 |
| 主力小幅净流入 | 3 |
| 主力净流出 | 0 |

---

## 三、加权与决策矩阵

**综合评分** = 8 个维度得分直接相加（满分 100）。

| 技术面评分 | 消息面 | 综合建议 | 参考仓位 |
|--------|--------|---------|------|
| 强势(≥75) | 正面 | 倾向积极 | 6-8成 |
| 强势(≥75) | 中性 | 可考虑建仓 | 5-7成 |
| 强势(≥75) | 负面 | 谨慎持有 | 3-5成 |
| 偏多(60-74) | 正面/中性 | 可谨慎参与 | 3-5成 |
| 偏多(60-74) | 负面 | 观望为主 | 0-2成 |
| 中性(45-59) | 任意 | 观望为主 | 0-2成 |
| 偏空(<45) | 任意 | 不建议买入 | 0成 |

---

## 四、🔴 输出前强制确认（买入区 ≥75 分必做）

评分落在「倾向积极 / 可考虑建仓」区间时，输出**必须**同时给出以下三条，缺一不可：

1. **本结论仅基于技术面**，未包含基本面尽调与消息面核实。
2. **目标位与止损位是按均线/ATR 推算的参考值**，不是交易依据，实际执行需自行确定。
3. **单一技术评分不构成投资建议**，且该评分规则未经过回测验证。

## 五、评分示例（格式示范，非真实数据）

```
📊 评分明细（总分 78/100）
   趋势 18/20  | 动能 14/20 | 量价 20/20 | 风险 11/15
   支撑  9/10  | 环境 4/5| 舆情 3/5  | 资金 3/5
   数据缺口：舆情仅取到 2 条（数据缺失项已按中性计分并标注）
   ⚠️ 以上评分为技术面规则输出，未包含基本面尽调，不构成投资建议
```

## 六、常见评分错误（❌ 反例）

| ❌ 错误做法 | ✅ 正确做法 |
|-----------|-----------|
| 把 RSI>80 当作最强信号加满动能分 | RSI>80 属超买，动能分不加分，风险维度扣分 |
| 缺数据时按「中性 7 分」凭空补 | 标注「数据缺失」并按 0 分计入总分 |
| 8 维不全就报总分 | 列出每一维的得分明细，缺项显式标注 |
| 评分 78 直接写「强烈买入」 | 写「技术面偏强」，并附三句强制确认 |
| 把规则分当成回测结论 | 明确说明该规则未经验证 |
