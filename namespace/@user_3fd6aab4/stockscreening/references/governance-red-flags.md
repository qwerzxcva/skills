# 公司治理风险指标清单

## 数据获取
使用 `westock-data` 获取：
- 股东信息（十大股东、持股比例、增减持记录）
- 股本结构（限售股解禁计划）
- 分红记录

使用 `neodata-financial-search` 搜索：
- 大股东减持公告
- 股权质押公告
- 关联交易公告
- 违规处罚记录
- 管理层变动

## 一、大股东行为 — 权重 30%

### 1.1 大股东减持
- **红线**：大股东/董监高近3个月累计减持 > 总股本1%
- **黄线**：大股东/董监高近6个月有减持记录
- **数据来源**：westock-data 股东增减持 + 公告

### 1.2 股权质押
- **红线**：第一大股东质押比例 > 80%
- **黄线**：整体股权质押比例 > 30%
- **数据来源**：westock-data 股东信息 + neodata-financial-search

### 1.3 实控人变更/动荡
- **红线**：近2年内发生实控人变更且新实控人背景不明
- **黄线**：控制权存在纠纷/司法冻结
- **数据来源**：neodata-financial-search

## 二、关联交易与资金占用 — 权重 25%

### 2.1 异常关联交易
- **红线**：关联交易金额 / 营收 > 30%
- **黄线**：关联交易金额 / 营收 > 15%
- **数据来源**：年报附注

### 2.2 资金占用
- **红线**：其他应收款中有大额非经营性占用（> 净资产5%）
- **黄线**：其他应收款 / 总资产 > 10%
- **数据来源**：资产负债表附注

### 2.3 对外投资异常
- **红线**：频繁跨界并购，且标的与主业无关
- **黄线**：近2年并购 > 3笔，且商誉持续增长
- **数据来源**：neodata-financial-search

## 三、分红与回报 — 权重 15%

### 3.1 铁公鸡
- **红线**：连续5年以上未分红（非扩张期合理情况除外）
- **黄线**：分红率 < 10% 且 ROE > 10%（有钱不分）
- **数据来源**：westock-data 分红记录

### 3.2 过度分红
- **红线**：分红金额 > 当年净利润 + 经营现金流为负（借钱分红）
- **黄线**：分红率 > 80% 且非公用事业类
- **数据来源**：分红记录 + 现金流量表

## 四、管理层与合规 — 权重 30%

### 4.1 管理层动荡
- **红线**：近1年内董事长/总经理/财务总监离职
- **黄线**：多位独立董事辞职
- **数据来源**：neodata-financial-search 公告

### 4.2 违规处罚
- **红线**：近2年内被证监会立案调查或行政处罚
- **黄线**：近2年内有交易所通报批评
- **数据来源**：neodata-financial-search

### 4.3 信披质量
- **红线**：近1年内多次更正公告/补充公告（>3次）
- **黄线**：年报/季报延期披露
- **数据来源**：neodata-financial-search

### 4.4 前科记录
- **红线**：历史上曾有财务造假/欺诈发行记录
- **黄线**：曾被ST/*ST处理
- **数据来源**：neodata-financial-search + westock-data

## 公司治理维度综合评分公式
```
治理评分 = 100 - Σ(红线 × 20分) - Σ(黄线 × 6分)
最低分为0
（治理问题通常比财务问题更致命，权重更高）
```
