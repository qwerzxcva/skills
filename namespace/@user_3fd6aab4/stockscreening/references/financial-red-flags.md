# 财务暴雷风险指标清单

## 数据获取
使用 `westock-data` 或 `wb-finance-skill` 获取以下数据：
- 资产负债表、利润表、现金流量表（近3-5年）
- 财务比率：ROE、毛利率、净利率、资产负债率等
- 审计意见类型

## 一、盈利质量 — 权重 25%

### 1.1 营收与利润背离
- **红线**：营收增长但净利润下滑，且连续2个季度以上
- **黄线**：营收增长但经营现金流为负
- **数据来源**：利润表 + 现金流量表

### 1.2 扣非净利润 vs 归母净利润
- **红线**：扣非净利润 / 归母净利润 < 50%，说明利润主要来自非经常性损益
- **黄线**：该比值在 50%-70% 之间
- **数据来源**：利润表附注

### 1.3 毛利率异常波动
- **红线**：毛利率同比变动 >10个百分点，且无合理解释（如行业巨变）
- **黄线**：毛利率连续3个季度下滑
- **数据来源**：利润表

## 二、资产质量 — 权重 25%

### 2.1 应收账款异常
- **红线**：应收账款 / 营收 > 50%（制造业）/ > 30%（消费行业）
- **红线**：应收账款增速 > 营收增速 × 1.5
- **黄线**：账龄1年以上应收账款占比 > 30%
- **数据来源**：资产负债表附注

### 2.2 存货积压
- **红线**：存货 / 总资产 > 40%（非房地产行业）
- **黄线**：存货周转天数同比增加 > 30%
- **数据来源**：资产负债表 + 存货周转率计算

### 2.3 商誉减值风险
- **红线**：商誉 / 净资产 > 50%
- **黄线**：商誉 / 净资产 > 30%，且被收购标的业绩未达承诺
- **数据来源**：资产负债表

## 三、现金流健康度 — 权重 20%

### 3.1 经营现金流
- **红线**：连续2年经营现金流为负
- **黄线**：经营现金流 / 净利润 < 0.5（利润没有现金支撑）
- **数据来源**：现金流量表

### 3.2 自由现金流
- **红线**：自由现金流连续3年为负（资本开支过大）
- **黄线**：自由现金流 / 营收 < 5%
- **数据来源**：现金流量表（经营现金流 - 资本开支）

### 3.3 存贷双高
- **红线**：货币资金充裕但短期借款/长期借款也高（存款 > 营收20% 且 有息负债 > 净资产50%）
- **黄线**：利息支出 / 净利润 > 30%
- **数据来源**：资产负债表 + 利润表

## 四、偿债能力 — 权重 15%

### 4.1 资产负债率
- **红线**：资产负债率 > 70%（非金融行业）
- **黄线**：资产负债率 > 60% 且短期借款占比 > 80%
- **数据来源**：资产负债表

### 4.2 流动比率
- **红线**：流动比率 < 0.8
- **黄线**：速动比率 < 0.5
- **数据来源**：资产负债表计算

### 4.3 对外担保
- **红线**：对外担保总额 / 净资产 > 50%
- **黄线**：对外担保总额 / 净资产 > 20%
- **数据来源**：年报附注 / 公告

## 五、审计与合规 — 权重 15%

### 5.1 审计意见
- **红线**：非标准无保留意见（保留意见/否定意见/无法表示意见）
- **黄线**：带强调事项段的无保留意见
- **数据来源**：年报审计报告

### 5.2 问询函/监管函
- **红线**：近1年内收到证监会/交易所问询函或监管函
- **黄线**：近2年内有信息披露违规记录
- **数据来源**：公告 / neodata-financial-search

## 财务维度综合评分公式
```
财务评分 = 100 - Σ(红线 × 15分) - Σ(黄线 × 5分)
最低分为0
```
