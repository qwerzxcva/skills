# 行业与宏观风险指标清单

## 数据获取
使用 `westock-data` 获取：
- 行业板块指数走势
- 行业估值水平
- 行业成分股表现

使用 `neodata-financial-search` 搜索：
- 行业政策动态
- 行业新闻与趋势分析
- 宏观经济数据

## 一、行业周期位置 — 权重 30%

### 1.1 行业指数走势
- **红线**：行业指数处于近3年 > 90% 分位 + 出现周线级别见顶信号
- **黄线**：行业指数处于近3年 > 70% 分位
- **数据来源**：westock-data 行业板块数据

### 1.2 行业景气度
- **红线**：行业龙头公司业绩集体下滑（>3家重点公司QoQ负增长）
- **黄线**：行业PMI/景气指数连续2个月下行
- **数据来源**：neodata-financial-search + 财报

### 1.3 行业生命周期
- **红线**：行业处于衰退期（市场规模连续2年萎缩）
- **黄线**：行业增速放缓至个位数，且无新增长点
- **数据来源**：neodata-financial-search 行业研报

## 二、政策风险 — 权重 30%

### 2.1 监管打压
- **红线**：行业遭遇重大监管政策利空（如教培双减、游戏版号停发级别）
- **黄线**：行业政策趋严/监管收紧信号
- **数据来源**：neodata-financial-search 政策新闻

### 2.2 补贴/优惠政策变动
- **红线**：核心依赖的补贴政策取消或大幅削减
- **黄线**：补贴退坡时间表明确
- **数据来源**：neodata-financial-search

### 2.3 国际贸易/地缘风险
- **红线**：被列入实体清单/制裁名单，且海外收入占比 > 30%
- **黄线**：关税大幅提高 / 海外业务面临不确定性
- **数据来源**：neodata-financial-search + 年报（海外收入占比）

## 三、竞争格局 — 权重 20%

### 3.1 竞争恶化
- **红线**：行业价格战白热化，龙头毛利率持续下滑
- **黄线**：行业集中度下降，新进入者增多
- **数据来源**：行业研报 + 财务数据

### 3.2 技术替代风险
- **红线**：公司核心技术路线面临被替代风险（如燃油车→新能源）
- **黄线**：行业技术路线变化速度快，公司研发投入不足（研发费用率 < 3%）
- **数据来源**：neodata-financial-search

### 3.3 客户/供应商集中度
- **红线**：前五大客户占比 > 80% 或 前五大供应商占比 > 80%
- **黄线**：前五大客户占比 > 50%
- **数据来源**：年报披露

## 四、宏观环境 — 权重 20%

### 4.1 宏观经济下行
- **红线**：GDP增速持续放缓 + 行业是强周期行业（房地产、汽车、钢铁等）
- **黄线**：PMI连续3个月 < 50（收缩区间）
- **数据来源**：neodata-financial-search 宏观数据

### 4.2 利率与流动性
- **红线**：加息周期 + 公司资产负债率 > 60%
- **黄线**：市场利率上行 + 公司有大量短期债务
- **数据来源**：宏观数据 + 财务数据

### 4.3 汇率风险
- **红线**：人民币大幅贬值 + 公司有大量美元债务
- **黄线**：海外收入占比 > 50%，汇率波动对利润影响大
- **数据来源**：neodata-financial-search + 年报

## 行业宏观维度综合评分公式
```
行业宏观评分 = 100 - Σ(红线 × 15分) - Σ(黄线 × 5分)
最低分为0
```
