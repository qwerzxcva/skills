# 技术面陷阱指标清单

## 数据获取
使用 `westock-data` 获取：
- K线数据（日线/周线/月线）
- 均线系统数据
- 成交量、换手率
- 技术指标（MACD、KDJ、RSI、BOLL等）

## 一、量价关系异常 — 权重 30%

### 1.1 价涨量缩
- **红线**：连续上涨5日以上但成交量逐步萎缩（>30%缩量）
- **黄线**：创新高但成交量未同步放大
- **数据来源**：K线数据（OHLCV） — 上涨动力衰竭，诱多信号

### 1.2 价跌量增
- **红线**：下跌时成交量持续放大（放量下跌）
- **黄线**：破位下跌时放量
- **数据来源**：K线数据（OHLCV） — 主力出货信号

### 1.3 天量天价
- **红线**：单日成交量是20日均量的3倍以上，且收长上影线
- **黄线**：放巨量冲高回落
- **数据来源**：K线数据（OHLCV） — 阶段性顶部特征

## 二、均线与趋势 — 权重 25%

### 2.1 均线死叉
- **红线**：周线级别 5周均线下穿 20周均线（中期趋势转空）
- **黄线**：日线级别 MA5/MA10/MA20 三线死叉
- **数据来源**：K线数据计算均线

### 2.2 假突破
- **红线**：突破关键阻力位后3日内跌回（假突破确认）
- **黄线**：突破时成交量未放大
- **数据来源**：K线数据 — 经典诱多陷阱

### 2.3 均线空头排列
- **红线**：MA5 < MA10 < MA20 < MA60 空头排列
- **黄线**：MA5 < MA20 且 MA20 斜率向下
- **数据来源**：K线数据计算

## 三、技术指标背离 — 权重 25%

### 3.1 MACD顶背离
- **红线**：股价创新高但MACD未创新高（顶背离）
- **黄线**：MACD高位死叉
- **数据来源**：K线数据计算MACD(12,26,9) — 上涨动能衰竭

### 3.2 RSI背离
- **红线**：股价创新高但RSI走低 + RSI > 70
- **黄线**：RSI > 80 超买区域
- **数据来源**：K线数据计算RSI(14)

### 3.3 成交量背离
- **红线**：股价创新高但OBV/成交量未创新高
- **黄线**：上涨过程中成交量逐步萎缩
- **数据来源**：K线数据（OHLCV） — 资金推动力不足

## 四、庄股/Suspicious 特征 — 权重 20%

### 4.1 分时图异常
- **红线**：频繁出现一字横盘、尾盘偷袭拉升/砸盘
- **黄线**：分时走势与大盘/板块显著背离
- **数据来源**：日K线形态观察 — 高度控盘或庄股特征

### 4.2 K线形态异常
- **红线**：频繁出现长上下影线（>实体3倍），且伴随缩量
- **黄线**：K线实体极小（十字星频发），走势呆滞
- **数据来源**：K线数据观察上下影线与实体长度比 — 高度控盘，流动性差

### 4.3 换手率极低
- **红线**：日换手率连续 < 0.1%（僵尸股）
- **黄线**：日换手率 < 0.3%
- **数据来源**：westock-data 换手率数据 — 无人关注，流动性风险

## 五、关键位置破位 — 权重（归入均线趋势 25% 中）

### 5.1 破位下行
- **红线**：收盘价跌破年线（MA250）且3日内未收复
- **黄线**：收盘价跌破MA120（半年线）
- **数据来源**：K线数据计算均线

### 5.2 前低支撑失效
- **红线**：跌破近6个月最低价（前低支撑位失守）
- **黄线**：连续3日在近6个月低点附近徘徊（±3%以内）
- **数据来源**：K线历史数据

### 5.3 跳空缺口
- **红线**：出现向下跳空缺口且5日内未回补
- **黄线**：出现向下跳空缺口
- **数据来源**：日K线

### 5.4 关键均线压力
- **红线**：股价反弹连续3次受阻于同一均线（MA60/MA120）
- **黄线**：股价长期运行在MA60下方（>20个交易日）
- **数据来源**：K线数据计算均线

## 技术面维度综合评分公式
```
技术评分 = 100 - Σ(红线 × 15分) - Σ(黄线 × 5分)
最低分为0
```
