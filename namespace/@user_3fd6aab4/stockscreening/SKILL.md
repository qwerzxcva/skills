# 个股排雷 (Stock Demining)

对 A 股 / 港股 / 美股个股进行多维度风险扫描，帮助用户识别潜在的投资陷阱。

## 触发条件

当用户请求涉及以下任一场景时使用本 skill：
- 查询某只股票的风险/隐患/问题
- 个股排雷/扫雷
- 个股体检/诊断/风险评估
- 询问某只股票"能不能买"之前先做风控检查
- 对持仓股进行定期风险复查

## 核心能力

1. **自动数据获取** — 优先调用 `wb-finance-skill`（金融场景总入口），辅以 `westock-data`（结构化数据）和 `neodata-financial-search`（自然语言搜索公告/新闻）
2. **五维度扫描** — 财务暴雷、估值泡沫、公司治理、技术面陷阱、行业宏观
3. **三种输出模式** — 检查清单 / 评分报告 / 深度分析，按需切换
4. **一票否决机制** — 致命风险自动直接标红

## 前置步骤：加载金融数据工具

本 skill 依赖以下三个独立的金融数据 Skill，需按需加载：

| Skill | 用途 | 何时加载 |
|-------|------|----------|
| `westock-data` | 结构化行情/财务/股东数据 | **必加载** — 获取 PE/PB/K线/财报等定量数据 |
| `neodata-financial-search` | 自然语言搜索公告/新闻/政策 | **必加载** — 搜索问询函/减持公告/行业新闻等定性信息 |
| `wb-finance-skill` | 金融场景总路由入口 | **可选** — 作为 westock-data 的替代入口，二选一即可 |

**推荐加载顺序**：先加载 `westock-data` 和 `neodata-financial-search`（各司其职、覆盖全面）。如果用户明确要求"用金融 skill"，则加载 `wb-finance-skill` 替代 `westock-data`。

加载方式：通过 `Skill` 工具分别加载，例如：
```
Skill: westock-data
Skill: neodata-financial-search
```

## 工作流程

### Phase 1：识别股票

从用户输入中提取股票代码或名称。如果用户只给了名称，先通过 westock-data 查询确认精确代码和市场（A股/港股/美股）。

### Phase 2：确定输出模式

询问或判断用户偏好的输出深度：

| 关键词 | 模式 | 说明 |
|--------|------|------|
| 快速看/扫一眼/有没有坑 | 检查清单 | 只列出触发的预警项 |
| 评分/打分/看看多少分 | 评分报告 | 五维度打分 + 风险等级 |
| 详细分析/深度/写报告 | 深度报告 | 逐项展开 + 数据对比 + 建议 |

如果用户没有明确指定，默认使用「评分报告」模式。

### Phase 3：五维度数据采集与逐项检查

按维度逐一加载对应的 references 文件并执行检查。每个维度完成后输出中间结果。

**执行顺序建议**：先做不依赖实时行情的维度（财务→治理→估值→行业→技术），技术面最后做因为需要实时 K 线。

#### 维度 1：财务暴雷风险
- 加载 `references/financial-red-flags.md`
- 获取数据：资产负债表、利润表、现金流量表、审计意见
- 工具路由：westock-data 获取财务数据，neodata-financial-search 查审计意见和监管问询
- 逐条对照指标清单判断触发情况
- **查询示例**：
  - `westock-data` 查财报 → 获取营收、净利润、毛利率、应收账款、存货、商誉、经营现金流等
  - `westock-data` 查财务比率 → 获取 ROE、资产负债率、流动比率等
  - `neodata-financial-search` 搜索 "{股票名} 审计意见" → 获取审计报告类型
  - `neodata-financial-search` 搜索 "{股票名} 问询函" → 获取监管问询记录

#### 维度 2：估值泡沫风险
- 加载 `references/valuation-red-flags.md`
- 获取数据：PE/PB/PS/PEG、历史分位、行业平均估值、换手率、近期涨跌幅
- 工具路由：westock-data 行情查询 + 历史估值
- **查询示例**：
  - `westock-data` 查行情 → 获取 PE(TTM)、PB、PS、总市值
  - `westock-data` 查历史估值 → 获取近5年 PE 分位
  - `westock-data` 查行业板块 → 获取行业平均 PE 作为对比基准
  - `westock-data` 查 K线 → 获取近1个月涨跌幅、日均换手率、日均成交额
  - PEG 需要自行计算：PE(TTM) / 近3年净利润复合增速

#### 维度 3：公司治理风险
- 加载 `references/governance-red-flags.md`
- 获取数据：股东信息、质押比例、增减持记录、分红记录
- 工具路由：westock-data 股东/分红数据，neodata-financial-search 搜索减持公告/违规/管理层变动
- **查询示例**：
  - `westock-data` 查股东信息 → 获取十大股东、质押比例、增减持记录
  - `westock-data` 查分红 → 获取历史分红记录、分红率
  - `neodata-financial-search` 搜索 "{股票名} 减持公告" → 查大股东减持
  - `neodata-financial-search` 搜索 "{股票名} 立案调查 行政处罚" → 查违规记录
  - `neodata-financial-search` 搜索 "{股票名} 董事长 总经理 离职" → 查管理层动荡
  - `neodata-financial-search` 搜索 "{股票名} 关联交易" → 查关联交易规模

#### 维度 4：技术面陷阱
- 加载 `references/technical-red-flags.md`
- 获取数据：日线/周线 K 线、均线、MACD/RSI、成交量
- 工具路由：westock-data K 线数据 + 技术指标
- **查询示例**：
  - `westock-data` 查日K线 → 获取近60个交易日 OHLCV，用于计算均线、识别形态
  - `westock-data` 查周K线 → 获取近52周数据，判断中期趋势
  - MACD/RSI/OBV 指标如 westock-data 不支持直接查询则基于 OHLCV 自行计算
  - 分时图异常判断：通过观察日K线上下影线长度与实体比例判断

#### 维度 5：行业/宏观风险
- 加载 `references/industry-macro-red-flags.md`
- 获取数据：行业指数、行业估值、行业新闻、宏观数据
- 工具路由：westock-data 行业板块数据，neodata-financial-search 搜行业政策/新闻
- **查询示例**：
  - `westock-data` 查行业板块 → 获取行业指数走势、行业估值水平
  - `neodata-financial-search` 搜索 "{行业名} 政策 监管 2026" → 查行业政策动向
  - `neodata-financial-search` 搜索 "{行业名} 景气度 发展趋势" → 查行业周期位置
  - `neodata-financial-search` 搜索 "{股票名} 海外收入 实体清单 制裁" → 查地缘风险
  - `neodata-financial-search` 搜索 "PMI GDP 利率 2026" → 查宏观环境数据

### Phase 4：综合评分与风险定级

加载 `references/scoring-system.md`，按评分公式计算总分和风险等级。

**一票否决检查**（优先于评分）：
逐项检查 scoring-system.md 中的 5 条一票否决项。任一条触发，直接评为「🔴 极高风险」并标注否决原因。

### Phase 5：按模式输出结果

根据 Phase 2 确定的模式输出：

**模式 A — 排雷检查清单：**
```
📋 {股票名称}（{代码}）排雷检查清单

🔴 致命预警（一票否决）：
  [如有] ...

⚠️ 触发的红线（严重问题）：
  1. [维度] 指标名称：具体数值 vs 阈值
  ...

⚡ 触发的黄线（需关注）：
  1. [维度] 指标名称：具体数值 vs 阈值
  ...

✅ 通过项：共 X 项
```

**模式 B — 综合评分报告：**
```
📊 {股票名称}（{代码}）风险评分报告

┌─────────────────┬────────┬──────┬──────────┐
│ 维度             │ 得分    │ 权重  │ 加权     │
├─────────────────┼────────┼──────┼──────────┤
│ 财务暴雷风险     │ XX/100 │ 30%  │ XX       │
│ 估值泡沫风险     │ XX/100 │ 20%  │ XX       │
│ 公司治理风险     │ XX/100 │ 25%  │ XX       │
│ 技术面陷阱       │ XX/100 │ 15%  │ XX       │
│ 行业/宏观风险    │ XX/100 │ 10%  │ XX       │
├─────────────────┼────────┼──────┼──────────┤
│ 综合得分         │        │      │ XX/100   │
│ 风险等级         │        │      │ 🟢/🟡/🟠/🔴 │
└─────────────────┴────────┴──────┴──────────┘

各维度关键发现：
- 财务：[最严重的 1-2 个问题]
- 估值：[最严重的 1-2 个问题]
- ...
```

**模式 C — 深度分析报告：**
在评分报告基础上，每个维度逐条展开：
- 数据来源和原始数值
- 与行业平均 / 历史区间的对比
- 风险解读和可能的影响
- 改进建议（如果有改善空间）

## 注意事项

1. **数据完整性**：如果某项数据无法获取（如某些港股/美股数据），明确标注「数据不可得」，不强行打分
2. **行业差异**：不同行业的指标阈值应有调整意识（如金融业资产负债率天然高，科技股 PE 天然高），在分析中注明行业特性
3. **时效性**：优先使用最新财报数据（最近一期季报/年报），技术面用最近交易日数据
4. **免责声明**：每次输出末尾附上简短声明——"以上分析基于公开数据和量化规则，不构成投资建议。投资有风险，入市需谨慎。"
5. **中国市场惯例**：涨用红色，跌用绿色（与欧美相反）；货币默认用 ¥
